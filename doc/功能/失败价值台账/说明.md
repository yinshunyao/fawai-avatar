# 失败价值台账

## 要点

已确认有价值的失败 / 换道错族后，写入本任务避坑卡（jsonl），可搜可回灌；三维达记忆配置阈值后实写 **avoid** lore。禁止每次工具失败都入账。

## 验收口径

1. `failure_ledger_upsert` 写入 `{FAWAI_DATA_DIR}/sessions/{task_id}/failure_ledger.jsonl`；字段含 symptom / cause / do_not_retry / commands_tried 等。`symptom` 等须为人读短句（禁止 `true`/`false`）；过门写 lore 时标题由 `ledger_title.summarize_failure_lore_title` 总结并加 `[avoid]` 前缀。
2. `failure_ledger_search` / `get` 默认仅当前任务。
3. 三维（完备/通用/效率）折算百分比后均 ≥ `FAWAI_LEDGER_GATE_THRESHOLD`（记忆配置，默认 **80**）才写 lore；笔记带 avoid 极性。
4. 旁路进度 `phase=failure_ledger_gate`，展示用时 / token 并计入任务 stats。
5. 规划提示写明：勿把 avoid 当正例；勿每步 `ok=false` 都 upsert。

## 边界

- 不替代铲运行成败维 / Skill avoid 栏。
- 不替代成功台账卡上的短 `avoid` 句（可链 `success_ledger_id`）。
- 非任务结束默认蒸馏。
