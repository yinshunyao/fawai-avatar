# 运行平台

## 验收

- 自动探测：`Darwin` / `Linux` / `Windows`、机器架构、是否 headless（无 `DISPLAY`/`WAYLAND_DISPLAY`，或 `FAWAI_HEADLESS=1` 强制；`=0` 强制按有桌面）。
- 大脑 system prompt 含平台事实与命令口径（含 macOS/Linux 的 `find`/`ls` 列文件口径）；无界面时明确禁止 GUI/截屏规划。
- 能力清单在无 GUI 时不暴露 `click`/`type`/`hotkey`；执行层若仍收到 GUI 动作则失败并说明原因。
- 观察候选在 headless 下不含 `obs_screen`；误采截屏得到失败摘要而非进程崩溃。
- 会话网关启动横幅打印平台与 headless 来源；headless 强制关截屏候选。
- 核心依赖可无 `mss`/`pyautogui` 安装；桌面能力：`pip install -e ".[gui]"`。
- 浏览器（与 OS headless 无关）：`pip install -e ".[browser]"` + `playwright install chromium`；默认无头。
- frpc：与当前 OS 二进制格式不匹配时给出明确错误（可用 `FAWAI_FRPC_BIN` 或关穿透）。

## 边界

- 不实现 Linux GUI 键鼠/截屏落地（网页走 `browser_*`，见 [浏览器操作](../浏览器操作/说明.md)）。
- 不提供独立 stdin REPL；交互仍走会话网关 PWA 或 `-m` demo。
- 不自动下载 frpc；不自动 `playwright install`（须显式装浏览器二进制）。

## 工程约束

后续改本仓能力时，遵守 `.cursor/rules/rules-platform.mdc`：凡处理须考虑平台；**无法本机调试也要在设计与代码层完成跨系统支持**。
