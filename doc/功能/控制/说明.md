# 控制（v1）

## 验收

- 执行原子动作：点击、键入、热键、运行 shell（受资源清单约束）。
- **C3 接地**：`ui_click` / `ui_type`（`args.ref` 来自最近 `obs_ax`）；`ui_verify` 仅 AX 回证（`method=ax` 可省略；禁止 `method=ocr/vlm`）；扩展原语 `double_click` / `right_click` / `scroll` / `press`。
- 前台 GUI 动作必须持有 `foreground_lease`；未持锁拒绝。
- 后台写操作必须在已申报且获批的资源清单内。
- 另转发后台动作：`fs_*` / `version_*`（无 GUI；不受 `FAWAI_DRY_RUN`）。
- **浏览器**：`browser_*`（Playwright；默认无头；不占前台租约；受 `FAWAI_DRY_RUN`；见 [浏览器操作](../浏览器操作/说明.md)）。
- **多屏**：click 默认图内坐标，闭环注入最近截屏 `origin_x`/`origin_y` 与画面尺寸 / Retina `coord_scale_*`；`app_focus` 激活 App（见 [多屏与全屏观察](../多屏与全屏观察/说明.md)）。
- **`app_focus` 拒假成功**：activate 后探测 frontmost；目标未在前台 → `ok=false`（疑全屏 Space）；参数兼容 `app` / `app_name`。
- **前台租约拒因**：区分「任务非 running|waiting」与「被其它任务占用」，禁止笼统一句导致假归因。
- **点击拒假成功**：图内坐标超出最近截图、映射后不在任何显示器内、或 AX 中心坐标荒谬 → `ok=false`（禁止再报成功）；输入框已有待发文案时规划优先 `press`/`hotkey` 提交。

## 边界

- GUI 键鼠以有桌面的 macOS 为主；Linux **无界面**下 GUI 动作硬失败，编码/文件/shell/`browser_*` 可用（见 [运行平台](../运行平台/说明.md)）。
- 无 lease 模块时不得绕过闸门。
- `FAWAI_DRY_RUN` 作用于 GUI/shell/`browser_*`，不阻断文件与版本工具。
- shell 参数兼容 `cmd` / `command` / `argv`；失败提示按当前 OS 给命令口径。探测多 CLI 用 `command -v a b c || true`（`which` 缺一个即非零）。
- shell **硬拦**用 `cat`/`cp`/`head` 等读本机绝对路径绕过 `fs_*`；`ssh`/`rsync`/部署 shovel 放行（见 `shell_guard.py`）。
- `hotkey`：`args.keys` 为字符串列表（如 `["cmd","tab"]`）；兼容误写的 `key`/`combo`=`"cmd+tab"`。
- macOS：**会话网关 Web 主入口**一次性请求辅助功能、屏幕录制，以及在 `FAWAI_READ_ROOTS` 含 `/` 时引导「完全磁盘访问」；任务执行中只检查状态，不再反复弹窗。
- GUI 动作前先过 headless 闸门，再校验辅助功能；未授权则拒绝并提示。
- 截屏失败时若主入口未引导过，才再引导屏幕录制权限。
- 桌面依赖为可选 extras：`pip install -e ".[gui]"`（`pyautogui` / `mss`）。
- 浏览器依赖：`pip install -e ".[browser]"` 后执行 `playwright install chromium`。

## 实现映射

| 规范名 | 路径 |
|:---|:---|
| 控制 | `fawai_avatar/control/` |
| 应用前台 | `control/app_focus.py`；`executor` kind=`app_focus` |
| 点击坐标 | `executor.resolve_click_global` + `validate_*`；loop 注入 origin/尺寸/scale |
| 控件接地 | `executor` kind=`ui_click`/`ui_type`/`ui_verify`；`observe/ax_tree` ref |

| shell 禁绕过 fs | `fawai_avatar/control/shell_guard.py` |
