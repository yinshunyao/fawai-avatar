# 执行配置自动模式

## 验收

- compose 入口为**图标钮**（无「模式」文字、无边框计数）；点开为执行配置面板。
- 四项（极速 / 全力 / 分档 / 计划）各自三态：**自动 / 开 / 关**；默认均为自动。
- **自动**：只表示「每个新任务初始化时再判」；**不**把上次分析结果记成全局「自动·开/关」；面板固定显示「自动」。
- **开 / 关**：手工固定偏好；分析跳过该键。
- **任务隔离**：打开/切换任务时底栏从该任务 `exec_config` / `mode_prefs` 回填；进行中拨动立刻 `POST /api/tasks/{id}/exec-config` 写任务 meta；无焦点任务时用本机全局末次（新建继承）。已结束任务再拨只改全局末次、不回写历史。
- 无全局「自动」总开关；说明文案在标题悬停浮窗，不在面板正文展开。
- 入站 `meta.mode_prefs`；上传 Form 同字段。兼容旧 `mode_auto` + `mode_auto_lock`。
- 全力语义：围绕目标尽量做完；进计划后子任务继承 `effort`。

## 边界

- 不另开第二轮 LLM 只评四开关。
- 不等于换模型；不等于关写租约等硬闸。
- `exec-config` API **不**改 `runtime`（不把普通任务改成 Cursor Agent）。
