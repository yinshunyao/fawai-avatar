# 主脑委派

## 验收

- 模型配置可为角色 `fast` 选供应商与模型；留空则关闭快模型委派，主脑逐步自执行。
- 主脑规划时可输出 `delegate: {tier:"fast"| "cursor", goal, stop_when, max_steps}`（或原生 `delegate_to_fast` / `delegate_to_cursor`）；本步 `actions` 为空。
- **机械步优先委派**：只读定位/多文件检索、已知路径再读、远程 ls/进程/supervisor/端口探查、同构只读链、简单改写——应优先一段委派，勿主脑逐步自跑。
- `tier=fast`：进入快模型子闭环（观察 → 规划 → 执行）；段内失败/收束/步数满后**摘要回灌主脑**。
- `tier=cursor`：须 [Cursor Agent](../../06-工作区与编码/07-CursorAgent/说明.md) 已启用；由 Cursor local agent 跑子目标后摘要回灌（不走本机 fs 子闭环）。
- 快模型禁止再委派、禁止 `need_input`（歧义升回主脑）；Cursor 委派段同禁再委派。
- 轨迹进度可见 `delegate_fast` / `delegate_cursor` / `delegate_done`；`plan.raw.model` 可区分主脑与委派面。
- 快模型规划默认 **关闭深度思考**（`thinking_role=fast`）；主脑规划默认开思考，不设默认思考预算。见 [LLM 接入](../../01-接入与呈现/01-LLM接入/说明.md)。

## 边界

- 不做「每步再评估用谁」的额外 LLM 轮；由主脑在规划时定责（提示词要求机械步优先委派）。
- 不做「每步再评估要不要思考」的额外 LLM 轮；思考开关跟角色与模型档案。成功后观察反省深度由同轮 [步级执行档](../05-步级执行档/说明.md) `step_run` 声明，仍非第二轮评分。
- 高风险终答、互斥路线、架构决断应由主脑直接处理，不宜委派。
- 段内不做完整执行反省换道：动作失败即回灌主脑。
- 强制模型角色 `force` 不覆盖显式传入的快模型 id。
