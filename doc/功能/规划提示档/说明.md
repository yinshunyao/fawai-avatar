# 规划提示档

## 验收

- 规划前按本轮目的选档：`vision` / `fs` / `gui` / `full`。
- `vision`：短提示 + 可附图走 VLM；能力清单为定位子集。
- `fs`：文件/代码/前端改页或已有 fs 工具历史 → **不附用户图**，走文本模型；注入 fs 相关子集。
- `gui`：依赖可见 App UI 时保留 GUI 相关提示。
- `full`：兜底接近原全量，仍带短 thought 约束。
- 硬校验仍用全量能力清单；`plan.raw.prompt_profile` 可观测。

## 边界

- 首期规则推断选档，不加「只为选档」的额外 LLM 轮。
- 不负责截断 JSON 的续写修复。
