# 云端中继

## 验收

- 提供与 LAN **同一消息信封**的出站挂载接口骨架（connect / send / on_message）。
- 中继只做帧转发与鉴权契约说明；**不**编排任务、不点桌面。
- 首期可为本地 echo / 未配置则跳过；不强制绑定某一托管厂商。

## 边界

- 不要求家宽入站端口（设计为 Mac 出站）。
- 具体托管隧道（如 Cloudflare Tunnel）或自建转发服务选型可后置替换实现，保持信封不变。
