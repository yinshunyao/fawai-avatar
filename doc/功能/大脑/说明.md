# 大脑（v1）

## 验收

- 输入：用户目标 + 观察摘要（+ 可选工具清单）。
- 输出：结构化下一步（自然语言结论 + 控制动作列表 / 结束判定）。
- `status=success` 时的 `thought` 即给用户看的最终回答（勿贴原始命令输出）；查询类须先 `continue` 执行，再空 `actions` 收尾结论。
- 不直接调用键鼠或改系统状态。

## 边界

- v1 单任务执行脑；总管侧编排脑可后置为规则调度。
- 依赖 LLM 接入。
- 系统提示注入当前 OS（macOS/Linux/Windows），要求 shell 命令与平台匹配；shell 字段优先 `args.cmd`。
- 与 [完成任务](../完成任务/说明.md) 联动：注入能力清单；文件类目标禁止 GUI 代替（校验失败重规划 1 次）。
- 与 [守规约束](../守规约束/说明.md) 联动：命中规则注入；分层写须 `doc_refs` / `architecture_skip_reason`；原生/JSON 写均可按 path 自动绑定；架构重规划强制 JSON。
- 与 [编码闭环](../编码闭环/说明.md) 联动：探索进度闸门在改文件类目标连续只读时注入约束；规划前走 [规划历史窗](../编码闭环/说明.md)。
- 与 [执行反省](../执行反省/说明.md) / [步骤重复](../步骤重复/说明.md) 联动：失败先 `reflect`；同构成功步裁决须 grounded，已定位 path 时改写优先。
- 规划输出非 JSON（自然语言/空内容）：附加格式约束重规划 1 次；仍无法解析则 `failed`（避免偶发散文直接中断任务）。
- 与 [规划提示档](../规划提示档/说明.md) 联动：按本轮目的选 `vision`/`fs`/`gui`/`full`；`fs` 档卸用户图走文本模型；提示词能力清单可子集，硬校验仍全量。
