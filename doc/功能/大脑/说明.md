# 大脑（v1）

## 验收

- 输入：用户目标 + 观察摘要（+ 可选工具清单）。
- 输出：结构化下一步（自然语言结论 + 控制动作列表 / 结束判定）。
- 每轮规划须给出 **`step_label`（本步业务意图，≤16 字）**，与任务级 `title` 分开：`title` 命名整条任务，`step_label` 概括**本步**在办什么（如「查找转换脚本」）；缺省时由 `thought` / 动作种类兜底。闭环在 `planned` 前即可把 `step_label` 推到会话步骤簇头（见 [会话通道](../会话通道/说明.md)）。
- `status=success` 时的 `thought` 即给用户看的最终回答（勿贴原始命令输出）；查询类须先 `continue` 执行，再空 `actions` 收尾结论。
- 不直接调用键鼠或改系统状态。

## 边界

- v1 单任务执行脑；总管侧编排脑可后置为规则调度。
- 依赖 LLM 接入。
- 系统提示在平台事实之前注入**路径事实**：当前工作区根（可写）与只读根（`FAWAI_WORK_ROOT` / `FAWAI_READ_ROOTS` 的解析结果）。相对路径相对工作区根；写入不得越出工作区根；绝对路径读取须落在工作区根或只读根内。未另开只读根时写明「仅工作区」。不要把未配置的「默认整盘」当成当前只读根。
- 系统提示注入当前 OS（macOS/Linux/Windows），要求 shell 命令与平台匹配；shell 字段优先 `args.cmd`。
- 与 [完成任务](../完成任务/说明.md) 联动：注入能力清单；必要路径台账（含证据保真）；过程相位（定位→取证→改写/作答→验收）；文件类目标禁止 GUI 代替（校验失败重规划 1 次）。
- 与 [守规约束](../守规约束/说明.md) 联动：命中规则注入；分层写须 `doc_refs` / `architecture_skip_reason`；原生/JSON 写均可按 path 自动绑定；架构重规划强制 JSON。
- 与 [编码闭环](../编码闭环/说明.md) 联动：探索进度闸门在改文件类目标连续只读时注入约束；压缩未读禁宽搜；规划前走 [规划历史窗](../编码闭环/说明.md)。
- 与 [脚本铲子生命周期](../脚本铲子生命周期/说明.md) 联动：造临时脚本前 `shovel_search`；参数化；写后软提示升铲/Skill。
- 与 [执行反省](../执行反省/说明.md) / [观察反省](../观察反省/说明.md) / [步骤重复](../步骤重复/说明.md) 联动：失败先 `reflect`；成功工具结果后可 `obs_reflect`（软 hints）；同构成功步裁决须 grounded，已定位 path 时换指纹（exact old→patch），禁止把 alternate 收成强制写相位。
- 规划输出非 JSON / 半截 JSON（自然语言/空内容/截断）：先尝试修补半截 JSON；再附加格式约束重规划 1 次；仍无法解析则**软降级为 `continue` 空动作并回灌格式提示**，禁止以「无法解析 JSON」整任务 `failed` 中断。
- 误把 `obs_screen` / `obs_ax` / `obs_fs` / `none` / `screenshot` 写入 `actions[].kind` 时：规范化升格进 `observe_kinds` 并移出 actions（`raw._lifted_observe_from_actions`），禁止「未知 action.kind」整任务失败；提示词仍要求取证只写 `observe_kinds`。
- 与 [规划提示档](../规划提示档/说明.md) 联动：按本轮目的选 `vision`/`fs`/`gui`/`full`；`fs` 档卸用户图走文本模型；附图目标在已有工具回合后强制卸图（有图≠全程 VLM）；`planned` meta 带 `prompt_profile`/`attach_user_images`；提示词能力清单可子集，硬校验仍全量。
- 与 [主脑委派](../主脑委派/说明.md) 联动：配置了快模型时可输出 `delegate`（或原生 `delegate_to_fast`）；段内由快模型执行后摘要回灌，主脑再规划。
