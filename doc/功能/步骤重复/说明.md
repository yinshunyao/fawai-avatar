# 步骤重复

## 验收

- 成功动作步末用**步骤指纹**（动作指纹保序串联，可选附带观察方式）做零 LLM 判定。
- 同 run 内同步骤指纹累计 ≥ `N`（默认 2）→ 调 LLM 裁决 `continue` / `alternate` / `abort`；progress 出现 `phase=stagnation`。
- 对某步骤指纹已判决后再次撞上 → **代码直接 abort**，不再二次 LLM。
- 裁决 `constraints` 须 grounded；代码清洗丢掉「禁读已定位 path / 臆造 Vue·React src / 只能再读·继续盲读」等反证据或反进展约束；只读已定位时强制补「改写优先」。
- 「必须先 fs_read 再 patch」类约束收成「最多一次定向核对后立即 mutate」；alternate ≠ 已进入改写相位。
- 结果含 `stagnation_count`；mock 下连续同构成功步可止损，不烧满 `max_steps`。
- **不等于** [执行反省](../执行反省/说明.md)（失败路径）；**不等于** [任务复盘](../任务复盘/说明.md)。

## 边界

- 仅成功路径（本步动作全 `ok`）；失败仍走执行反省。
- 空动作步不计入。
- 不用 thought / 截屏路径作主指纹。
- 可用 `FAWAI_STEP_REPEAT=0` 关闭；`FAWAI_STEP_REPEAT_N` 调阈值（默认 2）。
