# 步骤重复

## 验收

- 成功动作步末用**步骤指纹**（动作指纹保序串联，可选附带观察方式）做零 LLM 判定。
- 同 run 内同步骤指纹累计 ≥ `N`（默认 2）→ 调 LLM 裁决 `continue` / `alternate`（**无 abort**）；progress 出现 `phase=stagnation`。
- 对某步骤指纹已判决后再次撞上 → **仍回灌大脑裁决**（带「判决后仍重复」上下文）；止损只由下一轮规划 `status=failed` 决定。
- **规划豁免（可选）**：本步 JSON 顶层或任一动作 `args` 设 `allow_repeat` / `skip_step_repeat` / `ignore_step_repeat` 为真 → **不累计指纹、不调 stagnation**（典型：刚 `fs_patch` 后同窗 `fs_read` 验收）。标识不进指纹；无新意图勿滥标。
- 裁决 `constraints` 须 grounded；代码清洗丢掉「禁读已定位 path / 臆造 Vue·React src / 只能再读·继续盲读 / 必须进入改写相位」等反证据或假状态约束。
- 只读已定位时补「换指纹」：小窗抄 exact old → 立即 patch，或换 pattern/工具；若本步仅有 `grep N` 无正文则先拿可复制正文——**不**把 alternate 收成强制写状态 / mutate_prefer 开关。
- 「必须先 fs_read 再 patch」类约束收成同一套换指纹公式；progress/cause/thought 中的「进入改写相位」措辞会被 scrub。
- 结果含 `stagnation_count`；mock 下同构成功步可触发回灌，大脑可中止，不烧满 `max_steps`。
- **不等于** [执行反省](../执行反省/说明.md)（失败路径）；**不等于** [任务复盘](../任务复盘/说明.md)。

## 边界

- 仅成功路径（本步动作全 `ok`）；失败仍走执行反省。
- 空动作步不计入。
- 不用 thought / 截屏路径作主指纹。
- 可用 `FAWAI_STEP_REPEAT=0` 关闭；`FAWAI_STEP_REPEAT_N` 调阈值（默认 2）。
- `allow_repeat` 只豁免**本步**；未带标识的后续同构步仍按 N 计数。
