# 版本管理

## 验收

- **快照**：对指定文件/目录打版本（写入前可自动）。
- **查询**：列出版本；按 id 查看清单与元数据。
- **删除**：按 id 删除历史版本（不可恢复该快照本身）。
- **回退**：将工作区文件恢复到指定版本内容。
- 纯后台，无 GUI。

## 边界

- v1 存于 `data/versions/`（拷贝快照）；不强制依赖 git。
- 回退只覆盖快照内记录的路径；不做整仓 git reset。
- 密钥目录与 `.env` 默认不入快照（目录快照与显式路径均跳过；可用 `demo_eval_priority` D6 回归）。
