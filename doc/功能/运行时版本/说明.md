# 运行时版本

## 验收

- Web 左侧 **服务与版本** 可**存档**当前 `fawai_avatar` 包代码（落在 `data/runtime_releases/`）。
- 可列表、删除存档；可**选取存档启动**（覆盖当前包目录并重启；激活前自动备份当前树）。
- 与工作区文件「版本管理」（`version_*` / `data/versions/`）**分离**：本功能管**产品代码**可回退启动。

## 边界

- 存档跳过 `.venv` / `.git` / `data` / `.env` 等；不替代 git。
- 激活会改写当前包目录；须经口令鉴权。
- 建议在服务保活下使用，以便激活后自动拉起。

## 实现映射

| 规范名 | 路径 |
|:---|:---|
| 运行时版本 | `fawai_avatar/runtime/releases.py` |
| API | `/api/runtime`、`/api/runtime/releases*`（`lan_gateway.py`） |
| Web 面板 | `fawai_avatar/channel/static/index.html`（`#opsPage`） |
