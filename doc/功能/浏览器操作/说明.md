# 浏览器操作

## 验收

- 内置 Playwright 浏览器工具：`browser_navigate` / `browser_snapshot` / `browser_click` / `browser_type` / `browser_press` / `browser_close`。
- **默认无头**（`FAWAI_BROWSER_HEADLESS=1`）；设 `0` 可见窗口。与 OS 是否 headless **无关**——Linux 无界面服务器仍可用。
- **不占** `foreground_lease`；勿用桌面 `click`/`ui_click` 点系统 Chrome 代替本能力。
- 流程：打开 URL → `browser_snapshot` 得编号 `ref` → 按 `ref` 点击/键入；可选 `browser_press` / `browser_close`。
- 受 `FAWAI_DRY_RUN`：干跑不真开页。
- 未装依赖时能力清单标不可用，并提示 `pip install -e '.[browser]'` + `playwright install chromium`。

## 边界

- 不做：任意桌面 App 点准、系统 Chrome 外壳 AX、OCR/VLM 点坐标主路径。
- 不做：多标签编排 API、扩展商店、自动登录管家（登录态可后续加 `user_data_dir`）。
- 单进程单页会话；`browser_close` 释放。

## 环境变量

| 变量 | 默认 | 含义 |
|:---|:---|:---|
| `FAWAI_BROWSER_HEADLESS` | `1` | 无头；`0` 有头 |
| `FAWAI_BROWSER_CHANNEL` | 空 | 可选 `chrome` / `msedge` 等 Playwright channel |
| `FAWAI_BROWSER_TIMEOUT_MS` | `30000` | 导航/动作超时 |
