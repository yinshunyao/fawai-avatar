# 步级执行档

## 验收

- 会话 compose **模式**面板内有 **分档** 开关；默认关；本机记住；与极速/全力/计划模式解耦。
- [执行配置自动模式](../执行配置自动模式/说明.md) 下：非简单（含中档）自动开分档（未锁定时）。
- 发送/追问/追加/附图入站可带 `meta.step_tier`；写入任务 `meta.step_tier`（bool）；计划子任务继承。
- **分档开**：规划提示要求同轮写 `step_run`；闭环按档分流观察反省。
- **分档关**：提示不提 `step_run`；闭环忽略该字段，走现网默认（机械成功可跳过 / 否则完整反省）。
- 规划 JSON `step_run`：`reflect` | `brief` | `act`（别名 `execution` / `run_mode`）；与 `actions` 同轮写出。
- **`reflect`**：完整观察反省 LLM。
- **`brief`**：短观察反省（短提示、关思考、thought≤40）。
- **`act`**：规则检查；通过则 `skipped_act`（规则摘要入 history，**不推**「观察反省：跳过」进度卡）；不过升 `brief`。
- 失败仍走执行反省；任务 `meta.fast` 仍整单跳过观察反省（亦不推跳过卡）。
- 实际跑观察反省时，进度 facts / 规划文案可显示执行档中文标签。

## 边界

- 不等于任务级 Fast；不等于 `step_kind`；不等于主脑委派快模型角色。
- 不做规划后再评难度的第二轮 LLM。
- `finalize`/交稿是否强制 `reflect` 由模型自选；系统不硬改字段。
