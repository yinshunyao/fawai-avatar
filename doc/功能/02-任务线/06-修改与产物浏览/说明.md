# 修改与产物浏览

## 验收

### Diff 审阅

- 写后步骤卡展示路径、`+n/-m`、按 hunk 折叠的着色 unified diff。
- 大补丁截断时可「展开全文」（拉完整 diff，不依赖气泡塞满）。
- 本任务有改动文件清单入口，点击定位对应 diff 卡。
- `FAWAI_DIFF_MODE=confirm` 时卡上「接受 / 拒绝」按钮可用；口令「确认补丁 / 拒绝补丁」仍有效。

### 产物预览

- `.md`：预览用 Markdown 渲染（非纯 `<pre>`）。
- 图 / 音视频 / PDF：页内原生预览（既有）。
- pptx / docx / xlsx：优先打开主机生成的 `.preview.html`（或可用时的 `.preview.pdf`）；失败则摘录并提示仅摘录。
- 跨端：投影与原件均经 `/media`；另存仍下原件。

## 边界

- 不对齐 IDE 内联编辑 / 按 hunk 接受 / 左右分栏。
- 投影非像素级 Office；无 LibreOffice 时不做 PDF 投影。
- 不推翻既有「任务产物交付」落点与附件卡。

## 自检

.venv/bin/python -m fawai_avatar.demo_file_deliver
.venv/bin/python -m fawai_avatar.demo_diff_browse
