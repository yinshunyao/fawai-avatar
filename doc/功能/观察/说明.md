# 观察

## 验收

- 按**观察方式**采集状态并产出 LLM 可读摘要（不限于截屏）。
- **LLM 同调**输出 `observe_kinds` + `actions`：本步动作只依赖已采环境观察与上轮工具结果；`observe_kinds` 经硬闸门裁候选后用于**下一步**环境观察。**`obs_*` / `none` 禁止写入 `actions[].kind`**；若模型误放，规划规范化会升格进 `observe_kinds` 并移出 actions，避免「未知 action.kind=obs_screen」整任务失败。
- **步 0 / 无点选默认**：结构化目标 → `obs_fs`；其余（含 GUI）→ **`none`（不默截屏）**。候选仍可含 `obs_screen`，由计划点选后再截。
- **结构化闸门**：用「写/读/打开文件、工作区、源码…」等**完整意图词**判定；禁止裸「文件」子串（会误伤 GUI 会话名如「文件传输助手」，把点选的 `obs_screen`/`obs_ax` 静默降成 `obs_fs`）。
- **文档 / 附图内容**：目标是在读文档、图片文件或用户附图，且没有明确要求看或操作当前桌面时，候选去掉 `obs_screen` / `obs_ax`，步 0 为 `none`。模型点选截屏也会被丢掉。要点截屏或操作界面（截屏、屏幕上、点击等）时仍保留截屏候选。
- **步骤分类**：上一段 `act_serial` / `act_parallel` / `analyze` / `finalize` 后，若未显式点选 `obs_screen`/`obs_ax`，下一步强制 `none`（不刷浅 `obs_fs`）；见 [步骤分类与执行流](../步骤分类与执行流/说明.md)。
- **前台窗摘要**：真实取证步（`obs_fs` / `obs_screen` / `obs_ax` 等）附加廉价前台 App/窗口标题（`meta.frontmost_*`）；失败可降级，不崩闭环。macOS 用 osascript；Linux 有桌面尽力 xdotool；headless / 未支持 OS 写明不可用。**`none` 真跳过：不探前台。**
- **`none` 真跳过**：方式仅为 `none` 时不截屏、不采工作区、不探前台、**不推** `phase=observe` 进度（会话时间线不展示「观察完成（跳过）」），规划侧只收空壳观察（含 `observe_candidates` / 任务标题上下文）。需要画面或控件树须点选 `obs_screen` / `obs_ax`。
- **工具结果观察（`obs_tool`）**：动作返回后回灌规划。中等体量默认全文（`SOFT`/`HITS_SOFT`=0）：`fs_read` 读多少回灌多少；`fs_grep` hits 全文展开（须含 `path:line`），禁止只留「grep N」。**绝对上限** `FAWAI_TOOL_OBS_MAX_CHARS`（默认 48000）：超则强制头+尾压缩并落盘，避免千万字符灌进 history。`shell` 源端另有 `FAWAI_SHELL_MAX_STDOUT_CHARS`（默认 120000，头+尾截断）。大文件取证常态是头/尾/中间起行（`head`/`tail`/`sed -n`、`fs_read offset/limit`），不是整文件 `cat`。显式 `SOFT>0` 时中等体量也按 soft 压。
- 进度文案区分环境观察与工具结果观察（如「观察中（工作区文件）…」「观察工具结果…」），禁止写死「观察截图」。**实际取证的环境观察与工具结果观察完成态均须把摘要正文附进 progress**（环境：`obs.summary`，含前台窗摘要；工具：hits/stdout 等），不得只写空标签。**`none` 不发观察进度卡**（真跳过≠空标签卡）。
- 不修改系统状态（只读取证；落盘原文不算副作用业务写）。
- **窄场景回证**：截图可用；写文件后可做文件态回证；GUI 键入后可做 **AX 界面回证**（见 [自主操控](../自主操控/说明.md)）。

## 观察方式

| 方式 id | 界面名 | 何时用 |
|:---|:---|:---|
| `obs_fs` | 工作区文件 | 结构化/产品改码类**步 0 默认**；LLM 可点选 |
| `obs_ax` | AX 控件树 | macOS 有桌面候选；LLM 点选；产出 `ref`+bounds；headless/非 Darwin 失败摘要 |
| `obs_screen` | 截屏 | 候选含此项且 **LLM 点选**；步 0 **不**默认；`capture=False` 或 **headless** 剔除 |
| `none` | 跳过 | GUI/非结构化步 0 默认；`capture=False` 或模型显式跳过；**真跳过**（无前台探测、无观察进度卡） |
| `obs_tool` | 工具结果 | 每步动作后自动；非环境观察候选 |

硬闸门只**裁候选 / 定步 0 默认**；候选内选取以计划里的 `observe_kinds` 为准。

## 前台窗摘要字段

| meta 键 | 含义 |
|:---|:---|
| `frontmost_ok` | 是否取到前台 |
| `frontmost_app` | 前台 App 名（或 Linux comm） |
| `frontmost_window` | 窗口标题（可空） |
| `frontmost_reason` | 失败原因：`headless` / `xdotool_missing` / `unsupported_os` / `timeout` 等 |
| `frontmost_platform` | 探测时的 OS |

## 边界

- macOS **AX** 控件树已落地为 `obs_ax`。截屏像素接地见 [截屏识别接地](../截屏识别接地/说明.md)：可配 `vlm` 附图或 `ocr` 出框表（默认 `vlm`）。
- 截屏：macOS 优先 `mss`，失败回落 `screencapture`；其它有显示环境用 `mss`（需 `[gui]` extras）。无界面直接失败摘要，不崩闭环。多屏见 [多屏与全屏观察](../多屏与全屏观察/说明.md)：`displays` + `screen_target`（默认 `frontmost`）+ 截图 `origin_x/y`。
- 前台窗摘要不是截屏，也不自动激活目标 App（激活用 `app_focus`）。仅挂在真实取证观察上；`none` 不挂。
- 工具原文可落 `data/observe/tool_*`；history 只收摘要 + 路径。
- Windows：前台探测本切片标未支持（降级说明），不假装成功。
