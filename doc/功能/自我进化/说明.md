# 自我进化（C4）

## 验收

- **E1**：`skill_write` 经质量门入库；`skill_search` 可检索（**imitate/avoid 极性分栏**，见 [成败经验与检索极性](../成败经验与检索极性/说明.md)）；规划提示可注入 Skill 摘要（分栏）。启动时把 `fawai_avatar/skills/builtin/*.json` 拷到 `data/skills`（已存在不覆盖），含假成功教训 `lesson_write_set_not_acceptance`、`lesson_answer_must_cover_goal`。
- **E1 终态条件蒸馏（默认开）**：任务 `completed`/`failed` 时，若命中「多法成功」或「已明确失败」启发式，自动蒸**一张短卡** → 成功/失败价值台账 → 三维过门后写 lore；**禁止**整段轨迹灌库；已有 `lore_id` 则跳过。短卡 `acceptance`/`symptom` 等须为人读短句（禁止 `true`/`false`）；lore 标题由 `brain/ledger_title.py` 总结。开关在 Web「记忆配置」：`FAWAI_TASK_DISTILL`（只存 `memory_settings.sqlite`，**不写 .env / 不 sync 进进程 env**）。见 `brain/task_distill.py`。
- **E2 禁改（仅本产品智能体）**：经 `fs_*` / WorkspaceFs 写入下列路径 → 拒绝；**Cursor / 人工直接改盘不受限**。
  - `fawai_avatar/versioning/**`
  - `fawai_avatar/runtime/releases.py`、`keeper.py`、`code_watch.py`、`reload_gate.py`、`port_guard.py`
  - `fawai_avatar/workspace/paths.py`（闸门自身）
  - `doc/版本/v*/` 下**已存在**归档
  - `.env`（默认）
- **E2 可改**：当前树其它路径可 `fs_write`/`fs_replace`/`fs_patch`；写已存在文件时自动 `version_snapshot`（`FAWAI_AUTO_VERSION`）。
- **E2 升版**：可**新建** `doc/版本/v{新}/评测结果.md`；旧归档正文保持不变。
- 用例见 `demo_c4`（mock）。

## 边界

- 不做 C3 GUI 接地。
- **仍不做**：整段轨迹默认灌 lore、默认全自动棘轮、默认自动 `skill_write`（Skill 仍按需/`skill_write`；深度复盘见 [任务复盘](../任务复盘/说明.md)）。
- **条件蒸馏 ≠ 棘轮**：只补漏短卡进知识库；执行中仍可 `success_ledger_upsert`。
- 禁改尺子：弄坏则无法从坏进化自救（工作区回退 + 产品选版回退 + 外层保活 + 闸门元规则 + 评测真源）。
- 仍可**调用** `version_*` / 运行时选版 API；只禁智能体改其实现文件。
- Skill 首期规则入库（字段校验），不强制人审。
- 文件类目标仍走 C2：`fs_*` / `version_*` / `skill_*`，禁止 GUI 代替。

## P0 默认（放行时钉死）

| 项 | 默认 |
|:---|:---|
| Skill 路径 | `{FAWAI_DATA_DIR}/skills/*.json` |
| Skill 字段 | `id` / `title` / `when_to_use` / `steps` / `tags` / `source` / `created_at` |
| 智能体黑名单 | 上表最少核前缀/精确文件；`doc/版本/v…` 已存在则拒写 |
| 人工 / Cursor | **不走**本闸门；可改任意路径 |
| E1 写入 | 规则通过即入库 |
| 工具 id | `skill_search` / `skill_write` / `skill_get` |
