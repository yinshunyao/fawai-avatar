# 自我进化（C4）

## 验收

- **E1**：`skill_write` 经质量门入库；`skill_search` 可检索；规划提示可注入 Skill 摘要。启动时把 `fawai_avatar/skills/builtin/*.json` 拷到 `data/skills`（已存在不覆盖），含假成功教训 `lesson_write_set_not_acceptance`、`lesson_answer_must_cover_goal`。
- **E2 禁改（仅本产品智能体）**：经 `fs_*` / WorkspaceFs 写入下列路径 → 拒绝；**Cursor / 人工直接改盘不受限**。
  - `fawai_avatar/versioning/**`
  - `fawai_avatar/runtime/releases.py`、`keeper.py`、`code_watch.py`、`reload_gate.py`、`port_guard.py`
  - `fawai_avatar/workspace/paths.py`（闸门自身）
  - `doc/版本/v*/` 下**已存在**归档
  - `.env`（默认）
- **E2 可改**：当前树其它路径可 `fs_write`/`fs_replace`/`fs_patch`；写已存在文件时自动 `version_snapshot`（`FAWAI_AUTO_VERSION`）。
- **E2 升版**：可**新建** `doc/版本/v{新}/评测结果.md`；旧归档正文保持不变。
- 用例见 `demo_c4`（mock）。

## 边界

- 不做 C3 GUI 接地。
- **不做**任务完成时默认自动蒸馏 / 默认全自动棘轮（耗资源；按需复盘见议题 [任务复盘与管理](../../议题/任务复盘与管理/结论.md)）。
- 禁改尺子：弄坏则无法从坏进化自救（工作区回退 + 产品选版回退 + 外层保活 + 闸门元规则 + 评测真源）。
- 仍可**调用** `version_*` / 运行时选版 API；只禁智能体改其实现文件。
- Skill 首期规则入库（字段校验），不强制人审。
- 文件类目标仍走 C2：`fs_*` / `version_*` / `skill_*`，禁止 GUI 代替。

## P0 默认（放行时钉死）

| 项 | 默认 |
|:---|:---|
| Skill 路径 | `{FAWAI_DATA_DIR}/skills/*.json` |
| Skill 字段 | `id` / `title` / `when_to_use` / `steps` / `tags` / `source` / `created_at` |
| 智能体黑名单 | 上表最少核前缀/精确文件；`doc/版本/v…` 已存在则拒写 |
| 人工 / Cursor | **不走**本闸门；可改任意路径 |
| E1 写入 | 规则通过即入库 |
| 工具 id | `skill_search` / `skill_write` / `skill_get` |
