# 成败经验与检索极性

## 验收

### 必要（按优先级先后）

- **`skill_search` 极性分栏**：命中分为 `imitate`（可参考）与 `avoid`（勿当正例照抄）；`lesson` / `failure` / id 前缀 `lesson_` → avoid；`success` / 普通 skill → imitate。结果与 message 明示 polarity、tags、source。
- **规划 Skill 摘要**：`skills_prompt_block` 分栏展示；avoid 条目不得被当成成功步骤骨架。
- **铲子运行成败维**：`shell` 调用命中 `fawai_shovels/`（或 `FAWAI_SHOVELS_ROOT`）路径时记账（ok/fail 计数、近失败一句）；与文首设计态三维分（完备/通用/效率）并列，**禁止混用**。
- **`shovel_search` 展示成败维**：每条 hit 带 `outcome.rate`（`good`/`mixed`/`poor`/`unknown`）及近失败一句；message 摘要差评条目。
- **管理页手工编辑**：PWA「技能工具 → 工具」可改成功/失败次数与近失败一句（`set_outcome`）；档位由计数自动算；设计三维分另栏可改。
- **选型软闸【成败对照】**：本步 `shell` 调用 `poor`（或同槽近失败的 `mixed`）铲时，注入一次软闸重规划（`FAWAI_SHOVEL_OUTCOME_GATE=0` 可关）；禁止无视差评原样照抄 invoke。
- 冒烟：`python -m fawai_avatar.demo_outcome_polarity`

### 可选（可砍）

- `poor` 原样复用硬拒（默认关）。
- 任务终态经验卡 / 跨任务 `recall_search`（见分析文，本切片不做）。

## 边界

- 不给内置工具（`fs_*` / `shell` 本身）打全局生死分。
- 不做任务结束默认自动蒸馏完整 Skill。
- 设计态三维分仍只表示「写得怎样」；运行成败维才表示「用起来怎样」。

## 环境变量

| 变量 | 默认 | 含义 |
|:---|:---|:---|
| `FAWAI_SHOVEL_OUTCOME_GATE` | `1` | 差评铲照抄前【成败对照】软闸 |
