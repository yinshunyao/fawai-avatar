# Fast

## 验收

- 会话 compose **模式**面板内有 **极速** 开关；默认关；本机记住上次选择。关态悬停不得变绿（盖过全局 `button:hover`）。
- 发送/追问/追加/附图入站可带 `meta.fast`；写入任务 `meta.fast`（bool）。
- **Fast 开**：主脑/执行反省/步骤重复 LLM 强制 `enable_thinking=false`；成功路径跳过观察反省 LLM（`skipped_fast`，**不推观察反省进度卡**）；建卡后跳过编排复杂度判定，强制单 Worker（不进计划模式）。
- **Fast 关**：深度思考与观察反省、计划模式按既有角色/环境默认。
- 与 **Effort（全力）**、**分档（step_tier）** 解耦：可各自开/关，互不强制关掉对方。
- 开 Fast **不**换模型、**不**关写租约 / shell 禁绕过 fs / 取消等硬闸；失败路径仍可走执行反省（仅关思考）。
- 可由 [执行配置自动模式](../执行配置自动模式/说明.md) 在简单任务上自动打开（未锁定时）。

## 边界

- 不等于主脑委派的快模型角色（`planner_role=fast` / `route_role=fast`）。
- 不等于 Effort；不等于改 `FAWAI_PLAN_MODE` / `FAWAI_OBS_REFLECT` 环境变量。
- 首期仅布尔开/关。

## 实现映射

| 规范名 | 路径 |
|:---|:---|
| Fast | `fawai_avatar/brain/fast.py` |
| 入站 | `channel/hub.py`（`_fast_meta_from_inbound` / `_effort_fast_meta_from_inbound`）；`lan_gateway` upload `fast` |
| 计划模式 | `_finish_create_orchestrate`：`meta.fast` 时跳过 `decide_complexity`；进图 bootstrap / 监管子任务继承 `fast` |
| 闭环 | `runtime/loop.py`（`_task_fast` → plan 关思考 / 跳过 obs_reflect） |
| 提示 / 思考 | `brain/{planner,reflect}.py`；`llm/thinking.py` 显式 `enable_thinking=False` |
| UI | `channel/static/index.html` `#modePop` / `#fastSwitch`；`i18n/{zh-CN,en}.json` |
