# 服务保活

## 验收

- 默认入口 `fawai-gateway` / `python -m fawai_avatar.channel.lan_gateway` **经外层保活**拉起会话网关；子进程崩溃后自动重拉（带退避）。
- Web 左侧 **服务与版本** 可一键**重启服务**；保活开启时外层立即再起。
- 网关进程再起后自动 [进程中断续跑](../进程中断续跑/说明.md)（按检查点续跑孤儿任务；`paused` 不自动拉）。
- **代码热重载**（默认开）：监视 `fawai_avatar/` 下 `.py` / `.html` / `.js` / `.css` 变更，防抖后**发信号停子进程**，由外层主循环 `wait` 收尸并立即再起（类似 Django `runserver`）。监视线程不得把 `child` 引用清掉，否则后续变更会变成空操作。不监视 `.env`、`data/`、存档等。关：`FAWAI_CODE_RELOAD=0`。改的是外层 `keeper` 自身时，热重载**不会**更新外层，需手动重启入口进程。
- **端口回收**（默认开）：每次拉起网关前检查 `FAWAI_GATEWAY_PORT`；若被**本产品**野进程（残留 `lan_gateway` / 其保活外层、ppid=1 孤儿）占用则结束它们再启。非本产品占用只告警并退避重试，不杀。关：`FAWAI_PORT_RECLAIM=0`。
- **后台日志**：子进程 stdout/stderr tee 到终端 + `data/runtime/console.log`；异常退出摘 traceback 写 `data/runtime/last_crash.log`。Web「服务与版本」可刷新查看；`GET /api/runtime/console-logs`。
- **启动降级**：组件（如系统日志库）初始化失败时网关**仍起服**，对话/任务等基本功能可用；界面标降级，引导看后台日志。
- **一键修复启动错误**：`POST /api/runtime/repair-startup`；按崩溃摘录自动建整改任务（目标/要求/边界）并开跑 Worker。
- 调试可关保活：`FAWAI_NO_KEEPER=1`（或子进程内已是 `FAWAI_KEEPER=1` 时不再套娃）。无保活时无代码热重载、无端口回收。
- 亦可直接跑：`fawai-keeper` / `python -m fawai_avatar.runtime.keeper`。

## 边界

- 保活只保证**本机进程**存活，不替代系统级 launchd/systemd（可再挂一层）。
- 无保活时 Web 重启会退出进程，需手动再启；无保活时也可能无完整 crash 落盘（仍有网关自身 console 落盘）。
- 代码热重载会中断进行中的任务；实操长任务时可临时 `FAWAI_CODE_RELOAD=0`。
- 端口回收**不会**结束无关软件（如其它服务占用 7980）；需改端口或手动停掉对方。
- 与工作区「版本管理」（文件快照）无关；选版启动见 [运行时版本](../运行时版本/说明.md)。
- 一键修复不替代人工定位；遵守自我进化最少核禁改路径。

## 实现映射

| 规范名 | 路径 |
|:---|:---|
| 服务保活 | `fawai_avatar/runtime/keeper.py`；控制台时间戳/落盘 `runtime/console_log.py` |
| 代码热重载 | `fawai_avatar/runtime/code_watch.py` |
| 端口回收 | `fawai_avatar/runtime/port_guard.py`（`reclaim_gateway_port`） |
| 重启 API | `POST /api/runtime/restart`（`lan_gateway.py`） |
| 后台日志 | `GET /api/runtime/console-logs`；PWA `#consoleLogView` |
| 一键修复启动 | `channel/startup_repair.py` + `hub.start_startup_repair`；`POST /api/runtime/repair-startup` |
