# 执行反省

## 验收

- 动作失败后先走 `Brain.reflect`，再决定是否重规划；progress 出现 `phase=reflect`。
- 同批若前序只读失败、后续只读仍执行：反省仍按「任一条失败」触发，但观察里应已带上已跑完的只读结果（见 [编码闭环](../编码闭环/说明.md)「同批只读继续」）。
- 裁决仅为 `retry` / `alternate`；**不再** `abort`。任务终态只由规划 `status=success|failed`（或步数用尽）收口。
- 模型若仍输出 `abort`：代码收成 `alternate`，并注入「下一轮须 `status=failed`」约束（`coerce_reflection_no_abort`）。
- 同指纹失败 ≥2 强制换道；≥3 或 alternate 后仍同指纹 → 仍 `alternate` + 提示规划 `failed`，**不**由反省直接 `supervisor.fail`。
- 结果含 `reflect_count`；mock 下缺文件类失败 → `alternate` 后可换道成功；权限/租约类 → `alternate` + 提示规划 `failed`。
- **反省开读（已退役）**：不再因 cause 含 `fs_read` 等字样注入禁定位硬闸；失败后仍可 `fs_glob`/`fs_grep` 纠路径。补丁核对靠失败回执原文小窗与规划自律，不靠「开读须改写」禁搜。
- **步骤未捕获异常**（观察/规划/执行/回证等）：闭环捕获 → 合成 `step_runtime` 失败 → 同样走反省；能继续则 `alternate/retry` 重规划；步数用尽才失败；`reflection.trigger=step_crash`。
- **沙箱越界 grounded**：读失败时优先改用 `FAWAI_READ_ROOTS` 下绝对路径 `fs_read` 或 work_root 相对 / `data/observe`；代码侧清洗「用 shell cat 绕过沙箱」类 constraints（`ground_reflect_constraints`）；执行层硬拦本地 cat/cp 绕过。
- **not found grounded**：`file missing` ≠ 沙箱越界；清洗「禁止再 fs_read 绝对路径 / 必须只许 fs_glob」类反证据约束。注入正道须跟工具文案分流：已写「父目录存在/仅文件名缺失」→ 换其它落点或 `fs_glob` 看父目录，勿纠拼接、禁止同 path 空读；仅「目录也不存在」或相对路径可疑时才提示拼对路径 / `fs_grep` basename / hits 绝对 path / `fs_glob` 传 `path`。若 cause 误写越界/沙箱则改写。
- **failed 交付**：规划 `failed` 且约束要求输出本地命令时，终稿须带上 cause + 建议步骤（`format_abort_delivery` 仍可用于拼装命令要点），禁止只留一句错误。
- **必要路径台账**：`alternate`（含步骤重复）追加台账约束，禁止把恢复收成「只攻一条未决路径」；与 [完成任务](../完成任务/说明.md) 收尾闸配合。
- **方法族换道**：SSH 口令/公钥认证失败不得判成租约类终态；须 `alternate` 并注入带密 shovel 约束（`method_recovery`）；反省后 history 可追加 `【方法换道】`。
- **远端进度闸（默认关）**：部署/升级/同步类目标连续只读无远端副作用时，**默认不注入**。仅显式 `FAWAI_REMOTE_IDLE_GATE>0` 才注入换道；中止线默认 `FAWAI_REMOTE_IDLE_ABORT`，未设时为闸值的 2 倍。达中止线先强制 shovel/临时脚本一轮，仍无成功副作用则 failed 并交命令。闸门关闭时，历史里已有的【远端进度闸门】/【远端方法强制】不再送进下一轮规划。SSH 认证失败的方法族换道不依赖本闸。
- **远程不在场**：澄清/追问命中「没在电脑边/你想办法」→ 注入 `【远程操作约束】`，禁止再要粘贴配置。
- 检查点 / 统计 / 事件落盘失败为**软失败**（打日志），不直接打崩整任务。
- **不等于** [任务复盘](../任务复盘/说明.md)（终态用户触发蒸馏）。
- **不等于** [观察反省](../观察反省/说明.md)（成功工具结果后的软小结；本步失败走本功能时不叠跑）。

## 边界

- 失败路径含动作失败与步骤运行时异常；成功同构空转见 [步骤重复](../步骤重复/说明.md)。
- `old not found` 文案 ≠ 根因终态：先查 hunks 类型、path 是否存在、mutate 面是否挡住补读。
- 不鼓励无目标盲读；也不因反省文案禁掉重新定位。
- 不做多假设并行试跑；不做 GUI 接地级根因。
- 不自动触发 Skill 蒸馏。
- 枢纽侧 Worker 线程总崩溃收口见 [会话通道](../会话通道/说明.md)（仍须 `fail`+终态卡）；本功能尽量让异常在步内消化。
- 探索/定位/远端等**实验性硬闸**若显式开启，仍可能在强制改写轮后由闭环 `failed`（与反省 abort 无关）；默认关。

## 实现映射

| 规范名 | 路径 |
|:---|:---|
| 执行反省 | `fawai_avatar/brain/reflect.py` |
| 无 abort 收口 | `reflect.coerce_reflection_no_abort` + `apply_fingerprint_guard` + `runtime/loop.py` |
| 必要路径台账 | `fawai_avatar/brain/necessary_paths.py` |
| 沙箱绕过 / not found 清洗 | `reflect.ground_reflect_constraints` / `is_shell_bypass_fs_constraint` / `is_ban_absolute_fs_read_constraint` / `is_force_glob_only_constraint` |
| 方法族换道 / 远端闸 | `brain/method_recovery.py` + `runtime/loop.py` |
| 反省开读（已退役） | `reflect.reflection_needs_verify_read` / `explore_progress.history_requests_verify_*` 恒 False；闭环不再注入 |
| 大脑（reflect 入口） | `fawai_avatar/brain/planner.py::Brain.reflect` |
| 工作任务闭环接线 | `fawai_avatar/runtime/loop.py::WorkerLoop` |
