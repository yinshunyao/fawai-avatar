# 执行反省

## 验收

- 动作失败后先走 `Brain.reflect`，再决定是否重规划；progress 出现 `phase=reflect`。
- 裁决为 `retry` / `alternate` / `abort`；`abort` 直接任务失败，不空转烧步。
- 同指纹失败 ≥2 强制换道或止损；≥3 或 alternate 后仍同指纹 → abort。
- 结果含 `reflect_count`；mock 下缺文件类失败 → `alternate` 后可换道成功。
- **已写入 + 参数格式失败**：若 `write_set` 非空且失败像 `requires path` / `requires hunks` / 嵌套 args 结构错误，指纹守卫即便裁决 `abort`，闭环也会软降为 `alternate`（每 run 至多一次，`softened_format_abort`），注入「参数须扁平」约束后重规划；禁止把格式噪声当成整任务终态失败。
- **反省开读**：`alternate`/`retry` 且 cause/constraints 要求核对原文（如 `old not found`、截断锚点、缺 path）时，闭环追加 `【反省开读】`，规划侧在写工具面临时放行定向只读；禁止 mutate 面与「必须先读」约束互锁后空 actions `failed`。
- **步骤未捕获异常**（观察/规划/执行/回证等）：闭环捕获 → 合成 `step_runtime` 失败 → 同样走反省；能继续则 `alternate/retry` 重规划，不能则 `abort`；`reflection.trigger=step_crash`。
- 检查点 / 统计 / 事件落盘失败为**软失败**（打日志），不直接打崩整任务。
- **不等于** [任务复盘](../任务复盘/说明.md)（终态用户触发蒸馏）。

## 边界

- 失败路径含动作失败与步骤运行时异常；成功同构空转见 [步骤重复](../步骤重复/说明.md)。
- 格式失败软降不覆盖语义失败（如 `old not found`、租约冲突）；`write_set` 为空时仍可 abort。`old not found` 文案 ≠ 根因终态：先查 hunks 类型、path 是否存在、mutate 面是否挡住补读。
- 反省开读只开近窗定向只读，不长期关闭探索闸门；不鼓励无目标盲读。
- 不做多假设并行试跑；不做 GUI 接地级根因。
- 不自动触发 Skill 蒸馏。
- 枢纽侧 Worker 线程总崩溃收口见 [会话通道](../会话通道/说明.md)（仍须 `fail`+终态卡）；本功能尽量让异常在步内消化。
