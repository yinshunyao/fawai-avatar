# 语音输入

## 验收

- 会话对话框有麦克风按钮：点一下开始录音，再点停止并识别；`Esc` 取消。
- 录音经网关 `POST /api/transcribe`（口令鉴权）调用 ASR，识别文本**填入输入框**（可改后再发），**不**直接建任务。
- ASR 复用 `FAWAI_LLM_BASE_URL` / `FAWAI_LLM_API_KEY`；模型默认 `FAWAI_LLM_ASR_MODEL=qwen3-asr-flash`（OpenAI 兼容 `input_audio`）。
- 前端编码为 WAV 上传；服务端落盘 `session_media/in_audio_*` 便于排错；上限约 8MB / 60s。
- macOS / Linux 网关均可转写（无本机麦克风依赖）；录音发生在浏览器端。

## 浏览器安全上下文（开麦）

浏览器规定：`getUserMedia`（网页直接开麦）只在**安全上下文**可用：

| 访问方式 | 能否网页开麦 | 语音输入怎么用 |
|:---|:---|:---|
| `https://…` | 能 | 点麦克风录音 |
| `http://localhost` / `127.0.0.1` | 能 | 同上 |
| `http://局域网IP` / `http://公网IP`（当前 frp 默认） | **不能** | 点麦克风 → **选已录好的音频文件**再转写 |

这是浏览器策略，后端 ASR 本身不区分 HTTP/HTTPS。

**要网页直接开麦时**：用 HTTPS 打开页面（本机网关挂 TLS，或 frp/反代终止 TLS）；开发机也可用 `localhost`。  
**局域网 HTTP 不改证书时**：用系统录音机录一段，点麦克风选文件即可（已支持）。HTTPS 下长按麦克风也可选文件。

## 边界

- **不做**把原始 `audio` 信封直接当任务目标；首期只转写为文本再走现有 text 入站。
- **不做**实时流式字幕 / 按住说话专用手势（可后续加）。
- **不做**本机离线 Whisper；未配置密钥时接口返回可行动错误。
- **首期不做**网关自签 HTTPS / frp TLS 终止（开麦要 HTTPS 时另开切片）。
- headless 服务器无麦不影响能力：麦在用户设备浏览器。
