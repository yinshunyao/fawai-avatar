# 自主操控（C3 窄场景）

## 验收

- **TextEdit 闭环**：`app_focus` → `obs_ax` → `ui_click`/`ui_type`（按 `ref`）写入约定串 → `verify_ui_ax` 断言 AX 含该串。
- 前台 GUI 须持有 `foreground_lease`；`FAWAI_DRY_RUN` 不真点键鼠。
- 桌面操控目标不得因 `fs` 提示档被剔除 GUI 能力（见 [规划提示档](../规划提示档/说明.md)）。
- headless / 非 Darwin：`obs_ax` 失败摘要，不崩闭环；键鼠仍走既有 GUI 闸门。
- AX 依赖缺失或采集失败时，`ui_verify` / 键入后回证须报 **「ui_ax 不可用：…」**，禁止空树冒充「未找到某串」；安装提示须带当前解释器 `python -m pip install -e '.[gui]'`（含 `ApplicationServices`）。

## 边界

- 首切片仅钉 **macOS 文本编辑**；不承诺 Cursor/Electron 控件级点准；`ui_verify` 不做 OCR/VLM（`method=ocr` 硬失败）；不做手机。
- 改工作区文件仍须 `fs_*`，禁止 GUI 代写。
- 坐标 `click`/`type`/`hotkey` 保留为兜底；控件级优先 `ui_*` + `ref`。
- **`ref` 纪律**：须为最近 `obs_ax` 表中的**数字编号**；禁止臆造 `chat-input-field` 一类 DOM/语义 id。控制层会对非编号串做 title/role 模糊匹配，匹配失败时错误信息会列出可用 ref。
