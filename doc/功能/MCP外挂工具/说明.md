# MCP 外挂工具

## 验收

- 用户在 PWA `#extPage`（表 Tab：MCP）配置 stdio MCP server（id / command / args / env / cwd / enabled）；左侧查询、右侧配置。
- `POST /api/mcp/servers/{id}/refresh` 拉起进程并缓存 tools；能力清单合并动态项：`action_kind=mcp__{server_id}__{sanitized_tool}`。
- 规划可调用上述 kind；`Controller` 分发到 MCP `call_tool`，结果回灌观察。
- 禁用 server 后其 tools 从 available 清单消失；无配置时行为与未接入 MCP 时相同。
- 仅 stdio；依赖官方 `mcp` SDK（主依赖；若环境无预编译 wheel 需自行解决 cryptography 等构建）。
- 冒烟：`python -m fawai_avatar.demo_mcp`（无 SDK 也可测注册表/动态能力）。

## 边界

- 不做 SSE/HTTP MCP、resources/prompts、上传可执行插件、铲子台账 UI。
- MCP 为用户本机信任子进程（与 shell 同级风险）；不自动联网安装 server。
