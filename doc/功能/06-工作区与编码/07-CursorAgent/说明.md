# Cursor Agent

## 验收

### 必要（按优先级先后）

1. **独立菜单**：侧栏「Cursor Agent」单独页；不放进「模型配置」供应商组。
2. **登录认证**：浏览器登录 Cursor（Node `@cursor/sdk` → `~/.cursor/sdk/auth.json`）；无 API Key 表单。亦可用环境变量 `CURSOR_API_KEY` / `FAWAI_CURSOR_API_KEY`。
3. **连接配置**：本机 `{FAWAI_DATA_DIR}/cursor_agent_settings.sqlite` 存启用开关、默认模型、Mode、Auto Accept、模型目录缓存；与 `llm_settings.sqlite` 分库。
4. **模型目录**：登录后可刷新 `Cursor.models.list()` 并缓存；Bridge 失败时落盘本地兜底目录（`auto` / `composer-2.5` 等），页面仍可选。Web 可选默认模型。
5. **Mode**：`agent` / `plan`（SDK `AgentModeOption`）；创建与追问均传入。
6. **Auto Accept**：开关映射 SDK `LocalAgentOptions.auto_review`（工具自动审阅；对齐 IDE Auto Accept 语义，非 IDE 原生同名实现）。
7. **后台管理 API**：创建 / 追问 / 列表 / 归档 local Cursor agent；`cwd` 为任务工作区或 `work_root`。本轮不做 Cloud Agent。
8. **直连对话**：compose 开「Cursor Agent」后，下一条消息走 Cursor agent（不进主脑 Worker）。若当前焦点是 fawai 线程，**新开** Cursor 会话（不改写旧线程，可记 `related_task_id`）；已在 Cursor 线程则 **同 `task_id` `resume` 同一 `agent_id`**（多轮禁止因列表刷新丢身份而再拆新任务）。打开已有 Cursor 任务时底栏须显示「开」：身份以 `meta.runtime=cursor_agent` / `meta.cursor_agent` 为准，列表摘要则吃 `exec_config.runtime` / `exec_config.cursor_agent`（前端 `isCursorAgentTaskId` 与底栏同源）；拨开关只更新全局末次与下一句路由，不剥掉已有 Cursor 线程。进度经会话网关以 **Cursor 式步骤流**直播：`cursor-sdk` 的 thinking / tool-call 事件分别映射为会话 `plan`/`planned` 与 `act`/`acted` 步骤卡（`meta.tool` 为 Shell / Search / Read 等；每条 progress 带本轮 `run_id`）；回合结束须把同结构写入任务 **`meta.steps`**，会话裁剪后仍可用 `task_timeline` 回放。`cursor_status` 只作薄状态条，终稿仍为助手 `text` 气泡（不把终稿揉进状态卡）。
9. **主脑委派**：已启用且已登录时，主脑可 `delegate` `tier=cursor`（或原生 `delegate_to_cursor`）；段内由 Cursor agent 执行子目标，摘要回灌主脑。

### 可选（可砍）

- 流式逐 token 气泡（默认进度卡 + 终稿气泡即可）。
- Cloud Agent / 自动开 PR。

## 边界

- 不替代本机编码闭环工具（`fs_*` / `code_check`）；Cursor agent 是另一条执行面。
- 不把 Cursor 模型塞进 LLM 角色路由（`text`/`vlm`/`fast`）。
- 凭据优先环境变量，其次 `~/.cursor/sdk/auth.json`；产品 UI 不收集 Key。
- macOS / Linux headless 均可（依赖本机 `cursor-sdk` + Node 登录或环境变量 Key；登录脚本优先 Node ≥22）。
- **已登录 / 已有 Key 时**：创建与追问 Cursor Agent **不**再要求本机 Node；`no_node` 仅在未登录且找不到 Node≥22 时阻断浏览器登录。Node 探测含 `FAWAI_CURSOR_NODE`、PATH、`cursor-sdk` 自带 bridge Node、nvm `v22+`。
- Auto Accept 走 SDK `auto_review`；与 Cursor IDE 面板文案同名但对齐语义，不保证行为与 IDE 逐像素一致。
- 本机系统 HTTP 代理（如 `127.0.0.1:7890`）若劫持回环，会出现 `Bridge request failed with HTTP 502`。SDK 调用前会把 `127.0.0.1` / `localhost` / `::1` 写入 `NO_PROXY`；仍失败时检查代理软件的 localhost 例外。
