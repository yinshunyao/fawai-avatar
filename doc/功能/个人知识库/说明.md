# 个人知识库

本地 KV + 结构化笔记 + 旁路抽取；Web「记忆缓冲」审待确认，并管理已入库知识条目。

## 能力边界

| 面 | 说明 |
|:---|:---|
| 旁路入库 | P0 路径类直写；P1 默认进缓冲（可配直写） |
| 待确认缓冲 | 列表 / 入库 / 丢弃 / 清空 |
| 已入库知识 | 列表；**启用 / 停用**（软开关，停用后不参与检索与规划注入）；**删除**（硬删，笔记顺带清向量行） |
| 最近已入库 | sidecar 日志只读摘要 |
| Web 分区 | 记忆缓冲页三 Tab：待确认 / 已入库 / 最近；有待确认时默认开「待确认」，否则「已入库」；「清空缓冲」仅待确认 Tab 可见 |

## 验收口径

1. 记忆缓冲页以三 Tab 切换「待确认 / 已入库 / 最近」；「已入库」可见知识列表（KV / 笔记）。
2. 停用后同一内容不再出现在规划【个人知识库】摘要与 `lore_search` 命中；磁盘仍保留。
3. 再启用后可再次被检索。
4. 删除后条目消失且不可再启用；确认框不可恢复。

## 实现映射

| 规范名 / 面 | 路径 |
|:---|:---|
| 存储 | `fawai_lore/kv.py`、`notes.py`（`enabled`） |
| 检索过滤 | `fawai_lore/retrieve.py` |
| HTTP | `fawai_avatar/lore_api.py`；`lan_gateway` `GET /api/lore/entries`、`POST .../enable`、`POST .../delete` |
| Web | `channel/static/index.html` `#lorePage` / `#loreEntriesList` |

## 不做

- 不做多用户权限与云端同步。
- 不做条目正文在线编辑（改内容仍走工具 / 旁路）。
