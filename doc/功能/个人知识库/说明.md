# 个人知识库

本地 KV + 结构化笔记 + 旁路抽取；Web「记忆配置」以**配置**为主页，待确认按工单跳转处理，并提供记忆工具自测与索引重建。

**检索面（已切换）：** `lore_search`（**应传 `scopes`**，读 `search_menu` 效率档）/ `lore_get` / 规划注入；缺省才混合已开通道（工作区正文·文件名 ∪ 笔记 ∪ 已开任务/日志）。**不再**以旁路短 KV 当主搜，也不再未命中灌随机 key。

## 能力边界

| 面 | 说明 |
|:---|:---|
| 旁路入库 | **默认关**（`FAWAI_LORE_SIDECAR=0`）；**Web 暂时不展示**开关与状态；后端能力仍保留 |
| 待确认缓冲 | **Web 暂时移除**工单角标 / 横幅 DOM（CSS 亦强制 `display:none`，避免被 flex 盖掉 `[hidden]`） |
| 已入库知识 | 列表；**按更新时间**排序（新→旧 / 旧→新）；弹窗**查看 / 编辑**详情；**启用 / 停用**；**删除**；覆盖原「最近入库」查看需求 |
| 记忆配置主页 | **配置**为默认 Tab；主导航 **配置 / 已入库 / 工具测试**；待确认仍隐藏；**保存配置**在页头右上角；不再用标题旁「已入库 N」跳转 |
| 配置分组 | **工作区与可读区**（路径 + **每区多选**索引方式 + **价值台账晋升阈值** + **终态短卡蒸馏** + **代码符号索引**）；**数据区**（目录自系统配置迁入 + **按业务**多选索引方式） |
| 价值台账阈值 | `FAWAI_LEDGER_GATE_THRESHOLD`（默认 80）：成功/失败台账三维均须≥该百分比才写入 lore；见 [成功价值台账](../成功价值台账/说明.md) / [失败价值台账](../失败价值台账/说明.md) |
| 终态短卡蒸馏 | `FAWAI_TASK_DISTILL`（默认开；**只存 sqlite，不进 env**）：多法成功/明确失败时自动蒸短卡进台账→lore；见 [自我进化](../自我进化/说明.md) |
| 代码符号索引 | `FAWAI_CODE_INDEX`（默认开；**只存 sqlite，不进 env**）：`code_symbols`/`code_map`/刷新；含 HTML/CSS；关则拒建索改用 `fs_grep`；见 [代码索引](../代码索引/说明.md) |
| 索引策略 | `FAWAI_INDEX_POLICY`；工作区/可读区/数据区各业务独立多选；缓存与配置库锁定；任务会话勾选后走任务 API 进 `lore_search` |
| 对智能体 | 规划带【索引配置】+ `search_menu`（能力/效率）；`lore_search` **应传 `scopes`**；缺省才混合已开通道；回含 `index_catalog` |
| 配置存储 | 路径/策略写入 `{data_dir}/memory_settings.sqlite`；**数据目录**仍写 `.env`（改后需重启） |
| **lore_search** | `knowledge_search(scopes=…)`：按范围跑通道；**缺省 = 记忆配置当前已开通道**（已关开关不查，即使索引库仍有旧行）；显式 scopes 与开关取交，跳过项进 `scopes_skipped_disabled`；工作区正文/文件名命中再剔除 `FAWAI_DATA_DIR` 残留；分通道保底合并；菜单见 [分析/检索范围由LLM决策.md](../../分析/检索范围由LLM决策.md) |
| **lore_get** | `knowledge_get`：笔记 id → 文件路径 / 索引命中（非 KV key 主路径） |
| **规划注入** | `knowledge_prompt_block`；空结果不灌 KV 键表 |
| **知识库 FTS5** | `{lore}/fts.sqlite`；笔记词法索引；写入同步；工具「重建知识库 FTS」 |
| **正文 FTS5** | 默认扫**工作区**（`work_root`）；库在 `{data_dir}/memory_index/content.sqlite`；缺库首次查询自动建；**文件变更增量更新**（`memory_index/watch.py`，同 watchfiles/轮询） |
| **文件名索引** | 默认扫**工作区**；库在 `{data_dir}/memory_index/names.sqlite`；缺库首次查询自动建；**同上实时监视** |
| 根过宽保护 | 索引根为 `/` 或用户主目录时拒绝重建 |
| 工具测试 | lore_search / lore_get / 文件名 / 正文 FTS；重建知识库 FTS、文件名、正文、向量（已入库走主 Tab，工具页不再跳转） |
| **重建进度** | 后台线程重建；PWA 展示阶段/条数/用时；`GET /api/memory/index/progress` 轮询 |

## 验收口径

1. 打开「记忆配置」默认落在**配置**；主 Tab 含 **配置 / 已入库 / 工具测试**；待确认仍隐藏。
2. 「保存配置」在页头右上角；窄屏仍可触达。
3. 已入库为常显 Tab（可显示条数）；列表可按更新时间排序；点条目或「详情」可弹窗查看并编辑全文；无标题旁跳转钮、无独立「最近入库」页。
4. 工作区默认勾选 FTS + 文件名；可读区默认不勾；数据区知识库默认笔记 FTS+向量、任务会话默认 FTS；索引缓存/配置库不展示（锁定）。
5. 数据区可配置业务各自多选；观察/其它为意向（`engine=none`）；日志勾选后进 `scopes=logs`。
6. `lore_search` 按 `scopes`（或缺省 = 已开通道）只汇合**记忆配置已开**通道；已关范围不查旧索引；工作区命中不含 `data/` 残留；**不含**旁路短 KV。
7. 首次查询缺库时自动建工作区文件名/正文索引。
8. `/` 整盘作索引根时重建失败并提示收窄。
9. 规划提示含【索引配置】+ `search_menu`（效率 5→1）；智能体选 scopes/工具，不把 `memory_index` 当文件再搜。
10. 网关运行时监视已开索引根；改文件后文件名/正文索引增量更新（可 `FAWAI_MEMORY_INDEX_WATCH=0` 关闭）。

## 工作区 vs 数据盘（按业务，不二次缓存）

| | 工作区（`work_root`） | 数据盘（`FAWAI_DATA_DIR`，默认 `data/`） |
|:---|:---|:---|
| 是什么 | 要改/搜的项目文件树 | 分身运行态与索引**结果** |
| 文件扫盘建索引 | **文件名 / 正文 FTS**（默认开） | **禁止**再扫进 `memory_index`（已跳过整树） |
| 实时监视 | 监视已开索引根；增量 upsert | **同样跳过**整棵 `data_dir`（含 `runtime/console.log`、索引库），避免日志写盘触发 watchfiles 闭环 |
| 库内检索 | — | 笔记 lore FTS/向量；任务/日志走各自 API |

一句话：**工作区是源；data 里多数是结果与运行态**——索引缓存 / 知识库存盘本身不要再被正文索引吞进去。

细则与 SQLite 工具能力：[分析/数据盘索引按业务划分.md](../../分析/数据盘索引按业务划分.md)。

### `data/` 按业务

| 业务 | 路径 | 检索方式 |
|:---|:---|:---|
| **索引缓存** | `memory_index/`、`code_index/` | 自身即缓存；**不再扫** |
| **知识库存盘** | `lore/` | 笔记 FTS/向量（`lore_search`）；非文件再扫 |
| **任务会话** | `tasks.sqlite`、`sessions/`、`session_*`、`session_media/` | 勾选后 `lore_search(scopes=[tasks])` / `GET /api/tasks?q=`；**无**独立 FTS 库 |
| **观察落盘** | `observe/` | 可勾意向；`engine=none`；默认不进工作区 FTS |
| **配置** | `memory_settings.sqlite`、`llm_settings.sqlite` | 配置页 / API；锁定不展示 |
| **系统日志** | `system_logs.sqlite` | 勾选后 `scopes=[logs]` 子串 ∪ Web 列表 |
| **其它** | `versions/`、`runtime*`、`skills/`、`analysis/`、`frpc.*` | 可勾意向；各业务自管 |

工具测试分组：「工作区索引」= 扫 work_root；「数据目录索引」= 重建 lore 笔记 FTS/向量（不是扫整个 data）。

## 不做

- 不做多用户权限与云端同步。
- 不做已入库条目「改 id / 改 key」（弹窗只改笔记标题正文标签，或 KV 值）。
- 不做 `/` 整盘实时 Everything（无 USN）；索引为扫盘重建 + 查询读表。
- 正文 FTS 不是正则 `rg`；复杂正则仍用 `fs_grep`。
- **文件名 scope（`work_name`）**：自然语言整句按词 OR/分词打分（不再整句 AND）；口令/SSH 正文多在 md 里，空命中时应扩 `work_content` / `lore`，勿死盯文件名。
- 不做「抽短 KV → 当知识库主搜」的旧产品面。
- 不做把 `data/` 默认当工作区扫盘源（索引源与缓存库须分开标）。
