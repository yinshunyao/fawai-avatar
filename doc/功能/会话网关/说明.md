# 会话网关

## 验收

- 本机起 LAN 网关（macOS / Linux）：HTTP 静态 PWA + WebSocket 推送 + 上传图/发文本。
- 启动打印局域网 URL 与**短口令**；PWA 凭口令连接（首期不做二维码强制）。
- 启动横幅含**运行平台**（OS/架构/headless 来源）；无界面时 GUI 标注已禁用。
- 控制台日志（启动横幅、uvicorn、保活 `[keeper]`）带本地时间戳 `YYYY-MM-DD HH:MM:SS`。
- macOS：**仅** Web 主入口（`python -m fawai_avatar.channel.lan_gateway` / `fawai-gateway` 的 `main()`）一次性请求辅助功能 / 屏幕录制；启动日志打印授权状态。任务与 WorkerLoop 内不再主动弹窗。Linux 跳过权限弹窗。
- 口令：环境变量 `FAWAI_GATEWAY_PASSCODE` 有值则用配置；未配置则每次启动随机生成。
- 端口：`FAWAI_GATEWAY_PORT`，默认 `7980`。
- 截屏候选：`FAWAI_GATEWAY_CAPTURE`（默认关）；**headless 强制关**。
- 公网穿透（可选）：本机 **frpc**；配 `FAWAI_FRP_SERVER_ADDR` + `FAWAI_FRP_REMOTE_PORT` 时随网关启动（默认 frps 口 `FAWAI_FRP_SERVER_PORT=37000`）。多机同 frps 时用 `FAWAI_FRP_PROXY_NAME` 区分代理段名（默认 `fawai-avatar-gateway`）。二进制：`FAWAI_FRPC_BIN` 或**与当前 OS 匹配**的仓库 `bin/frpc` 或 PATH 中的 `frpc`（Linux 拒绝 Mach-O）。启动日志打印公网 URL；ini/日志/pid 在 `data/frpc.ini`、`data/frpc.log`、`data/frpc.pid`。**同一 ini 只保留一个 frpc**：启动/停止前按 ini 清掉孤儿（保活热重载不会堆几百个穿透进程）。
- 用户文本/图入站 → 总管：**无 `task_id`** 则 `create_task`；**有**则线程内路由续跑/另开，或执行中追加（规则见 [会话通道](../会话通道/说明.md)）；暂停/取消口令映射总管 API。
- **发送回执与防双发**：PWA 发送时带稳定 `message_id`；枢纽先落盘并**立刻广播用户气泡**，路由/LLM 前再推 `phase=accepted`；WebSocket 入站**异步**处理（不堵收包）。同 `message_id` 重投只回执不二次路由；同任务同正文约 3s 内近重复不落第二份。发送钮在收到服务端同 id 回执前保持「发送中」。`POST /api/messages` 响应含 `inbound`（与 upload 对齐）。
- **新建也先受理**：无 `task_id` 新建时**先** `create_task` + 建卡 + `phase=accepted`，再后台跑编排脑判定/出图（`awaiting_plan`）；禁止等 LLM 完了才出第一张卡。出图完成后再发 `plan_create` 卡并调度；简单目标清闸门后拉 Worker。
- **编排脑/路由 LLM 不堵事件循环**：`decide_complexity` / `build_plan_graph` / `replan_full_graph` / `route_followup` / 追加分析等同步调用须 `asyncio.to_thread`（`SessionHub._run_blocking`）；否则进计划或「重新执行」出图期间整站无响应。
- 任务进度与观察媒体（若有截屏）以 `progress` / `image` / `card` 推到已连接会话；执行中**流式**阶段 progress（见 [会话通道](../会话通道/说明.md)）。
- **最大步数**：`FAWAI_MAX_STEPS`（默认 `0` = 不限制）；`>0` 时超过则 `max_steps exceeded`。
- **用户图**：入站 image 带 `media_url`（`/media/…`）可在气泡展示；`/api/upload` 返回 `echo` + `inbound`。goal 内嵌的 `[image:路径|/media/…]` 须渲染为图片（禁止当纯文本露出）；历史裁剪优先保留用户消息（含附图）。
- **会话附件**：粘贴/选图先挂 compose 附件（可预览、可移除），**不**立即发送；用户可再输入文字后点发送再 upload 派发。
- **多行输入**：compose 为可增高 `textarea`；宽屏 Enter 发送、Shift+Enter 换行（IME 组字中不拦截）；窄屏 Enter 换行，点发送钮提交。气泡纯文本已 `pre-wrap` 保留换行。
- **语音输入**：麦克风录音 → `POST /api/transcribe` → 文本填入输入框（可改后再发）；**HTTP 局域网不能网页开麦**时改为选录音文件转写；见 [语音输入](../语音输入/说明.md)。
- 会话页图片（用户图与观察媒体）可点击放大预览；点遮罩 / 关闭钮 / `Esc` 退出。
- 会话页展示消息**日期时间**（日分隔 + 气泡旁时刻；来自信封 `ts`）。
- 连入时 `/api/session` 只带**近段**历史（约 120 条）作引导；**打开任务线程**时先 `GET /api/tasks/{id}/history` 按任务补齐全部信封（含执行步骤 progress）**再渲染**气泡与步骤流，避免近段缺用户消息时误用 goal 合成合并气泡。WebSocket **不**重放历史（避免气泡重复）。追问与首条指令在会话中分条展示，不拼进同一绿泡。
- WebSocket **断线自动重连**（指数退避）；单条入站处理失败不拆连接，回推 error 气泡。
- **模型配置**（左侧独立导航）：供应商凭证 + 按角色「供应商→模型」写入 `llm_settings.sqlite`（无 Key 不可选；保存热更新）；在线拉列表；模型参数弹窗；`GET|PUT /api/llm/settings`；`GET|POST /api/llm/models`。见 [LLM 接入](../LLM接入/说明.md)。
- **系统配置**（左侧导航）：外观与语言（本机）+ 运行与大脑 / 网关与保活 / frp / 中继 / 编码闭环 / 工具观察压缩；`GET|PUT /api/settings`（`scope=system`）。写仓库根 `.env` 并热更进程环境；密钥脱敏（空提交不改，可显式清空）；端口/口令/frp/保活等标「需重启」。不含评测专用 `FAWAI_EVAL_*`、不含模型页字段。
- **服务与版本**（左侧独立菜单）：重启服务、**代码热重启开关**（默认关）、**后台日志**、**一键修复启动错误**、运行时存档/选版启动（见 [服务保活](../服务保活/说明.md)、[运行时版本](../运行时版本/说明.md)）；默认经保活外层启动。顶栏不再单独放「服务」入口。
- **启动降级**：系统日志库等组件 init 失败时网关仍提供 HTTP/WS；`/api/health` / `/api/runtime` 标 `degraded`；对话与任务可用。
- 执行进度（`progress`）在会话页以 **Cursor 式步骤流**直接插入对话滚屏（无「执行时间线」折叠菜单）；同族阶段合并就地刷新；结论可见、过程默认折叠可点开；代码改动以 diff 着色展示。对话行按信封 **`ts` 插入**（追问卡/气泡不得因晚到而挂在后续步骤流末尾；追加/追问卡另按 `inbound_id` 紧跟对应用户气泡）。**同一任务多次追问各开一段**，跟在对应用户消息/续跑卡之后，不连续并入首轮流；**执行中追加**与 **continue 追问卡**在**卡到达时**封口前段（非用户气泡乐观插入时）：前段步骤流 → 用户气泡 → 追加/追问卡 → 后段步骤流（同 `run_id` 也可多段）；任务卡不重复贴 goal 正文。**任务状态收尾**（`任务 … → completed/failed/…`）并入步骤流末条，不单独占一行气泡；最终结论仍用助手 `text`。
- 刷新/重启服务后：凭口令重连，`/api/session` 仍返回枢纽已落盘的近段历史（默认 `data/session_history.jsonl`）；点进旧任务须靠 `/api/tasks/{id}/history` 才能看到完整处理记录，避免被近段窗口裁掉。若会话历史已裁掉该任务的 progress，接口会按任务库 `meta.steps` 回放处理步骤（见 [会话通道](../会话通道/说明.md)）。
- 进程再起：自动 [进程中断续跑](../进程中断续跑/说明.md)（`running`/`waiting`/`blocked`/`pending` 按检查点续跑；`paused` 需用户恢复）。
- **布局**：宽屏左侧主导航（对话 / 任务管理 / 系统日志 / 记忆配置 / 服务与版本 / 模型配置 / 系统配置）+ 中间对话框或管理页；**窄屏（≤859px）不展示左侧功能导航**，改为顶栏右上角汉堡钮弹出菜单切换；对话列表与线程仍可进退切换（返回键）。一任务一条；点对话列表进入线程；发送自动带当前任务 id。侧栏会话行版式见 [任务统计](../任务统计/说明.md)。
- **外观**：PWA 支持浅色 / 暗色 / 跟随系统；**宽屏**顶栏与系统配置「外观」可切换；**窄屏顶栏不展示外观段**，仅在系统配置中切换；偏好存本机 `localStorage`（`fawai_theme`），不写服务端。
- **界面多语言**：中文 / 英文；宽屏顶栏与系统配置可随时切换（窄屏仅系统配置）；偏好 `localStorage`（`fawai_locale`）；目录 + `t()`，见 [界面多语言](../界面多语言/说明.md)。
- **任务状态徽章**：WS 出站 `card` / 带任务态的 `progress`（如 `started`→running、终态→completed/failed）时，左侧导航与任务管理页状态须即时刷新；不依赖切回列表页。规划回合里的 `continue`/`success` 等不得当作任务态徽章。文本控制口令（暂停/取消等）成功后枢纽**必须 publish** 带 `meta.status` 的卡，禁止只 return 给 HTTP echo（WS 无 echo）。
- **归档（PWA 暂隐）**：服务端仍保留 `POST /api/tasks/{id}/archive`、`/unarchive` 与列表 `?archived=`；PWA 暂不展示归档子菜单、输入栏归档/恢复钮与管理页归档操作；对话列表仅显示未归档。
- **停止任务**：对话输入栏发送钮右侧；任务为 running/pending/waiting/blocked/paused 时显示；`POST /api/tasks/{id}/cancel`：有存活 Worker 时立刻推送 progress「正在停止…」（`phase=cancelling`）；**无 Worker** 时直接推「任务已取消」（`phase=cancelled`），避免步骤卡在正在停止。Worker 收束后再推 cancelled / 终态卡；PWA 将 cancelling↔cancelled 合并为同一张步骤卡，历史回放遇终态也会收口转圈。
- **从步骤恢复**：步骤簇 / 带 `#N` 的步骤卡，桌面悬停 / 窄屏常显「从此恢复」→ `POST /api/tasks/{id}/resume-from-step`（见 [进程中断续跑](../进程中断续跑/说明.md)）；执行中须先停止。
- **步骤簇**：同一步号的多段 progress 收成一簇，点簇头展开/收拢子阶段（见 [会话通道](../会话通道/说明.md)）。
- **新对话**：右上角进入空白 compose（不带 id → 新建）；创建后自动进入该任务线程。
- **任务管理**：左侧「任务管理」后台页（筛选 / 列表 / **单条复盘**）；宽屏表格（操作列图标钮 ≥36×36、有边/底）、窄屏卡片（底栏大触控操作 ≥40px）；操作含打开 / 复盘 / 取消 / 删除（归档与多选联合复盘暂隐）；`GET /api/tasks`、cancel/delete；`POST …/review` **先建复盘任务**（waiting + 指令），在对话里放行后执行。顶栏不再放「管理」抽屉入口。
- **系统日志**：任务/文件/命令/代码/鼠标截屏可订阅落盘（默认全记），不进会话气泡；`GET /api/system-logs`（`limit`/`offset`+`total` 分页）、`GET|PUT /api/system-log-subscriptions`、`POST /api/system-logs/analyze`（失败一键分析→整改任务）；PWA 左侧「系统日志」可分页查看；订阅在右上角按钮弹窗配置。复盘仍进任务会话。
- **任务统计**：侧栏/任务卡可复制完整 id；展示总 token 与总执行时间；点摘要看轮次、大模型次数、工具分布。见 [任务统计](../任务统计/说明.md)。

## 边界

- 首期仅局域网；云端中继见独立功能条目。
- 不做实时桌面视频流。
- 不做原生 App。
- 地址发现：启动日志打印 URL；手机手动打开（不做 mDNS 硬依赖）。
- 历史持久化随 `FAWAI_DATA_DIR`；清目录或换 data_dir 会看不到旧记录。
- 不做多会话服务端账本；不做「焦点条 / 设为焦点」作为主交互。
- 系统配置不暴露评测专用环境变量；不热换监听端口 / 不无重启重绑 frpc（保存后提示重启）。
- 系统配置不做多用户权限分级（仍一口令进网关）。
- SQLite（任务库 / 系统日志库）每次查询后必须关闭连接；禁止依赖 `with sqlite3.connect()` 关 FD（它只提交事务）。网关启动时尽量抬高 soft `nofile`（macOS 默认 256 易 `EMFILE: Too many open files`）。
