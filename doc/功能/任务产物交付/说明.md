# 任务产物交付

## 验收

- **落点（软判断）**：需要写出交付物时，由规划模型判断目录——无项目/目录证据 → `data/sessions/{task_id}/`；上下文能感知到具体项目或目录（用户点名路径、本任务已定位子树、编码目标落在已点名仓内子树）→ 写到该处。仅 work_root / monorepo 根**不宜**当默认落点。非硬闸。
- **附件卡**：产物落盘后会话出 `kind=file` 气泡（文件名 / 类型 / 大小）；可预览、可下载另存。
- **跨端**：其他终端经浏览器取网关文件（`/media/…`）；大文件支持 HTTP Range 分片；禁止只给本机绝对路径当交付。
- **预览**：图 / 音视频 / PDF 浏览器内预览；常见办公（`pdf` / `pptx` / `docx` / `xlsx`）可预览（办公提取文案或页内查看器）；一律可另存。

## 自检

```bash
.venv/bin/python -m fawai_avatar.demo_file_deliver
```

## 边界

- 落点靠规划提示，不新增「必须 sessions」路径硬闸。
- 办公预览为首期可用深度（页内/提取文本），不承诺与 PowerPoint 像素级一致。
- 写仓内业务源码仍走 `fs_*`，本功能只管「交付物」展示与默认偏好。
