# 代码索引

## 验收

- 可在 `FAWAI_WORK_ROOT` 内列出 **符号**（类/函数/方法等）与精简 **仓地图**。
- 纯后台；与 `fs_*` 同一套工作根与跳过目录规则。
- **多语言**：Python 用 stdlib `ast`；其它常见后缀（js/ts/vue/go/rs/java/c/cpp/rb/php/swift/cs 等）用启发式声明抽取；**HTML/CSS** 抽取 `id` / `class` / CSS 选择器 / `@media`（`<style>` 与独立 `.css`；HTML 内 `<script>` 复用 js 启发式）；解析失败返回空，不假装成功。
- **开关**：记忆配置 `FAWAI_CODE_INDEX`（默认开；只存 `memory_settings.sqlite`，不进 env）。关则 `code_symbols` / `code_map` / `code_index_refresh` 拒绝建索并提示改用 `fs_grep`；`explore_search` 符号通道同拒。
- **落盘复用**：`{data_dir}/code_index/`（`meta.json` + `symbols.jsonl`）；按文件 mtime/size 增量刷新；查询先 `ensure_index`。
- **探仓借用（默认关符号）**：`explore_search` 默认每条 query **只 grep**；`include_symbols=true` 时才并行 symbols，或单独 `symbols_query`。参数兼容 `queries` / `query` / `pattern` / `q`；可选 `code_index_refresh` 强制重建。结构定位主走 `code_symbols` / `code_map`。

## 边界

- 不做向量语义检索；文本内容搜索仍用 `fs_grep`。
- 不做 SCIP / LSP / Zoekt；不依赖 fawai_shovels / tree-sitter。
- 不写业务源码；不改版本库（只写 data 下索引缓存）。
- 大树须带 `head_limit`；地图为截断摘要，不是全量 AST dump。
- HTML/CSS 为启发式锚点（去重后的 id/class/选择器），不是完整 DOM/CSSOM；复杂正则与正文定位仍用 `fs_grep`。
- 不做 JSON/Markdown「伪符号」。

## 自检

```bash
.venv/bin/python -m fawai_avatar.demo_code_index
```

| 探仓借用 | `fawai_avatar/workspace/explore.py` |
| 工具接线 | `fawai_avatar/control/background.py`（`code_symbols` / `code_map` / `code_index_refresh`） |
| 能力清单 | `fawai_avatar/brain/capabilities.py` |
