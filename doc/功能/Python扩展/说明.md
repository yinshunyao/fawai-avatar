# Python 扩展

## 验收

- 会话根：`{FAWAI_DATA_DIR}/sessions/{task_id}/`（缺则创建）；相对路径只相对该根。
- **`py_write`**：在会话目录新建/覆盖文件（`path` + `content`）。
- **`py_pip`**：用主程序解释器 `{python} -m pip install …` 装包（优先 `sys.executable`，否则 `{work_root}/.venv/bin/python`）；禁止 uninstall。
- **`py_run`**：用同一解释器跑 `script` / `code` / `module`；捕获 returncode/stdout/stderr；落盘 `runs/{utc_ts}/stdout.txt`、`stderr.txt`、`meta.json`；可选 `result_path`（须在会话根内）回传；成功时登记 `deliverables` 推会话附件卡。
- **交付物落点（软判断）**：未感知项目/目录 → 写出相对会话根（`cwd` / `FAWAI_PY_SESSION_ROOT`），勿默认 work_root/仓根；上下文已感知具体目录/项目 → 写到该处。由规划模型判断，非硬闸。
- 须有 `task_id`；后台工具，不受 `FAWAI_DRY_RUN`。
- macOS / Linux headless 均可（无 GUI）。

## 边界

- 装包写入**共享**主程序 `.venv`，会影响产品进程环境；首期只 install。
- 不替代产品仓 `fs_patch` / `code_check`；改产品源码仍走编码闭环。
- 不做 Notebook、LSP、pdb/断点交互调试、每任务独立 venv。
- `py_write`/`result_path` 路径禁止逃逸会话根；禁止写 `.env`。子进程绝对路径写出靠规划约定（见 [任务产物交付](../任务产物交付/说明.md)）。

## 自检

```bash
.venv/bin/python -m fawai_avatar.demo_py_session
```
