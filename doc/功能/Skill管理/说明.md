# Skill 管理

## 验收

- PWA `#extPage`（表 Tab：Skill / MCP / **工具**）：Skill 表左侧查询（含停用/搜索，可匹配步骤正文）、右侧配置表单；上传 JSON（单对象或数组）、启停、删除。
- **工具表**：查询 `fawai_shovels` 工具代码（id/标题/路径/代码预览/评价维）；右侧只读代码 + **手工编辑**设计三维分与运行成败维；见 [脚本铲子生命周期](../脚本铲子生命周期/说明.md)、[成败经验与检索极性](../成败经验与检索极性/说明.md)。
- 外观：`#extPage` 使用主题 CSS 变量（`--surface` / `--bg-elevated` / `--bg-input`），支持浅色 / 暗色 / 跟随系统。
- HTTP：`GET /api/skills`、`PUT /api/skills/{id}`、`GET /api/skills/{id}`、`POST /api/skills/upload`、`POST …/enable`、`POST …/delete`；工具表见 `/api/shovels*`。
- `enabled=false` 时：`skills_prompt_block` / `skill_search` 不出现；`skill_get` 返回不可用。
- `skill_search` / 规划注入按极性分栏：`lesson`/`failure` → avoid（勿照抄）；普通/`success` → imitate（见 [成败经验与检索极性](../成败经验与检索极性/说明.md)）。
- 字段仍走 `validate_skill_payload`；另存 `enabled`（默认 true）。
- 内置 skill 可编辑/停用；删除后仅当文件缺失时启动回填 builtin（不覆盖用户改稿）。
- 冒烟：`python -m fawai_avatar.demo_skills_admin`

## 边界

- 不做「简要/全程」二选一；不做强制人审闸（规则质量门即可）。
- 不等于任务复盘勾选落 Skill（复盘路径仍可用）。
- 工具表不新建/删除铲文件；只读代码、改评价维。
