# 任务统计

## 验收

- 对话侧栏与任务管理页：点击任务 **id** 复制完整 `task_id`（不打开线程）；成功有短暂反馈。
- 侧栏列表行：标题最多两行，**右上短 id**（点复制，带复制图标，不打开线程）；下一行**左为时间 + 状态徽章**，**右为用量摘要**（与 id 右对齐；仅有轮次/工具等细节时显示 `…`，可点进详情）；完整时间悬停可见。不做摘要预览行。
- 列表行展示 **总 token** 与 **总执行时间**（墙钟合计；运行中含当前段；摘要耗时按量级用 `s` / `m` / `h`）；无用量时侧栏不占位空 `—`。
- 点击用量摘要打开详情：总 token（含 prompt/completion）、总执行时间、**轮次**、**大模型对话次数**、**工具类型与调用次数**。
- 真源为任务 `meta.stats`；运行中增量更新；`GET /api/tasks`、`/api/session` 摘要带出。
- 旧任务无 stats 时：有 `meta.steps` 可懒回填轮次/工具；token 可能仍为 `—`。
- **复盘任务**（`meta.kind=review`）与普通任务同一套摘要与详情：分析/执行段累计墙钟；分析阶段 LLM usage 写入 token / `llm_calls`；每段计 1 轮。
- **计划模式父任务**（`plan_role=orchestrator`）：侧栏/列表 **token = 全部监管脑子任务 token 之和**；**耗时 = 会话创建→结束**（`created_at` → 终态 `updated_at`，运行中用当前时刻）。节点卡仍展示各自子任务 stats。归并进度带 `parent_stats`（及 `parent_status`）更新侧栏；PWA 另用节点卡汇总兜底。禁止用单节点 `stats` 覆盖父任务摘要。

## 边界

- 不做跨任务汇总看板、不计费出账。
- 不以会话 progress 历史作列表唯一真源。
- 普通任务总执行时间主指标为 Worker run 墙钟（暂停段不累计）；不等于逐步 `elapsed_ms` 之和。
- 计划模式父任务耗时按会话跨度，**不是**各节点墙钟相加（并行节点不会叠乘）。
- 复盘旁路不经 WorkerLoop，由 hub 复盘线程写同一 `meta.stats`；等待勾选期间墙钟不累计。
