# 动作段预期闸

## 验收

- **多只读一段**：定位/探路相位可一次规划多个只读 actions（约 4～8）；写 / 前台 / 高风险 shell 仍宜短步。
- **机械成功少进模**：整批动作均为机械只读且全部 `ok` 时，观察反省走**规则摘要**入 history，**不**调用 LLM（除非 `FAWAI_OBS_REFLECT_MECHANICAL=llm`）。关总闸 `FAWAI_OBS_REFLECT=0` 仍完全关闭。
- **预期闸**：`Action.expect` 可含 `contains`（精确子串）/ `not_contains` / `contains_any`（模糊：多个可接受标记任一命中）；工具 `ok` 后校验文本（message + data）；不满足 → `ok=false`（文案 `expect failed:…`）并打断同批后续，进入既有执行反省路径。
- **写入已落盘特例（P0）**：`fs_patch` / `fs_replace` / `fs_write` 成功 message 含稳定标记 `· applied`。若 mutate **已写入**（`written` / `hunks_applied` / auto diff），但 expect 只断言臆造成功口令（如 `patch applied`）→ **保持 `ok`**（`expect_ignored`），避免「表面失败、磁盘已改」。真实内容 expect 仍可失败，但文案须带 `【写入已落盘】` + diff 小窗，禁止当未修改。
- **规划软倾向**：多步 `act_serial` / shell / `py_run` 倾向带 expect；纯探路只读与 **mutate 默认可不带**；勿对 `fs_patch` 断言不存在的 `patch applied`。无 expect 不拒规划、不重规划。
- progress：机械跳过时仍可用 `phase=obs_reflect`，文案标明规则摘要；facts 可带 `skipped=true`。
- 自检：`demo_action_segment`；既有 `demo_obs_reflect`（写后路径仍应 LLM 反省）不得被机械跳过误伤。

## 边界

- **不等于**取消执行反省；失败 / expect 失败仍反省。
- **不等于**主脑委派（委派是换模型跑子目标；本功能是同脑段内少进模）。
- **不等于** [步骤分类与执行流](../步骤分类与执行流/说明.md)（步型 + 跳过浅观察 + 只读并行）；本功能的 expect / 机械跳过反省仍被其复用。
- 不做依赖槽自动填参；不做无预期超长盲跑。
- 含 shell / 写 / GUI 的成功批默认仍走 LLM 观察反省。

## 环境变量

| 变量 | 默认 | 含义 |
|:---|:---|:---|
| `FAWAI_OBS_REFLECT` | `1` | `0` 关闭全部观察反省 |
| `FAWAI_OBS_REFLECT_MECHANICAL` | `skip` | `skip`=机械成功规则摘要；`llm`=机械成功仍调 LLM |

## 自检

```bash
.venv/bin/python -m fawai_avatar.demo_action_segment
.venv/bin/python -m fawai_avatar.demo_obs_reflect
```
