# 观察反省

## 验收

- 本步动作**全部成功**、工具结果观察已写入 history 后，闭环先走 `Brain.obs_reflect`，再进入探索闸 / 步骤重复 / 下一轮规划。
- progress 出现 `phase=obs_reflect`；history 出现 `【观察反省】`（含 thought / progress / notes / hints）。
- `progress` 为 `advanced` | `stalled` | `enough_to_answer`；hints 为**软建议**，不强制 abort。
- 与 [执行反省](../执行反省/说明.md) 互斥：本步有失败走执行反省时**不**叠跑观察反省。
- 关闸：`FAWAI_OBS_REFLECT=0`（或 false/no/off）时不调用；默认开。
- mock（`FAWAI_BRAIN_MOCK=1`）下仍产出固定短文，便于自检。
- 观察反省 LLM 调用默认 **关闭深度思考**（`thinking_role=obs_reflect`），避免轻量小结被思考 token 拖慢；见 [LLM 接入](../LLM接入/说明.md)。
- **入模预览**：默认头+尾快速预览（`FAWAI_OBS_REFLECT_PREVIEW_CHARS`，默认 `2500`；`0`=全文入模）。超预算时全文落盘 `data/observe/obs_reflect_*_preview.txt`，history 带 `fs_read` 指针；**禁止**把预览裁切写成「工具 stdout 被截断」。

## 边界

- **不等于**执行反省（失败裁决 retry/alternate/abort）。
- **不等于**步骤重复（成功同构空转）。
- **不等于**任务复盘（终态用户触发蒸馏）。
- **不等于**收尾「面向用户最终回答」那一轮；不因观察反省直接 `success`/`failed`。
- 不触发于：步首环境观察后、空 actions、`awaiting_user_answer` 收尾轮。
- 预览裁切 ≠ 工具观察压缩（工具 soft 见 [编码闭环](../编码闭环/说明.md)）；完整工具观察仍回灌规划 history。

## 环境变量

| 变量 | 默认 | 含义 |
|:---|:---|:---|
| `FAWAI_OBS_REFLECT` | `1` | `0`/false/no/off 关闭观察反省 |
| `FAWAI_OBS_REFLECT_PREVIEW_CHARS` | `2500` | 反省入模预览预算；超则头+尾并落盘；`0`=不裁切 |

