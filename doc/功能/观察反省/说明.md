# 观察反省

## 验收

- 本步动作**全部成功**、工具结果观察已写入 history 后，闭环先走 `Brain.obs_reflect`，再进入探索闸 / 步骤重复 / 下一轮规划。
- **实际调用 LLM** 时：progress 出现 `phase=obs_reflect`；history 出现 `【观察反省】`（含 thought / progress / notes / hints）。
- `progress` 为 `advanced` | `stalled` | `enough_to_answer`；hints 为**软建议**，不强制 abort。
- 任务 `meta.effort=true`（compose **Effort 开**）时，系统提示收紧 `enough_to_answer`（必要路径/新鲜度/可修复失败）；见 [Effort](../Effort/说明.md)。
- 任务 `meta.fast=true`（compose **极速开**）时跳过本步观察反省 LLM（`skipped_fast`）；**真跳过**：不推 `obs_reflect` 进度卡、不往会话 history 写「极速跳过」占位；见 [Fast](../Fast/说明.md)。
- 任务 [步级执行档](../步级执行档/说明.md) **分档开**（`meta.step_tier`）时，规划可带 `step_run`：`reflect` 完整本入口；`brief` 短观察反省；`act` 规则跳过（`skipped_act`）。分档关则忽略该字段。
- **`act` / 机械成功跳过**：**真跳过进度卡**（时间线不展示「观察反省：跳过…」）；规则摘要仍可写入规划 history，供后续规划用。
- 与 [执行反省](../执行反省/说明.md) 互斥：本步有失败走执行反省时**不**叠跑观察反省。
- 关闸：`FAWAI_OBS_REFLECT=0`（或 false/no/off）时不调用；默认开。
- mock（`FAWAI_BRAIN_MOCK=1`）下仍产出固定短文，便于自检。
- 观察反省 LLM 调用默认 **关闭深度思考**（`thinking_role=obs_reflect`），避免轻量小结被思考 token 拖慢；见 [LLM 接入](../LLM接入/说明.md)。
- **机械成功跳过 LLM**：整批均为机械只读且全部成功时，默认写入规则摘要、不调 LLM（`FAWAI_OBS_REFLECT_MECHANICAL=skip`）；见 [动作段预期闸](../动作段预期闸/说明.md)。
- **入模材料**：未超预算时原文入模。超预算（`FAWAI_OBS_REFLECT_PREVIEW_CHARS`，默认 `2500`；`0`=不压缩）走工具结果压缩 `digest_text`（头行、尾行、目标关键词与报错行）。摘录**不是原文**，只用于分析处置策略；提示词、入模导语和 history 都写明这条强制规则。禁止把摘录当原文引用，禁止为补全摘录去读落盘或重跑同一命令。原文仍在规划 history 的工具观察里。**大文件头/尾/中间起行取证是正常手段**；摘录已含头+尾时不得因未整文件 cat 判「关键缺失」。

## 边界

- **不等于**执行反省（失败裁决 retry/alternate/abort）。
- **不等于**步骤重复（成功同构空转）。
- **不等于**任务复盘（终态用户触发蒸馏）。
- **不等于**收尾「面向用户最终回答」那一轮；不因观察反省直接 `success`/`failed`。
- 不触发于：步首环境观察后、空 actions、`awaiting_user_answer` 收尾轮。
- 反省入模压缩只给观察反省看。规划侧工具观察仍默认不压缩（见 [编码闭环](../编码闭环/说明.md)）。完整工具观察仍回灌规划 history。

## 环境变量

| 变量 | 默认 | 含义 |
|:---|:---|:---|
| `FAWAI_OBS_REFLECT` | `1` | `0`/false/no/off 关闭观察反省 |
| `FAWAI_OBS_REFLECT_MECHANICAL` | `skip` | `skip`=机械只读成功用规则摘要；`llm`=仍调 LLM |
| `FAWAI_OBS_REFLECT_PREVIEW_CHARS` | `2500` | 反省入模预算；超则压缩摘录（非原文）；`0`=不压缩 |
