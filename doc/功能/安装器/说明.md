# 安装器

## 验收

- 提供**私有 Python 运行时前缀**打包脚本：产出可分发目录/压缩包，内含解释器、预装依赖、可写 `app/` 源码树、一键启动器；安装后**无需**用户自装系统 Python 或手跑 `venv`/`pip`。
- **三端产物**：`darwin-arm64` / `darwin-x64` / `linux-x64` / `windows-x64`（本机可打当前平台；全矩阵走 GitHub Actions）。
- 启动器：起 keeper/网关 → 健康检查 → **本机默认打开** `http://127.0.0.1:<port>/`；远端/手机地址仅展示或写在说明里，**不代开**。
- **安装包语言**：启动器与安装说明支持 **中文（zh-CN）** / **英文（en）**；可用环境变量 `FAWAI_LANG`、启动参数 `--lang`，或首次按系统语言猜测并写入 `data/install_lang.txt`。
- **GitHub Release**：打 `v*` 标签或手动 workflow 构建工件；发布脚本/`gh release` 上传压缩包到 [yinshunyao/fawai-avatar](https://github.com/yinshunyao/fawai-avatar) Releases。

## 边界

- 不做 PyInstaller 单文件默认通道；不做原生会话 App。
- Windows 包不承诺与 macOS 同等 GUI/AX；Linux 包不承诺桌面键鼠。
- 须在与目标同类 OS 上构建（或走 Actions 矩阵）；跨 OS 交叉编译原生 wheel 不保证。
- 公证/代码签名：P1；未配证书时跳过（当前脚本未自动 notarize）。
- 开发态仍可用 README 的 editable 安装；本功能管**消费分发**。
