# LLM 接入

## 验收

- 可用 OpenAI 兼容 API 完成一轮对话（`chat`）。
- 支持 tool / function calling 协议，返回可解析的 tool_calls。
- **智能路由（v1）**：消息无图 → 文本角色；含 `image_url` / 图像 content → 多模态角色。
- **配置真源**：供应商凭证与按角色的「供应商 → 模型」路由写入本机 `{FAWAI_DATA_DIR}/llm_settings.sqlite`；保存即热更新；**不再**用 `.env` 的 `FAWAI_LLM_*` / `FAWAI_LORE_EMBED_MODEL` 驱动运行时。首次启动若库空，可从旧 `.env` 迁移一次（旧键可留作备份）。
- **Web「模型配置」**：左侧独立导航。① 供应商凭证区：各家 Base URL / API Key / 超时；未配置 Key 显示「未配置」。② 模型路由：每角色两级下拉——供应商（无 Key 的选项禁用）→ 模型（仅该供应商已拉列表）；无 Key 时整行不可选。③ 模型行「设置」打开参数弹窗；生成参数按模型写入库表 `model_profiles`。
- **在线模型列表**：`GET|POST /api/llm/models`（`kind=text|vlm|asr|embed`）。可按 `provider_id` 取库内凭证；POST 也可带临时 `base_url` / `api_key` 做预览。DashScope 走原生目录 `/api/v1/models`（按 TG/VU/ASR/TR）；其它 OpenAI 兼容走 `/models` + 启发式分类。供应商列表见 `GET /api/llm/providers`；整包读写见 `GET|PUT /api/llm/settings`。
- **深度思考（按角色 + 档案）**：`qwen3.7-*` 等混合思考模型默认开思考会拖慢机械步。调用时传 `thinking_role`；解析优先级为 **显式参数 > 角色默认 > 模型档案 > 不传**。角色默认：主脑 / 执行反省 / 步骤重复 / 复盘 → 开；快模型委派 / 观察反省 → 关；旁路记忆抽取强制关。**不设默认思考预算**：`thinking_budget` 为 0 或空时不写入请求，思考不封顶；只有调用参数或模型档案里的正整数才作为上限。经 `extra_body` 传 `enable_thinking` / `thinking_budget`；**已接线供应商**：DashScope / 千问系、内置小黄（`kklt` / `api.kklt.lol`）。档案「空=跟随角色」在小黄上也会写入请求。进度 facts「模型」行可显示「思考开/关」。步骤卡深度思考正文仍依赖响应里的 `reasoning_content` 等字段；小黄 `gpt-6-sol` 实测多数回合只消耗 `reasoning_tokens`、不回传可见思考正文，界面可能仍无展开区。机械探路应优先 [主脑委派](../主脑委派/说明.md) 快模型（思考关），勿逐步烧主脑思考。
- **流式增量（可选回调）**：`LlmClient.chat(..., on_delta=…)` 走 `stream=True`；回调收到累计的 `thinking`（深度思考正文，如 `reasoning_content`）与 `content`（普通输出）；无回调时仍可阻塞整段返回。工作任务规划/反省经会话通道直播到 PWA（见 [会话通道](../会话通道/说明.md)）。

## 默认路由（内置供应商种子）

| 角色 | 说明 | 百炼默认模型 | 小黄默认模型 |
|:---|:---|:---|:---|
| `text` | 纯文本（主脑） | `qwen3.7-plus` | `gpt-6-sol` |
| `vlm` | 多模态 | `qwen3-vl-plus` | `gpt-6-sol` |
| `fast` | 快模型（委派）；空=关闭 | `qwen3.8-27b` | `gpt-6-sol` |
| `asr` | 语音转写 | `qwen3-asr-flash` | （可空） |
| `ocr` | 截屏 OCR（高精识别出框） | `qwen3.5-ocr` | （可空） |
| `embed` | 嵌入 | `text-embedding-v3` | （可空） |
| `force` | 强制覆盖文本/多模态；不覆盖 ASR / OCR / 显式委派快模型 | （空） | （空） |

另有全局项 **截屏识别方式** `screenshot_grounding`：`vlm` | `ocr`（存 `llm_settings.sqlite` meta；默认 `vlm`）。见 [截屏识别接地](../截屏识别接地/说明.md)。

内置供应商默认地址：百炼 `https://dashscope.aliyuncs.com/compatible-mode/v1`；小黄 `https://api.kklt.lol/v1`。可在 Web 新增/删除非 builtin 的自定义供应商。

## 生成参数（按模型）

选定文本 / 多模态 / 强制等 chat 模型后，档案写入：

`{FAWAI_DATA_DIR}/llm_settings.sqlite` → 表 `model_profiles`

（首次迁移可从旧目录 `data/llm_models/{model}.json` 导入。）

| 字段 | 说明 |
|:---|:---|
| `temperature` | 空=不传 |
| `top_p` | 空=不传 |
| `max_tokens` | `0`/空=不限制 |
| `presence_penalty` | 空=不传 |
| `frequency_penalty` | 空=不传 |
| `enable_thinking` | 空=跟调用角色默认；`true`/`false` 强制开/关 |
| `thinking_budget` | 思考 token 上限；`0`/空=不限制、不写入请求；仅思考开启且为正整数时写入 |

`LlmClient.chat` 按**本次路由到的模型 id**读取对应档案写入 completion 请求；思考字段走 `extra_body`，不进标准采样 kwargs。ASR / embed 仅共用对应供应商凭证与超时，不读采样/思考参数。

旧版若仍在 `.env` 写有采样键：首次为某模型建档时可作种子；之后以模型档案为准。

## 边界

- 不负责任务编排、键鼠、截屏。
- 密钥进本机 SQLite，与原 `.env` 同等信任域；不进 git、不写进文档正文。
- 路由规则保持简单：只看消息是否含图像，不做意图分类。
- **不做**每步再调一轮 LLM 判断「要不要思考」；角色默认 + 委派快模型即可。
- 主脑→快模型委派由规划字段触发，不是按消息自动分流；见 [主脑委派](../主脑委派/说明.md)。
- ASR 见 [语音输入](../语音输入/说明.md)；与对话路由独立。
- 系统运行项（干跑、网关、frp 等）在「系统配置」/ `.env`，不在本页、不迁本库。
- 不做云端同步或密钥加密 KMS；不改 Responses 协议栈。
