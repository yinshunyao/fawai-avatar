# LLM 接入

## 验收

- 可用 OpenAI 兼容 API 完成一轮对话（`chat`）。
- 支持 tool / function calling 协议，返回可解析的 tool_calls。
- **智能路由（v1）**：消息无图 → 文本模型；含 `image_url` / 图像 content → 多模态模型。
- 接入凭证与路由模型名来自本地 `.env` / 环境变量；`.env` 不入库。
- **Web「模型配置」**：左侧独立导航；「接入凭证 / 模型路由」写 `.env`；每个模型行右上角「设置」打开该模型参数弹窗；**生成参数按模型**落盘 `data/llm_models/{model}.json`（不写 `.env`）。
- **重启后路由与 Web 一致**：磁盘 `.env` 为真源；保活拉起子进程与网关启动会用磁盘覆盖旧进程环境，避免「已保存 qwen3.7-plus，重启又跑成 qwen3.8-*」。见 [服务保活](../服务保活/说明.md)。
- **在线模型列表**：`GET /api/llm/models?kind=text|vlm|asr|embed`。DashScope 走原生目录 `/api/v1/models`（按 TG/VU/ASR/TR）；其它 OpenAI 兼容走 `/models` + 启发式分类。
- **深度思考（按角色 + 档案）**：`qwen3.7-*` 等混合思考模型默认开思考会拖慢机械步。调用时传 `thinking_role`；解析优先级为 **显式参数 > 角色默认 > 模型档案 > 不传**。角色默认：主脑 / 执行反省 / 步骤重复 / 复盘 → 开（主脑默认预算 1024）；快模型委派 / 观察反省 → 关；旁路记忆抽取强制关。经 `extra_body` 传 `enable_thinking` / `thinking_budget`（DashScope 兼容）。进度 facts「模型」行可显示「思考开/关」。

## 默认模型（DashScope）

| 路由 | 环境变量 | 默认 |
|:---|:---|:---|
| 纯文本（主脑） | `FAWAI_LLM_TEXT_MODEL` | `qwen3.7-plus` |
| 多模态 | `FAWAI_LLM_VLM_MODEL` | `qwen3-vl-plus`（口语「qwen3.7-vlm」对应官方 ID） |
| 快模型（委派） | `FAWAI_LLM_FAST_MODEL` | 空=关闭主脑委派；见 [主脑委派](../主脑委派/说明.md) |
| 语音转写 | `FAWAI_LLM_ASR_MODEL` | `qwen3-asr-flash`（对话框语音输入） |
| 嵌入 | `FAWAI_LORE_EMBED_MODEL` | `text-embedding-v3` |
| 强制覆盖 | `FAWAI_LLM_MODEL` | 不设则走路由；**不**覆盖 ASR；**不**覆盖显式委派的快模型 id |

另需：`FAWAI_LLM_BASE_URL`、`FAWAI_LLM_API_KEY`。可选超时 `FAWAI_LLM_TIMEOUT`（秒，默认 120；0=SDK 默认）。模板见仓库根 `.env.example`。

## 生成参数（按模型）

选定文本 / 多模态 / 强制模型后，自动确保存在：

`{FAWAI_DATA_DIR}/llm_models/{model}.json`

| 字段 | 说明 |
|:---|:---|
| `temperature` | 空=不传 |
| `top_p` | 空=不传 |
| `max_tokens` | `0`/空=不限制 |
| `presence_penalty` | 空=不传 |
| `frequency_penalty` | 空=不传 |
| `enable_thinking` | 空=跟调用角色默认；`true`/`false` 强制开/关 |
| `thinking_budget` | 思考 token 上限；`0`/空时主脑用默认 1024；仅思考开启时写入请求 |

`LlmClient.chat` 按**本次路由到的模型 id**读取对应档案写入 completion 请求；思考字段走 `extra_body`，不进标准采样 kwargs。ASR / embed 仅共用凭证与超时，不读采样/思考参数。

旧版若仍在 `.env` 写有 `FAWAI_LLM_*` 采样键：首次为某模型建档时可作种子；之后以模型档案为准，勿再依赖 `.env` 全局采样。

## 边界

- 不负责任务编排、键鼠、截屏。
- 密钥不入库、不写进文档正文、不提交 GitHub。
- 路由规则保持简单：只看消息是否含图像，不做意图分类。
- **不做**每步再调一轮 LLM 判断「要不要思考」；角色默认 + 委派快模型即可。
- 主脑→快模型委派由规划字段触发，不是按消息自动分流；见 [主脑委派](../主脑委派/说明.md)。
- ASR 见 [语音输入](../语音输入/说明.md)；与对话路由独立。
- 系统运行项（干跑、网关、frp 等）在「系统配置」，不在本页。
