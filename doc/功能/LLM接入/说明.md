# LLM 接入

## 验收

- 可用 OpenAI 兼容 API 完成一轮对话（`chat`）。
- 支持 tool / function calling 协议，返回可解析的 tool_calls。
- **智能路由（v1）**：消息无图 → 文本模型；含 `image_url` / 图像 content → 多模态模型。
- 密钥与模型名来自本地 `.env` / 环境变量；`.env` 不入库。
- **Web「模型配置」**：左侧独立导航；分「接入凭证 / 模型路由 / 生成参数」三组（参考常见 OpenAI 兼容控制台）；`GET|PUT /api/settings?scope=model`；写 `.env` 并热更。

## 默认模型（DashScope）

| 路由 | 环境变量 | 默认 |
|:---|:---|:---|
| 纯文本 | `FAWAI_LLM_TEXT_MODEL` | `qwen3.7-plus` |
| 多模态 | `FAWAI_LLM_VLM_MODEL` | `qwen3-vl-plus`（口语「qwen3.7-vlm」对应官方 ID） |
| 语音转写 | `FAWAI_LLM_ASR_MODEL` | `qwen3-asr-flash`（对话框语音输入） |
| 嵌入 | `FAWAI_LORE_EMBED_MODEL` | `text-embedding-v3` |
| 强制覆盖 | `FAWAI_LLM_MODEL` | 不设则走路由；**不**覆盖 ASR |

另需：`FAWAI_LLM_BASE_URL`、`FAWAI_LLM_API_KEY`。可选超时 `FAWAI_LLM_TIMEOUT`（秒，默认 120；0=SDK 默认）。模板见仓库根 `.env.example`。

## 生成参数（可选）

| 环境变量 | 说明 |
|:---|:---|
| `FAWAI_LLM_TEMPERATURE` | 空=不传 |
| `FAWAI_LLM_TOP_P` | 空=不传 |
| `FAWAI_LLM_MAX_TOKENS` | `0`/空=不限制 |
| `FAWAI_LLM_PRESENCE_PENALTY` | 空=不传 |
| `FAWAI_LLM_FREQUENCY_PENALTY` | 空=不传 |

写入 `LlmClient.chat` 的 completion 请求；ASR / embed 仅共用凭证与超时。

## 边界

- 不负责任务编排、键鼠、截屏。
- 密钥不入库、不写进文档正文、不提交 GitHub。
- 路由规则保持简单：只看消息是否含图像，不做意图分类。
- ASR 见 [语音输入](../语音输入/说明.md)；与对话路由独立。
- 系统运行项（干跑、网关、frp 等）在「系统配置」，不在本页。
