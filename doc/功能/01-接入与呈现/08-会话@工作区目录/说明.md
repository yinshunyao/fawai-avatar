# 会话@工作区目录

任务对话 compose 输入 `@` 弹出工作区级联菜单（目录 + 文件）；选中路径写入文本与 `meta.at_dirs`，规划侧注入【语义路径】软偏置。

## 验收

- 线程 / compose 输入 `@` 弹出 `work_root` 一级条目（目录在前、文件在后；无角色项）。
- 桌面：目录**单击**展开下级（列滑入动画；下级为空则空列表），目录/文件均**双击**选中；文件单击无动作；悬停只高亮；进入三级时可藏一级；列可滚动。窄屏：目录点入下钻 + 返回；双击选中。
- 选中后：输入框与气泡以 chip 原语呈现（只显示当前名，悬停见完整相对路径；目录/文件图标区分）；线缆文本仍为 `@相对路径`；发送带 `meta.at_dirs`（POSIX，相对 work_root）。
- `GET /api/workspace/dirs?path=` 返回 `entries`（`kind=dir|file`）+ `has_children`；越界 400。
- 规划材料含【语义路径】；非法路径丢弃不挡发送。
- Fast / Effort / 计划模式等 compose 行为不变。

### 自检路径

1. 打开 PWA 任务对话 → 输入 `@` → 见一级目录与文件。
2. 桌面单击目录进下级（有滑入动画）；双击目录或文件选中；窄屏点入并用「返回」。
3. 选中 → 输入框出现 chip（仅名）→ 发送 → 气泡同款 chip；入站 / 任务 meta 含 `at_dirs`。
4. 规划回合 system 旁注可见【语义路径】。
5. `GET /api/workspace/dirs?path=../../`（或绝对路径）→ 400；菜单无角色项。

## 边界

- 不做整盘 READ_ROOTS 浏览、不做硬闸「只能改这些路径」。
- 不等于角色提及；隐藏点文件/常见噪音目录不列出。
