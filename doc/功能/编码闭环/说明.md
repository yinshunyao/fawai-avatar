# 编码闭环（Cursor 对齐）

## 验收

### P0

- **精准补丁** `fs_patch`：局部唯一匹配替换；多 hunk；匹配 0/多处失败；大源码禁止无故 `fs_write` 整写（须 `force_full_write`）。`hunks` 可为 JSON 数组字符串（自动解析）；`old`/`new` 含「…」或以 `...` 收尾视为截断并拒绝；目标 path 不存在时明确提示先 `fs_glob`/`fs_read`。`old` 未命中 → `【补丁锚点未接地】`（禁止按意图编造）+ 尽量附原文小窗。成功回执 `fs_patch {path} · applied`；步骤指纹含 hunk 正文哈希。与 expect 假失败关系见 [动作段预期闸](../动作段预期闸/说明.md)。
- **仓检索**：`fs_grep` 支持 `context_before` / `context_after`；`fs_read_many` 限额多读；**不限制** pattern 最短长度（体量靠 `head_limit`/`path`/`glob`）。
- **同批只读继续**：一步内多条只读动作（`fs_grep`/`fs_read`/`fs_glob`/`explore_search`/`code_*` 等）时，前一条失败**不**掐后续只读；写类 / 前台 / 带 `write_resources` / `shell` 仍 fail-fast。避免「短词检索失败导致同批多字检索未执行」。
- **改码回证** `code_check`：按后缀跑默认检查（`.py`→`py_compile`）；`args` 须 `path`/`paths`/`command`（兼容 `file`/`files`/`cmd`）；缺参且本任务 `write_set` 非空时闭环回填；失败不得把编码目标直接标 success。
- **编码跑测**：`code_check` / `fs_*` / `code_*` / `git_*` / `explore_*` 不受 `FAWAI_DRY_RUN`；白名单 `shell_verify` 可跑校验命令。
- **会话 Diff**：写后 progress/`card` 带 unified diff 摘要；`FAWAI_DIFF_MODE=auto|confirm`（默认 `auto`）；confirm 下须口令 `确认补丁` / `拒绝补丁`。

### P1

- **Git**：`git_status` / `git_diff` / `git_commit`（commit 须显式；不自动 push）。
- **多文件改动清单**：写类动作须填齐 `write_resources`；闭环汇总清单路径。
- **编码上下文**：规划注入 `AGENTS.md` / `.cursor/rules` 摘要（可截断）。
- **逐步工具调用**：编码类目标可走原生 tool_calls（`FAWAI_NATIVE_TOOLS`，默认开）；写入分层路径时自动绑定默认 `doc_refs`（见 [守规约束](../守规约束/说明.md)）；工具 args 若误嵌套一层 JSON/`args` 键，规划侧展平后再执行。
- **探仓（暂时降权）**：缺 path 时**优先** `fs_grep` / `fs_glob`（须收窄 `path`/`glob`）。`explore_search` 仅多关键词并行；**默认只 grep**（不建符号索引）；`include_symbols=true` 或 `symbols_query` 才跑 symbols；省略/`*` 的 glob 默认收窄到常见源码后缀。已有明确 path 应定向读改，禁止为探仓而探仓。
- **探索进度闸门（默认关）**：多轮分片只读取证属正常，**默认不限制只读轮次、不强制 mutate**。仅显式 `FAWAI_EXPLORE_ONLY_GATE>0` 时注入软提示（提效 / 读不到则 failed）；仅显式 `FAWAI_EXPLORE_ONLY_ABORT>0` 才启用实验性【探索改写强制】。同 path 反复读/重叠窗加速 streak 仅在闸门开启时有意义。
- **定位预算（默认关）**：多轮分片/`fs_read` 小窗取证属正常，**默认不限制只读轮次、不强制 mutate**。仅当显式 `FAWAI_LOCATE_BUDGET_STEPS>0` 时注入软提示（提效/读不到则 failed，不逼写）；仅当显式 `FAWAI_LOCATE_FORCE_STEPS>0` 才启用实验性【定位改写强制】。锚点质量排序（源码 path:line 优先）仍可用于提示与复盘。读效率问题后续优化检索/小窗，而非用步数逼写。
- **探索闸行为武装**：本 run 已出现成功只读探索且 `write_set` 仍空时，即使口语 goal 漏检编码启发式，也启用探索 streak 跟踪（与定位锚点武装并列）。
- **宽检索降质（默认关）**：`FAWAI_WIDE_GREP_HITS` 默认 `0`，不再注入 `【宽检索降质】`。检索体量靠工具 `head_limit`（硬顶 100）与 `context≤5`；达上限由模型自行加大 limit 或收窄翻页。显式 `>0` 才恢复旧降质闸（实验/回退）。
- **工具观察压缩（默认关）**：`FAWAI_TOOL_OBS_SOFT_CHARS` / `HITS_SOFT` 默认 `0`，hits/stdout **不压缩、不二次截断条数**；回灌与工具返回对齐。单行命中正文工具侧硬顶约 500 字。显式 `>0` 才启用 soft 压缩与未读 dump 闸。
- **过程相位（规划）**：系统提示要求定位 → 取证 → 改写/作答 → 验收；压缩摘要不算取证完成。
- **弱写入闸门**：`fs_patch` / `fs_replace` 成功后若 diff 仅为未 `var()` 引用的 CSS 自定义属性、或仅空白/注释，标注 `weak_write` 并注入 `【弱写入】`；在消化前禁止 `status=success`。`write_set` 非空 ≠ 验收通过。
- **可见副作用闸门**：页面/布局/样式类目标在已有写入后，空 `actions` 的 `success` 也须再走收尾轮；`thought` 须说明用户可见变化（可对照 diff/@media；附图目标须对照图中问题）。占位文案（如 `native tool_calls`）重试一次仍不合格，或自认无可见变化 → `failed`。**实机截屏 / 桌面 Chrome / 浏览器打开属可选验收**；做不到不得因此 `failed`。若要验窄屏，用 `browser_navigate(viewport=mobile)`→`browser_snapshot`，勿桌面截屏冒充手机。
- **规划历史窗**：规划前压缩 history（近窗全文 + 远窗摘要，同 path 只读去重）。超窗时先做一次 compact，摘要留下做过什么、得到什么结论，并按旧历史指纹缓存；模型调用失败才退回「工具名 / 路径 / 成败」的机械摘要。摘要不写「禁止再读」；没写进摘要的事实仍要定向再读。口令不进入这份摘要。
- **步骤待办**：没有任务图的执行循环另维护最多 8 条待办，状态只有待办 / 进行中 / 已完成。清单每轮单独注入规划，不放进会被压缩的历史，并写入检查点。有任务图的监管脑不维护这份清单。
- **工具结果回灌**：默认全文回灌（soft/hits soft 关）；`fs_read` 读多少回灌多少；`fs_grep` hits 展开工具返回的全部命中。体量靠工具参数，不靠观察侧压缩。

## 边界

- 不对齐 Tab / 内联编辑；P0 无向量检索。
- 不自动 `git push` / force。
- 自我进化禁改名单仍生效。
- Diff confirm 默认关（`auto`）；强快照仍开。
- 探索闸门不替代步骤重复；二者可同时触发。闸门 inject / 强制改写靠 history 标记驱动规划侧 `mutate_prefer` 工具面，不只依赖模型读文案。
- 弱写入 / 可见副作用闸门不替代探索闸门：前者管「写出质量与收尾判定」，后者管「探索→改写相位」。
- **反省开读 / 开读须改写（已退役）**：不再由闭环注入、也不再禁 `fs_read`/`fs_grep`/`fs_glob`。旧标记文案保留符号但不驱动工具面。补丁失败仍靠失败回执「原文小窗」+ 步骤重复/反省换指纹；路径 not found 时允许重新定位。
- 历史窗只影响送入规划的副本；闭环落盘/检查点仍保留较完整 history。

## 环境变量

| 变量 | 默认 | 含义 |
|:---|:---|:---|
| `FAWAI_DIFF_MODE` | `auto` | `auto` 立即落盘并推 diff；`confirm` 暂存待确认 |
| `FAWAI_NATIVE_TOOLS` | `1` | 编码类目标用原生 tool_calls |
| `FAWAI_FULL_WRITE_LINE_LIMIT` | `80` | 已存在文件超过此行数禁止无 force 的 `fs_write` |
| `FAWAI_EXPLORE_ONLY_GATE` | `0` | 连续只读软提示阈值；默认关；`>0` 才注入【探索进度闸门】（不逼写） |
| `FAWAI_EXPLORE_ONLY_ABORT` | 未设=`0` | 实验：强制改写绝对步数；须显式 `>0`；不再默认 2×GATE |
| `FAWAI_EXPLORE_REPEAT_READ_BOOST` | `3` | 同一 path 成功 `fs_read` 达此次数时探索 streak 额外 +1；`0`=关 |
| `FAWAI_EXPLORE_OVERLAP_READ_BOOST` | `1` | 同 path 成功 `fs_read` 行窗与历史窗口重叠时 streak 额外 +1；`0`=关 |
| `FAWAI_LOCATE_BUDGET_STEPS` | `0` | 定位后只读软提示阈值；默认关；`>0` 才注入【定位预算】（不逼写） |
| `FAWAI_LOCATE_FORCE_STEPS` | `0`（未设=关） | 实验：定位后强制改写绝对步数；须显式 `>0`；不再默认 budget+1 |
| `FAWAI_WIDE_GREP_HITS` | `0` | 宽检索降质；默认关；`>0` 才按命中数注入 |
| `FAWAI_WIDE_GREP_FILE_HITS` | `0` | 单文件命中阈值；默认关；`0`=沿用目录阈值 |
| `FAWAI_WEAK_WRITE_GATE` | `1` | 弱写入检测与 success 拦截；`0`=关 |
| `FAWAI_VISIBLE_EFFECT_GATE` | `1` | 页面/布局类收尾须说明可见副作用；`0`=关 |
| `FAWAI_HISTORY_KEEP_RECENT` | `8` | 规划历史近窗保留消息条数 |
| `FAWAI_HISTORY_MAX_CHARS` | `18000` | 规划用 history 压缩后字符软上限 |
| `FAWAI_TOOL_OBS_SOFT_CHARS` | `0` | 工具观察 soft；默认关；`>0` 才压缩 stdout 等 |
| `FAWAI_TOOL_OBS_HARD_CHARS` | `6000` | soft 开启时压缩后硬截断 |
| `FAWAI_TOOL_OBS_HITS_SOFT_CHARS` | `0` | hits soft；默认关（全文回灌）；`>0` 才按字符压缩 |
| `FAWAI_TOOL_OBS_FS_READ_LINES` | `0` | `fs_read` 回灌硬顶；`0`=与本次读到行数对齐；`>0` 才额外封顶 |
