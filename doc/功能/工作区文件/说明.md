# 工作区文件

## 验收

- **写**：仅在 `FAWAI_WORK_ROOT` 内写入/替换；默认先自动打版本快照（可关）；写路径须走资源清单闸门（若挂了总管）。
- **读**：`fs_read` / `fs_grep` 可走 `FAWAI_READ_ROOTS`（默认 `/`，整盘只读）；相对路径仍相对 work_root；绝对路径须落在 work_root 或只读根。
- **查找**：`fs_glob` 默认扫 work_root；也可传 `path`（经 `FAWAI_READ_ROOTS`）从该目录扫——**不得**静默忽略 `path` 仍只扫 work_root。`fs_grep` 的 `path` 同为只读根下绝对路径。
- **纯后台**，不占用前台 lease，不涉及键鼠/GUI。
- `fs_glob` 支持路径前缀 + `**`（如 `fawai_avatar/**/*.html`）与 `{html,js}` 花括号；`path=/` 时 pattern 须含明确字面量；不得对已传 `path` 静默空返回。仓外 `path` 优先 `rg --files`（权限噪点不拖成慢 walk）。
- **读失败拒因**：文件不存在 → `not found (file missing)`（明确 ≠ 沙箱越界）。文案按父目录分流：父目录已在 →「路径闸已放行，仅该文件名缺失」，禁止当成拼接错误空读；父目录也不在 / 相对路径可疑 → 才提示核对拼接或 `fs_grep` basename。路径闸拒绝 → `path escapes work root and read roots`（与 missing 分码文案）。
- `fs_grep` 主参数为 `pattern`（兼容误写的 `query`）；**不限制** pattern 最短长度（1～2 字亦可）；体量靠 `head_limit`/`path`/`glob` 收窄。命中经工具结果观察回灌 `path:line` 正文；**不会**落成 `grep_result_*.txt`。超长结果压缩时用观察给出的绝对落盘路径再 `fs_read`。
- `fs_read` / `fs_read_many` 正式参数为 `offset` + `limit`（1-based 起始行）；兼容误写的 `start_line` / `end_line` / `line`；`offset`/`start_line`/`line`=0 按文件头收成 1（容忍 0-based 习惯）。
- `fs_replace` / `fs_patch` 的 `old` 须与文件原文完全一致；只能从 `fs_read`/失败回执「原文小窗」逐字复制，禁止按意图编造。
- `fs_patch`：`hunks` 支持 JSON 数组字符串自动解析；解析失败或类型不对时错误信息写明收到的类型。
- 锚点质量门：`old`/`new` 含 Unicode「…」或以 `...` 收尾 → 拒绝并提示先 `fs_read`；目标文件不存在 → `target missing` + 禁止臆造 path。
- **补丁锚点未接地**：`old` 不在文件中 → 报错带 `【补丁锚点未接地】`，并尽量附上按记号命中的原文小窗供逐字复制；「请先 fs_read」≠ 无限只读许可证。
- 启动：macOS 在只读根含 `/` 时引导「完全磁盘访问」；写仍永不越出 work_root。

## 边界

- **写禁止**逃出工作根；读可越出至 `FAWAI_READ_ROOTS`。设 `FAWAI_READ_ROOTS=work` 可收回为仅 work_root。
- 禁止用 `shell cat/cp` 读本机文件绕过 `fs_*`（代码硬拦；ssh/rsync 部署放行）。
- 默认跳过 `.git` / `.venv` / `__pycache__` 等；默认禁止写入 `.env`。
- 不做 GUI 选文件；大文件读取须带 `offset`/`limit`（或等价别名）。
- **定位文件策略**：已有 path → 定向 `fs_read`/`fs_patch`；缺 path 再用 `fs_glob` / `fs_grep` / `explore_search`（explore 须检索词）；连续空结果或要看目录树再用 `shell`（`ls`/`find`）。macOS 用 BSD `find -name`，勿用 GNU `find -printf`；Linux 可用 GNU 扩展，但优先与 macOS 通用写法。
- 质量门不拦截源码中部合法的 Python `...`（Ellipsis）；只拦收尾截断与「…」。
