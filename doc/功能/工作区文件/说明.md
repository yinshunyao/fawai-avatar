# 工作区文件

## 验收

- 可在 `FAWAI_WORK_ROOT` 内：**查找**（glob/grep）、**读取**、**写入/替换**文件内容。
- **纯后台**，不占用前台 lease，不涉及键鼠/GUI。
- 写入默认先自动打版本快照（可关）；写路径须走资源清单闸门（若挂了总管）。
- `fs_glob` 支持路径前缀 + `**`（如 `fawai_avatar/**/*.html`）与 `{html,js}` 花括号；不得静默空返回。
- `fs_grep` 主参数为 `pattern`（兼容误写的 `query`）；命中经工具结果观察回灌 `path:line` 正文；**不会**落成 `grep_result_*.txt`。超长结果压缩时用观察给出的绝对落盘路径再 `fs_read`。
- `fs_read` / `fs_read_many` 正式参数为 `offset` + `limit`（1-based 起始行）；兼容误写的 `start_line` / `end_line` / `line`；`paths` 须为真实工作区路径。
- `fs_replace` / `fs_patch` 的 `old` 须与文件原文完全一致；匹配失败时先定向 `fs_read` 再改。
- `fs_patch`：`hunks` 支持 JSON 数组字符串自动解析；解析失败或类型不对时错误信息写明收到的类型。
- 锚点质量门：`old`/`new` 含 Unicode「…」或以 `...` 收尾 → 拒绝并提示先 `fs_read`；目标文件不存在 → `target missing` + 禁止臆造 path。

## 边界

- 禁止逃出工作根；默认跳过 `.git` / `.venv` / `__pycache__` 等。
- 默认禁止写入 `.env`。
- 不做 GUI 选文件；大文件读取须带 `offset`/`limit`（或等价别名）。
- **定位文件策略**：优先 `fs_glob` / `fs_grep` / `explore_search`；连续空结果或要看目录树再用 `shell`（`ls`/`find`）。macOS 用 BSD `find -name`，勿用 GNU `find -printf`；Linux 可用 GNU 扩展，但优先与 macOS 通用写法。
- 质量门不拦截源码中部合法的 Python `...`（Ellipsis）；只拦收尾截断与「…」。
