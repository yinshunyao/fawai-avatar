# 脚本铲子生命周期

## 验收

### P0（必要，按优先级先后）

- **`shovel_search`**：按 query 检索 `fawai_shovels` 文首 meta（id/title/when_to_use/tags/path/invoke/三维分）；缺台账目录时明确失败文案。
- **选型序**：能力清单工具 → 已有铲 → 临时 `py_*` / `fs_write`+`shell`；改产品源码仍 `fs_patch`。
- **写前软闸**：拟造临时脚本/临时代码且本 run 尚未成功 `shovel_search` → 注入【铲子优先】并重规划一轮（不执行该批造脚本动作）；`FAWAI_SHOVEL_SEARCH_GATE=0` 可关。
- **实现约束（规划提示）**：参数/env 传需求；禁止明文口令与未公开绝对路径进脚本正文；通用性≥3 才进公共铲。
- **写后软提示**：本 run 有成功临时脚本/会话 `py_write` 且将 `success` 时，注入一次【铲子提炼】（自评三维分；≥3 落铲或 `skill_write`）；不阻断 success；`FAWAI_SHOVEL_PROMOTE_HINT=0` 可关。
- macOS / Linux headless 均可（只读台账 + 提示，无 GUI）。

### 可选（可砍）

- 硬闸：未搜铲直接拒首次造脚本（默认关，`FAWAI_SHOVEL_SEARCH_HARD=1` 才开）。
- 独立 `shovel_register` 工具（首期用 `fs_write` + `catalog.py --check`）。

## 边界

- 不做任务完成默认自动蒸馏/棘轮升铲。
- Skill ≠ 铲；升铲须遵守 `fawai_shovels/SHOVEL.md`（文首 meta、台账、脱敏）。
- 不替代编码闭环与 Python 扩展路径闸。

## 环境变量

| 变量 | 默认 | 含义 |
|:---|:---|:---|
| `FAWAI_SHOVELS_ROOT` | 空=自动探测 | 铲根目录；兼容 `HIPP_TOOLS_ROOT` |
| `FAWAI_SHOVEL_SEARCH_GATE` | `1` | 写前【铲子优先】软闸 |
| `FAWAI_SHOVEL_SEARCH_HARD` | `0` | 未搜铲则本步造脚本动作直接失败 |
| `FAWAI_SHOVEL_PROMOTE_HINT` | `1` | success 前【铲子提炼】软提示 |
