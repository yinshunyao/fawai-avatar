# 系统日志

## 验收

- 控制操作成功回执**不**进入会话气泡 / `session_history`。
- **复盘除外**：复盘正文与状态卡仍进任务会话。
- 落盘：`data/system_logs.sqlite`；字段含 `category` / `action` / `actor` / `task_id` / `ok` / `message` / `detail`。
- **降级**：库初始化失败时网关仍起服（`available=false`）；本页空列表并提示去「服务与版本」看后台日志 / 一键修复；不阻塞对话与任务。
- **订阅**：PWA 按**大类 + 操作**勾选；勾选决定是否**记录**（非仅筛选）；偏好持久化；**默认全开全记**；改订阅只影响之后写入。
- **可订阅大类**（界面中文；落盘英文码）：
  - **任务操作**：删除 / 归档 / 取消归档 / 取消 / 暂停 / 恢复（UI、REST、口令、AI 触发同源）
  - **文件操作**：读取 / 写入（含替换、补丁）；`detail` 含路径与行号/行范围（有则记）
  - **命令**：执行命令（`shell` / `shell_verify` 等）；`detail` 含实际命令行
  - **代码与程序**：`code_*` / 探仓等；`detail` 含路径或程序标识
  - **鼠标与截屏**：点击 / 键入 / 热键 / 截屏；截屏**只记路径**（不入库原图）
- Web：`GET /api/system-logs`（可按 category/action/ok 筛）；`GET|PUT /api/system-log-subscriptions`；口令同网关。
- 失败：写系统日志（若该类已订阅）；REST HTTP 错误；聊天口令失败可再发一条会话 `error`。
- **界面**：左侧导航「系统日志」进入管理页（订阅折叠区 + 筛选工具栏 + 列表）；不占用右侧抽屉、不进顶栏按钮。
- **一键分析（失败）**：失败行「分析」、工具栏「一键分析失败」→ `POST /api/system-logs/analyze`；**复用任务对话**自动建整改任务，goal 写清目标/要求/边界（工具实现 vs 描述/调度增强），并开跑 Worker。
- **分析状态**：落盘 `analyze_task_id` / `analyze_ts`；已分析默认跳过，界面显示「已分析 / 查看」；`force=true` 或「重分析」才新建。原整改任务已删则清标记后可再分析。

## 边界

- 不做任务 lifecycle / lease 心跳全量镜像。
- 不做大脑规划思考原文；**已执行动作**可记。
- 首期进入管理页拉取即可；可不做 WS 实时推送。
- 不做历史会话里旧控制 card 的批量清理。
- 订阅作用域：全局一份（不做按任务订阅）。
- 一键分析只针对 `ok=false`；不替代人工复盘；不绕过自我进化最少核禁改路径。
- 分析状态按 log 条目标记，不做跨机器同步。

## 实现映射

| 规范名 | 路径 |
|:---|:---|
| 系统日志 | `fawai_avatar/channel/system_log.py::SystemLogStore` |
| 订阅目录 | `system_log.py` 内 `LOG_CATALOG` + `data/system_log_subscriptions.json` |
| 写入入口 | `hub.log_system`（任务操作）；`Controller.execute`（文件/命令/代码/鼠标）；`WorkerLoop._observe`（截屏） |
| 一键分析 | `channel/log_analyze.py` + `hub.start_log_failure_analysis`；`POST /api/system-logs/analyze` |
| API | `GET /api/system-logs`；`GET|PUT /api/system-log-subscriptions`；`POST /api/system-logs/analyze`（`lan_gateway.py`） |
| PWA 管理页 | `fawai_avatar/channel/static/index.html`（左导航 + `#logsPage`） |
