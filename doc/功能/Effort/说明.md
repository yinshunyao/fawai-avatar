# Effort

## 验收

- 会话 compose **模式**面板内有 **全力** 开关；默认关；本机记住上次选择。关态悬停不得变绿（盖过全局 `button:hover`）。
- 发送/追问/追加/附图入站可带 `meta.effort`；写入任务 `meta.effort`（bool）。
- **Effort 关**：观察反省 / 规划按平衡收束；允许合理基线够用收尾。
- **Effort 开**：观察反省提示收紧 `enough_to_answer`；规划须继续必要路径；执行反省清洗「因相对路径/cwd 失败就停止必要路径」类约束，并要求先换绝对路径/`cwd`/铲子。并强调：能力清单只约束选型，**不**限制生成正文/脚本；禁止因「无创意 skill / 编排元概念」早退。
- 开 Effort **不**换模型、**不**关写租约 / shell 禁绕过 fs / 取消等硬闸；**不**等于取消真硬闸（实名/支付等）。
- 语义：围绕目标尽量做完；计划子任务继承后**每节点**同样尽量完成。可由 [执行配置自动模式](../执行配置自动模式/说明.md) 按分析打开。

## 边界

- 不等于深度思考、不等于 Cursor Auto 模型路由。
- 与 [Fast（极速）](../Fast/说明.md)、[分档（步级执行档）](../步级执行档/说明.md) **解耦**：可各自开/关，互不强制关掉对方。
- 首期仅布尔开/关，无 `low/medium/max` 多档。
- 不等于强制无限烧轮；止损与取消仍有效。
