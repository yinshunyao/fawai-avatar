# 界面多语言

## 验收

- PWA 支持 **中文（zh-CN）** 与 **英文（en）**；**宽屏**顶栏与系统配置「界面语言」可随时切换；**窄屏（≤859px）顶栏不展示语言段**，仅在系统配置中切换。
- 偏好存本机 `localStorage`（`fawai_locale`）；刷新后保持；未设置时按浏览器语言猜测。
- 顶栏品牌名与连接状态（已连接 / 未连接 / 重连中等）随语言切换即时重译；登录门闩页优先刷新，不残留上一语言。
- 导航（含窄屏顶栏菜单）、门闩、任务管理、系统日志、服务与版本、模型配置、系统配置、气泡壳、状态/阶段枚举展示名随语言切换。
- 静态文案用 `data-i18n*`；动态文案用 `tr(key)` / `tOr(key, fallback)`（勿命名为 `t`，避免与任务参数 `t` 撞名）。
- 设置项 / 日志大类·操作：优先目录键，缺键时回退服务端中文 label。
- 复盘等协议口令仍发稳定词（如 `ok`），与按钮展示语言无关。
- **progress / card 的 `meta.phase`（强制）**：凡代码里新增或改名会话可见阶段码（如 `obs_reflect`、`verify_read`），**同一回合**在 `zh-CN.json` 与 `en.json` 补 `phase.<码>`；中文条目不得仍是英文码。PWA 用 `phaseLabel` → `tOr("phase."+code, code)`，缺键会直接露英文码。自检：`channel/selfcheck.py` 的 `_check_progress_phase_i18n`（`python -m fawai_avatar.channel.selfcheck`）。

## 边界

- 不翻译 LLM / 工具原始输出与用户消息正文。
- 不写服务端语言账本；不写入 `.env`。
- 首期仅 zh-CN / en。

## 实现映射

| 规范名 | 路径 |
|:---|:---|
| 界面多语言 | `fawai_avatar/channel/static/i18n.js`；`static/i18n/zh-CN.json`；`static/i18n/en.json`；PWA `static/index.html`（`#langSeg` / `#langSegSettings`） |
| progress 阶段文案闸 | `fawai_avatar/channel/selfcheck.py`（`_check_progress_phase_i18n`） |
