# 界面多语言

## 验收

- PWA 支持 **中文（zh-CN）** 与 **英文（en）**；顶栏与系统配置「界面语言」可随时切换。
- 偏好存本机 `localStorage`（`fawai_locale`）；刷新后保持；未设置时按浏览器语言猜测。
- 顶栏品牌名与连接状态（已连接 / 未连接 / 重连中等）随语言切换即时重译；登录门闩页优先刷新，不残留上一语言。
- 导航、门闩、任务管理、系统日志、服务与版本、系统配置、气泡壳、状态/阶段枚举展示名随语言切换。
- 静态文案用 `data-i18n*`；动态文案用 `tr(key)` / `tOr(key, fallback)`（勿命名为 `t`，避免与任务参数 `t` 撞名）。
- 设置项 / 日志大类·操作：优先目录键，缺键时回退服务端中文 label。
- 复盘等协议口令仍发稳定词（如 `ok`），与按钮展示语言无关。

## 边界

- 不翻译 LLM / 工具原始输出与用户消息正文。
- 不写服务端语言账本；不写入 `.env`。
- 首期仅 zh-CN / en。
