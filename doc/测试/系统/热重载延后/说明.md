# 热重载延后

| 字段 | 值 |
|:---|:---|
| 类型 | 系统 |

## 目标

证明代码热重载闸门：存在 `running` / `blocked` 任务时不可立刻应用重载；`waiting` / `pending` 不挡；取消执行中任务后恢复可应用。

## 前置

- 本机可跑 Python 包 `fawai_avatar`
- 无需真实 LLM / 网关 / 保活进程（只测 `reload_gate` 与任务库）

## 步骤

1. `python -m fawai_avatar.demo_reload_defer`
2. 观察输出含 `demo_reload_defer ok`

## 期望

- 空库 / 仅 `pending`/`waiting` → `should_apply_code_reload` 为真
- 存在 `running` 或 `blocked` → `has_active_executing_tasks` 为真、不可立刻应用
- 取消执行中任务后重新放行

## 失败征兆

| 现象 | 优先怀疑 |
|:---|:---|
| `waiting` 也挡重载 | `EXECUTING_STATUSES` 误扩 |
| `running` 不挡 | 未读到 `tasks.sqlite` / data_dir 不一致 |
| `blocked` 不挡 | 闸门漏查 `blocked` |
