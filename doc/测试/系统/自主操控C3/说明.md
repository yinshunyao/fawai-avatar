# 自主操控 C3（系统）

## 目的

验证提示档不误判 `fs`、能力含 `ui_*`、`obs_ax` 平台降级、DRY_RUN 接地动作；可选真机 TextEdit 闭环。

## 命令

```bash
cd fawai-avatar
.venv/bin/python -m fawai_avatar.demo_c3
# 真机（需辅助功能 + pip install -e '.[gui]'）：
# FAWAI_C3_LIVE=1 FAWAI_DRY_RUN=0 .venv/bin/python -m fawai_avatar.demo_c3
```
