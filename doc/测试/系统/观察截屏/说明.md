# 观察截屏

| 字段 | 值 |
|:---|:---|
| 类型 | 系统 |

## 目标

验证观察层能出图并给出 LLM 可读摘要；失败时权限引导可理解。换 macOS 权限或截屏实现后必测。

## 前置

- macOS：屏幕录制权限（及实现路径所需能力）；进程启动时应已一次性请求过（见控制侧 `ensure_startup_permissions`）。
- 人机闸门：首次可能弹系统设置，需真人点允许。

## 步骤

1. 确保允许本机 Python/终端屏幕录制。
2. 调用 `observe(<某目录>)`，或改跑带 capture 的冒烟入口。
3. 检查输出目录是否有截图文件；摘要是否含尺寸/路径等可读字段。
4. （可选）故意撤销屏幕录制权限，再调一次，看错误/引导是否清晰。

## 期望

- 授权时：有截图文件；`Observation.summary` 非空且可供大脑使用。
- 未授权时：不静默空成功；应失败或引导打开系统设置（与控制侧权限说明一致）。
- 观察本身不修改桌面状态（不点键鼠）。

## 失败征兆

| 现象 | 优先怀疑 |
|:---|:---|
| 黑屏/全黑图 | 权限未真正授予或截的是错 display |
| 无文件但 ok | 写路径失败被吞 |
| 卡住很久 | `screencapture` / `mss` 阻塞 |
| 摘要无用 | 字段裁切过狠，大脑无法规划 |
