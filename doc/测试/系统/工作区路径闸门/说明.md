# 工作区路径闸门

| 字段 | 值 |
|:---|:---|
| 类型 | 系统 |

## 目标

找安全与边界问题：禁止逃出 `FAWAI_WORK_ROOT`；默认跳过危险/无关目录；密钥与 `.env` 不进版本快照。

## 前置

- 准备临时 work_root 与 data_dir（可仿 `demo_fs_version`）。
- 挂总管时：写操作须申报资源清单（可对照控制说明）。

## 步骤

1. 正常写入 work_root 内相对路径 → 应成功。
2. 尝试 `../` 逃逸、绝对路径指到根外、符号链接指外（若支持）→ 应拒绝。
3. 对 `.env` 或文档约定的密钥路径执行 `version_snapshot` / 自动快照 → 不应把密钥内容打进快照库。
4. 确认 `.git` / `.venv` / `__pycache__` 等默认不被 glob 扫进业务结果（或按实现文档跳过）。
5. 大文件 `fs_read` 不带 limit → 应受限或明确报错（若已实现 limit 强制）。

## 期望

- 任何成功写入的最终路径仍落在工作根内。
- 逃逸尝试：`ok=false` 且 message 可读。
- 快照目录中无 `.env` 明文副本（抽查 `data/versions/`）。

## 失败征兆

| 现象 | 优先怀疑 |
|:---|:---|
| `../` 写出根外 | `workspace/paths.py` 规范化缺失 |
| 快照含 `.env` | 版本忽略名单未覆盖 |
| glob 扫到整个家目录 | work_root 默认值指错 |
| 拒绝但无信息 | 错误未传到 ActionResult |
