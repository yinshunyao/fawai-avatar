# 代码索引冒烟

## 目的

验证 `code_symbols` / `code_map` / `code_index_refresh`：多语言（`.py` + `.ts`）符号、落盘复用、`explore_search` 自动借用符号、跳过 `.venv`、能力清单 mock 选型。

## 前置

- 已 `pip install -e .`（本仓 venv）
- 不依赖 LLM / 屏幕权限

## 步骤

```bash
cd fawai-avatar
.venv/bin/python -m fawai_avatar.demo_code_index
```

## 期望

- 打印 `demo_code_index: all ok`
- Python 与 TypeScript 符号均可命中；`data/code_index/` 写出 meta/jsonl
- `explore_search` 单 query 同时含 grep 与 symbols 结果
- mock 对「列符号」「仓地图」「刷新索引」分别选出对应 kind

## 失败征兆

- 解析不到方法、或扫进 `.venv`
- 能力校验把 `code_*` 当未知 kind
- explore 只有 grep 无 symbols
