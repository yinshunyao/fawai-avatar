# 取消停步

## 目标

证明执行中调用总管 `cancel` 后，工作任务闭环停止后续 observe/plan/act，任务状态保持 `cancelled`，不会反省空转烧满 `max_steps`。

## 前置

- 本机可跑 Python 包 `fawai_avatar`
- 无需真实 LLM / 截屏（demo 用慢速假大脑 + `dry_run`）

## 步骤

1. `python -m fawai_avatar.demo_cancel`
2. 观察输出含 `"ok": true`、`status=cancelled`、`error=cancelled`

## 期望

- worker 线程在取消后结束（不会卡死到超时）
- `plan_calls` 明显小于 `max_steps`（未烧满）
- 进度相位出现 `cancelled`
- 库内任务状态为 `cancelled`

## 失败征兆

| 现象 | 优先怀疑 |
|:---|:---|
| 取消后仍烧满步数 | `WorkerLoop` 未在步间/动作间隙读状态 |
| 状态变成 `failed` | 取消释放租约后走了反省 abort / fail 覆盖 |
| worker 不退出 | 暂停等待死循环或闸门未覆盖 cancel |
