# 测试任务一览

三类用途见 [AGENTS.md](./AGENTS.md)。  
改代码后至少跑**冒烟**；发版 / 大改再跑**系统**；自我改进 / 升版对照至少跑**端到端**节「自我改进=是」。细节见各任务 `说明.md`。

## 端到端

真实全系统评估**典型个人助理**能力。默认自我改进集 = `自我改进=是`（沙箱内交付、无购物支付/真外发）。机制探针与通道标加强且 `自我改进=否`。
