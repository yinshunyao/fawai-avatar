# 编码闭环冒烟

## 目标

证明 P0/P1 编码闭环工具链可离线跑通：精准补丁、检索上下文、改码回证、会话 Diff confirm、探仓、Git。

## 前置

- 已 `pip install -e .`
- 无需 LLM（含 mock WorkerLoop）
- 本机有 `git`

## 步骤

```bash
cd fawai-avatar
.venv/bin/python -m fawai_avatar.demo_coding_loop
```

## 期望

- 全部 `[PASS]`；进程退出码 0
- 末行含 `demo_coding_loop: all passed`

## 失败征兆

- `refuse full write` 未触发 → 大文件整写闸门失效
- `pending` 已落盘 → confirm 模式写穿
- `git_*` 失败 → 临时仓 init/权限问题
