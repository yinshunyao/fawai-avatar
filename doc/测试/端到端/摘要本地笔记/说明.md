# 摘要本地笔记

| 字段 | 值 |
|:---|:---|
| 类型 | 端到端 |
| 层级 | 核心 |
| 平台 | both |
| 自我改进 | 是 |

## 目标

读本地笔记再写出摘要，检验「检索/阅读 → 生成 → 落盘」是否像个人助理，而不是只聊天不落文件。

## 前置

- 真实 LLM；独立工作根。
- 预先写入 `notes/raw.md`，正文至少含三个可核验实体（例：项目名「Scanly」、日期「2026-11-03」、人名「Alice」）。
- 建议 `FAWAI_DRY_RUN=1`。

## 步骤

1. 目标：「阅读 `notes/raw.md`，把一页中文摘要写到 `notes/summary.md`；摘要须提到原文里的关键专名。」
2. 跑到终态。
3. 读 `notes/summary.md`：非空，且至少命中原文两个实体（专名/日期）。

## 期望

| 项 | 判据 |
|:---|:---|
| 产出 | `notes/summary.md` 存在且非空 |
| 忠实 | 摘要能对应原文实体，不胡编工作区外「已下单/已付款」类情节 |
| 过程 | 应先读后写；允许一次规划多步 |

## 失败征兆

| 现象 | 优先怀疑 |
|:---|:---|
| 无 summary | 未写盘或路径错 |
| 摘要与 raw 无关 | 未真正 `fs_read` / 幻觉 |
| 改写了 raw 却无摘要 | 目标理解偏了 |
