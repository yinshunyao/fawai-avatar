# 会话网关连入

| 字段 | 值 |
|:---|:---|
| 类型 | 端到端 |
| 层级 | 加强 |
| 平台 | both |
| 自我改进 | 否 |

## 目标

通道加强：Mac 起网关 → 手机同 Wi‑Fi 打开 URL → 口令通过 → 发文本入站建任务 → 能看到进度/回包。  
补 D7 / 人机闸门；**不进**自我改进默认集（默认集用沙箱内助理目标即可）。

## 前置

- Mac 与手机同一局域网；防火墙放行 `FAWAI_GATEWAY_PORT`（默认 `7980`）。
- 建议：`export FAWAI_DRY_RUN=1`（避免手机一句指令真点桌面）。
- 可选：`FAWAI_GATEWAY_PASSCODE` 固定口令，否则用启动日志随机口令。
- 人机闸门：手机浏览器操作；首次可能要信任局域网。

## 步骤

1. 启动：`.venv/bin/python -m fawai_avatar.channel.lan_gateway`（或 `fawai-gateway`）。
2. 记录终端打印的 URL 与短口令。
3. 手机打开该 URL，输入口令进入 PWA。
4. 发送一句简单文本（如「ping」或「写个测试说明」）。
5. 观察：Mac 日志有入站；手机侧有 progress / text / error 之一。
6. （可选）测暂停/取消控制口令是否映射到总管。
7. 跑自检对照：`.venv/bin/python -m fawai_avatar.channel.selfcheck`。

## 期望

- 口令错误进不去；正确则 WS 稳定。
- 文本入站触发总管 `create_task`（或等价建任务路径）。
- 出站信封类型符合会话通道约定（`text` / `progress` / `card` / `error` 等）。
- 不做桌面视频流也能完成「对话式」反馈。

## 失败征兆

| 现象 | 优先怀疑 |
|:---|:---|
| 手机打不开 URL | 非同网、端口未听、绑了 127.0.0.1 |
| 口令总失败 | 环境变量与启动打印不一致；PWA 缓存旧页 |
| 消息无回 | Hub 未挂总管 / Worker 未跑 / WS 推送断 |
| 误触真 GUI | 未开 `FAWAI_DRY_RUN` 且大脑产出了前台动作 |
