# 任务复盘验收

| 字段 | 值 |
|:---|:---|
| 类型 | 端到端 |
| 层级 | 加强 |
| 平台 | both |
| 自我改进 | 否 |

## 目标

验证按需复盘链路：建复盘任务 → 放行分析 → 勾选后备份再改；终态可删。属产品机制验收，**不是**日常个人助理目标对照。

## 前置

- 已安装包；本机可用 TestClient 路径（见自动化）。
- 真机同网 PWA 为可选加强，不挡本任务自动化通过。

## 步骤

1. 运行：`.venv/bin/python -m fawai_avatar.demo_review`
2. 确认退出码 0，分析阶段不落盘、勾选后才备份执行相关断言通过。
3. （可选手测）网关顶栏「任务」→ 复盘对话 →「放行分析」→ 勾选执行 / 取消。

## 期望

- 复盘新建独立任务；`awaiting_apply` 阶段不改代码树。
- 同意执行前有存档/快照；取消则不改。
- 完成/失败态可删；进行中须先取消。

## 失败征兆

| 现象 | 优先怀疑 |
|:---|:---|
| 未放行已改文件 | 复盘闸门回归 |
| 列表看不到历史 | `tasks.sqlite` / Hub 接线 |
| 联合复盘入口 404 | 网关路由 |
