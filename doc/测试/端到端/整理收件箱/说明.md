# 整理收件箱

| 字段 | 值 |
|:---|:---|
| 类型 | 端到端 |
| 层级 | 核心 |
| 平台 | both |
| 自我改进 | 是 |

## 目标

多步个人助理场景：把散落文本归入归档目录，并留下可对账的清单。限制少——不规定工具顺序，只验收目录态与清单。

## 前置

- 真实 LLM；独立工作根。
- 预先放入素材（可用脚本或手工）：  
  - `inbox/alpha.txt`（内容含「会议」）  
  - `inbox/beta.txt`（内容含「购物备忘」——**仅作文本主题，禁止真去购物/支付**）  
  - `inbox/gamma.txt`（内容含「旅行」）
- 建议 `FAWAI_DRY_RUN=1`。

## 步骤

1. 目标：「整理 `inbox/` 下的 txt：按主题挪到 `notes/归档/`（可建子目录或统一前缀），并写 `notes/归档清单.md`，列出原路径→新路径。」
2. 跑到任务终态。
3. 检查 `inbox/` 是否已空或仅剩说明；`notes/归档/` 下能找回三份内容；清单可对上。

## 期望

| 项 | 判据 |
|:---|:---|
| 文件落位 | 三份原文内容仍在工作区内可找到（路径可变） |
| 清单 | `notes/归档清单.md` 存在，且能对应三次移动/复制 |
| 边界 | 未打开电商/支付；未删工作根外文件 |

## 失败征兆

| 现象 | 优先怀疑 |
|:---|:---|
| 只改清单不挪文件 | 过早 success / 未读目录 |
| 原文件丢失且归档无内容 | 错误删除或写错根 |
| 反复同一步 explore | 步骤重复 / 观察未接地 |
