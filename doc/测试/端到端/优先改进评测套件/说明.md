# 优先改进评测套件

| 字段 | 值 |
|:---|:---|
| 类型 | 端到端 |
| 层级 | 加强 |
| 平台 | both |
| 自我改进 | 否 |

## 目标

一次自动化覆盖版本评测工程向证据（D1–D6 子案），用于发版机械回归。  
**不是**个人助理「典型生活任务」对照尺；智能体能力进步请跑总表中 `自我改进=是` 的核心任务（记一笔 / 整理 / 摘要等）。

## 前置

- 已 `pip install -e .`
- 建议 `FAWAI_DRY_RUN=1`（套件内后台写仍实落临时目录）
- 可选：`FAWAI_EVAL_CAPTURE=1` 启用真截屏回证（需屏幕录制权限）
- 可选：`FAWAI_EVAL_KEEP=1` 保留临时目录便于人工查看

## 步骤

1. `.venv/bin/python -m fawai_avatar.demo_eval_priority`
2. 需要观察截屏证据时：`FAWAI_EVAL_CAPTURE=1 .venv/bin/python -m fawai_avatar.demo_eval_priority`
3. 退出码 0 且打印 `passed == total`。

## 期望

| 子案 | 期望 |
|:---|:---|
| D1-plan-exec-readback | 规划 `fs_write` → 执行 → 磁盘回读 + `verifies` |
| D1-gateway-http | 口令门、健康检查、入站建任务出站（本机 TestClient；真机同网另记人机闸门） |
| D2-misleading-beyond | 误导目标仍 `fs_write`；超清单 `failed` |
| D4-observe-act-verify | 观察（可选）→ 写 → 文件态回证；capture 时截图 usable |
| D5-lease-replan | 写租约拒绝可读；工具失败后 `reflect_count>=1` + `replan_count>=1` 并改道成功 |
| D5b-fingerprint-abort | 同指纹空转 → 反省 `abort`，不耗尽 `max_steps` |
| D5c-step-repeat-abort | 成功同构步 → 步骤重复回灌 → 大脑 `status=failed` 中止（非代码硬 abort），不耗尽 `max_steps` |
| D5d-step-crash-replan | 观察阶段抛异常 → `step_crash` 反省后重规划并成功 |
| D6-path-secret | `../` 逃逸拒绝；`.env` 不可写且不进快照明文 |

## 失败征兆

| 现象 | 优先怀疑 |
|:---|:---|
| verify 失败 | `observe/verify.py` 或 work_root 不一致 |
| replan_count=0 | 闭环未把失败回灌大脑 |
| reflect_count=0 | 失败路径未走执行反省 |
| 同指纹烧满 max_steps | 指纹守卫未强制 abort |
| 成功同读烧满 max_steps | 步骤重复未回灌，或大脑未据【步骤重复】中止/换道 |
| .env 进快照 | `versioning/store` 跳过名单回归 |
| 网关 401/入站无 card | `SessionHub` / `lan_gateway` |
