# 后台文件与版本

## 目标

证明工作区读写与版本快照/查询/回退/删除在**无 GUI** 下完整可用；发版必跑。

## 前置

- 已安装包；不依赖 `FAWAI_DRY_RUN`（后台动作本就不吃该开关）。
- 无需 LLM、无需辅助功能权限。

## 步骤

1. 运行：`.venv/bin/python -m fawai_avatar.demo_fs_version`
2. 观察打印的临时 `WORK=` / `DATA=` 与各步 ok。
3. 确认末尾 `status: smoke ok` 且退出码 0。

## 期望

- `fs_write` → 再写触发自动快照并返回 `version_id`。
- `fs_read` / `fs_glob` / `fs_grep` 结果与写入内容一致。
- `version_list` 含该 id；`version_rollback` 后文件内容回到快照前。
- `fs_replace` 成功；`version_delete` 后 `version_get` 显示不存在。

## 失败征兆

| 现象 | 优先怀疑 |
|:---|:---|
| 无 `version_id` | 自动快照关闭或写入路径未进版本库 |
| 回退后内容不对 | 快照拷贝不全 / 路径相对根解析错 |
| grep/glob 空 | 忽略规则过宽或 work_root 指错 |
| 删除后仍 exists | `version_delete` 未清元数据或缓存路径 |
