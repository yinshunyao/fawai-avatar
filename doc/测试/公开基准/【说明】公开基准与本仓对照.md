# 公开基准与本仓对照

本页是「公开基准」目录的总说明：**先定分工与候选名录，尚未宣称已接入或已报分。**

## 1. 两把尺子

| 尺子 | 落点 | 回答什么 | 默认用途 |
|:---|:---|:---|:---|
| **本仓端到端** | `doc/测试/端到端/` | 在本产品运行时上，典型个人助理目标能否交付 | 自我改进、升版前后、换模型对照 |
| **公开基准** | 本目录 | 相对业界常见评测集，能力切片落在哪、差距是否可叙述 | 外证叙事、GUI/长任务短板定位、接入规划 |

评分量表（`doc/版本/评分量表.md`）吸收的是公开基准的**指标轴**（任务成功率、工具选用、接地回证等），不是把某公开题库原样当本仓回归集。

端到端文档里「原『基准』对照尺」指的是**本仓**那把；公开基准是另一把，二者可互相印证，**公开集通过不替代**「记一笔待办」等自我改进核心。

## 2. 产品边界（强制）

公开题库常含购物、支付、任意站点操作、不可逆系统改动。对本仓默认约定：

| 鼓励对照 | 禁止并进默认自我改进集 |
|:---|:---|
| 本地文件 / 笔记 / 整理 / 摘要类可脚本验收任务 | 真下单、真支付、真发信 |
| 桌面窄场景（已授权 App、可回证） | 未沙箱的「任意 App 全能」叙事 |
| 网页 DOM/a11y 类（与 `browser_*` 同族） | 用公开榜第一名话术掩盖本仓未测项 |

报公开分时须写清：**harness 版本、步数预算、是否本仓运行时、是否仅模型 API 直连**。禁止把「模型在别人 harness 上的分数」写成「fawai 版本分」。

## 3. 候选名录（草稿）

状态列含义：`未接入` = 本仓无跑通流水与版本落分；`对照用` = 量表/分析已引用轴，未跑题；`规划中` = 有意缩小集或子集复现。

| 短名 | 类型 | 主要测什么 | 与 fawai 切片 | 状态 | 公开入口（示意） |
|:---|:---|:---|:---|:---|:---|
| **OSWorld** | 桌面长任务 | 跨 App 电脑操控；成功率（SR）对标人类 | D1 / D4；对标分析里「无标准 GUI 评测集」缺口 | 未接入 | 论文与官方仓库检索 `OSWorld` |
| **ScreenSpot / ScreenSpot-Pro** | GUI 接地 | 截屏上点对元素/图标 | D4 L2；与 Pattern A/C 相关 | 未接入 | 检索 `ScreenSpot` GUI grounding |
| **WebArena** | 网页 Agent | 真实感网站上的目标完成 | `browser_*` / Pattern B；相对桌面更易先试子集 | 未接入 | 检索 `WebArena` |
| **GAIA** | 通用助理问答+工具 | 多步检索与工具调用；结果核验严 | 部分贴近「查本地再答」精神，场景偏开放网 | 未接入 | 检索 `GAIA` LLM agent |
| **AgentBench** | 多环境 Agent | 任务成功率等综合轴 | 量表 D1 设计依据；不一定整库复现 | 对照用（OS/DB 样本已落盘，**不执行**） | [AgentBench/说明](./AgentBench/说明.md) |
| **本仓迷你桌面集** | 自建（规划） | 10～30 条可脚本验收的本机任务（设置/访达/浏览器/办公窄切片） | 分析文「自建迷你 OSWorld」；可先进端到端加强项 | 规划中 | 见 [GUI 业界对照](../../分析/05-控制/01-GUI操控业界方案对照.md) |

分数随模型与 harness 变化很快；名录只钉**测什么与是否相关**，不钉死排行榜数字。需要区间感时可链分析文，分析文更新优先于本表抄数。

## 4. 拟定原则（如何加一条）

新增公开基准条目时，说明里至少写清：

1. **测什么** — 一句话能力切片（完成 / 接地 / 网页 / 安全…）。  
2. **对齐哪一维** — 映射到评分量表 D1–D7（可多维，标主维）。  
3. **与本仓端到端关系** — 互补、重叠、或暂不值得抢自我改进带宽。  
4. **接入前置** — 沙箱桌面、权限、依赖、预计人机闸门。  
5. **成功判据** — 官方脚本 / 人工核验 / 本仓 verify 能否复用。  
6. **不做项** — 例如「只报子集」「不跑支付类题」。

未满足「可复跑步骤 + 期望」前，保持 `未接入`，不得写入版本评测「已通过某公开基准」。

## 5. 建议优先级（供拍板，非已定排期）

下列均为**规划优先级**（先后），不是默认可砍项；是否开工另议。

| 序 | 方向 | 理由 |
|:---|:---|:---|
| P0 | 维持并跑满本仓 `自我改进=是` 核心 | 版本 D1 证据线；公开集不能替代 |
| P1 | 自建迷你桌面 / 文件+窄 GUI 可脚本集 | 成本低于整库 OSWorld；直接服务产品叙事 |
| P2 | WebArena 或同类网页子集（若 `browser_*` 要外证） | 与现有浏览器腿同族，环境比全桌面轻 |
| P3 | OSWorld / ScreenSpot 类正式接入 | harness 与本机租约/观察栈对齐成本高；有外证需求再上 |
