# `doc/测试/公开基准` — 业界公开 Agent 基准对照

## 目录用途

收录**业界公开评测集 / 基准**与本产品的对照说明：各自测什么、和本仓端到端如何分工、是否值得接入、接入时的边界。

本目录回答的是「外面常见尺子是什么、我们怎么对齐或避让」；**不**替代 `端到端/` 里的自我改进核心任务，也**不**在此堆版本打分表（打分仍进 `doc/版本/`）。

## 文档范围

| 允许 | 禁止 |
|:---|:---|
| 公开基准名录、测什么、与 fawai 能力切片对照 | 把未跑通的公开集写成「本版已达标」 |
| 接入优先级、harness 前置、与 D1–D7 映射草稿 | 可运行业务代码、密钥、未脱敏客户轨迹 |
| 官方仓库 / 论文链接（公开 URL） | 第二套版本总分；与冒烟断言混写 |
| 明确「只吸收指标轴、不镜像整库」的边界 | 把购物/支付/真外发类公开题默认并进自我改进集 |
| 上游**小样本**任务 JSON/jsonl（只读对照，须标许可与 SOURCE） | 把样本目录挂进 demo / CI / 版本最低任务集 |

## 目录结构

```text
doc/测试/公开基准/
  AGENTS.md
  【说明】公开基准与本仓对照.md   ← 总说明（先读）
  {短名}/说明.md                  ← 单基准说明
  {短名}/样本/…                   ← 可选：上游摘录（不执行）
```

- 新基准：先在总说明名录加一行，再视需要建 `{短名}/说明.md`。
- 上游样本：只摘可读小文件；写清 `SOURCE.txt` + 许可；**禁止**接入 `fawai_avatar.demo_*` 或发版必跑清单。
- 跑通某公开集后的**分数与结论**：写入 `doc/版本/{版本号}/评测结果.md`，本目录只保留「怎么对、测什么」与可选样本。

## 与相邻目录

| 相邻 | 边界 |
|:---|:---|
| `doc/测试/端到端/` | 本仓产品基准（主人自然语言 → 可观察交付）；自我改进默认集在此 |
| `doc/测试/冒烟/`、`系统/` | 无真实 LLM 的功能/闸门回归；与公开基准无关 |
| `doc/版本/评分量表.md` | 维度设计已吸收公开基准轴；公开集分数是外证，不是量表真源 |
| `doc/分析/` | 业界方案长文（如 GUI 对照）可链到本目录名录，不重复堆榜 |

编辑前先读本文件与 [`../AGENTS.md`](../AGENTS.md)。
