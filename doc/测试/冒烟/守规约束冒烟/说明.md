# 守规约束冒烟

| 字段 | 值 |
|:---|:---|
| 类型 | 冒烟 |

## 目标

证明规则注册表命中注入、分层写路径须 `doc_refs` / `architecture_skip_reason`、校验失败可机读拒绝；原生写自动绑定默认 `doc_refs`；JSON 计划漏声明仍拒；探索进度闸门（含强制改写 / mutate_prefer 工具面 / 反省开读放行定向只读 / 绝对路径分层）、patch hunks 字符串清洗与 stagnation grounded 清洗可用。

## 前置

- 已 `pip install -e .`
- 无需真 LLM（mock）

## 步骤

```bash
cd fawai-avatar
.venv/bin/python -m fawai_avatar.demo_compliance
```

## 期望

- 全部断言通过；末行 `demo_compliance: all passed`
- 进程退出码 0

## 失败征兆

- 无 `doc_refs` 的分层写未被拒 → 架构校验未接线
- 原生 `fs_patch` 分层写仍被拒 → 自动绑定未接线
- 规则块为空（目标含「改代码」）→ 注册表触发失败
