# 本地冒烟闭环

| 字段 | 值 |
|:---|:---|
| 类型 | 冒烟 |

## 目标

证明当前版本在**无真键鼠、默认可跳过截屏**时，总管租约、大脑规划、控制执行链路能串起来，作为发版基线。

## 前置

- 已 `pip install -e .`，在仓库根或已装包环境。
- 建议：`export FAWAI_DRY_RUN=1`
- 密钥可选：无 key 时用 mock 大脑仍应通过租约段。

## 步骤

1. 运行：`.venv/bin/python -m fawai_avatar.demo_smoke`
2. 阅读终端：应出现 LLM 配置摘要、lease checks ok、大脑与控制相关输出。
3. 确认进程退出码为 0，无未捕获异常。

## 期望

- 前台租约：第二任务抢前台失败并进入 `blocked`。
- 资源写租约：同一文件写写冲突，后申请者拿不到。
- 大脑（默认 mock）产出可执行结构；控制在 dry_run 下不真点键鼠。
- 全程无 traceback。

## 失败征兆

| 现象 | 优先怀疑 |
|:---|:---|
| lease 断言失败 | `task/leases.py` / `Supervisor` 状态机回归 |
| 大脑解析错 | `brain/planner.py` 或 mock 开关被环境变量污染 |
| 控制抛错 | dry_run 未生效，或 Action 字段改名未兼容 |
| 卡在截屏 | 意外开了 capture 且缺屏幕录制权限 |
