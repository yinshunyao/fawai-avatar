# dotenv 覆盖冒烟

| 字段 | 值 |
|:---|:---|
| 类型 | 冒烟 |

## 目标

证明磁盘仓库根 `.env` 能覆盖进程里旧的 `FAWAI_*`，避免保活重启后 Web 已保存的模型路由回退。

## 前置

- 已 `pip install -e .`，在仓库根或已装包环境。
- **不需要**真实 LLM / 网关。

## 步骤

1. 运行：`.venv/bin/python -m fawai_avatar.demo_dotenv_overlay`
2. 确认退出码 0，终端含 `demo_dotenv_overlay: all passed`。

## 期望

- `overlay_dotenv`：父进程旧 `FAWAI_LLM_TEXT_MODEL=qwen3.8-max` 被磁盘 `qwen3.7-plus` 覆盖。
- `load_dotenv(override=True)`：磁盘键覆盖已有进程环境；`override=False` 不覆盖。

## 失败征兆

| 现象 | 优先怀疑 |
|:---|:---|
| 覆盖后仍是旧模型 id | `config.overlay_dotenv` / `parse_dotenv_pairs` |
| override=False 也改了环境 | `load_dotenv` 分支写反 |
