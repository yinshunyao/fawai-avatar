# 代码索引冒烟

| 字段 | 值 |
|:---|:---|
| 类型 | 冒烟 |

## 目的

验证 `code_symbols` / `code_map` / `code_index_refresh`：多语言（`.py` / `.ts`）与 **HTML/CSS** 符号、落盘复用、`explore_search` opt-in 借用符号、`FAWAI_CODE_INDEX` 开关、跳过 `.venv`、能力清单 mock 选型。

## 前置

- 已 `pip install -e .`（本仓 venv）
- 不依赖 LLM / 屏幕权限

## 步骤

```bash
cd fawai-avatar
.venv/bin/python -m fawai_avatar.demo_code_index
```

## 期望

- 打印 `demo_code_index: all ok`
- Python / TypeScript / HTML·CSS 符号均可命中；`data/code_index/` 写出 meta/jsonl
- `explore_search` 在 `include_symbols=true` 时同时含 grep 与 symbols；默认只 grep
- `FAWAI_CODE_INDEX=0` 时 `code_symbols` 拒绝且不写 env
- mock 对「列符号」「仓地图」「刷新索引」分别选出对应 kind

## 失败征兆

- 解析不到方法、或扫进 `.venv`
- HTML 内 `button.send` / `id` 抽不出
- 能力校验把 `code_*` 当未知 kind
- 关开关后仍建索成功
