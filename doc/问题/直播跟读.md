# 直播跟读

深度思考与普通输出的焦点跟读。结论和改动都改原条。

| # | 问题 | 状态 | 结论 | 改进方案 |
|:---|:---|:---|:---|:---|
| 1 | Web 深度思考时能跟上最新 token，思考结束后焦点不跟随正常输出。 | 已确认 | 思考限高框（`.step-live-body`，约 220px）内部用 `scrollTop` 钉到正文末行，所以框内最新 token 一直可见。早期普通输出无自己的限高内滚时，外层若仍锚在思考框，输出会往下长出视野；若跟整段输出又会因段过高被「保顶部」拉回。 | 已改两轮。先：输出可见时外层跟末行 1px 锚。后：模型输出也做成与深度思考同款限高框（进行中约 220px / 完成后约 320px，框内滚动）；外层改跟输出限高框，框内 `scrollTop` 钉最新 token；用户上滚框内则暂停钉底。收起思考/步骤簇或线程已滚走时仍不抢焦点。 |
| 2 | 模型输出区过长，把会话页撑得很长，不便对照上方深度思考。 | 已确认 | 与 #1 同源：输出区原先无 max-height，长 JSON/规划正文整段展开。需要与深度思考同款限高+框内滚动，而不是靠外层线程无限拉长。 | 已改。见 #1 后半：`.step-live-content .step-live-body` 限高内滚 + 直播钉底。 |
