# `doc/问题` — 逐条问题

## 目录用途

记还在对齐的小问题：现象、已经确认的结论、改进方案。  
细节在这里改原条，不另起日期日志。不等于功能放行。

## 文档范围

| 允许 | 禁止 |
|:---|:---|
| 一题一表：问题、状态、结论、改进方案 | 可运行代码 |
| 改原条 | 把本目录条目当成已放行功能 |

## 目录结构

```text
doc/问题/
  AGENTS.md
  {短主题}.md
```

## 协作约定

| 相邻 | 边界 |
|:---|:---|
| `功能/` | 已支持行为以功能说明为准；这里只记问题和改动 |
| `分析/` | 机制对照与展望；逐条问题不堆在分析目录 |
| `议题/` | 要立项时另开议题 |

编辑前先读本文件与 `doc/AGENTS.md`。
