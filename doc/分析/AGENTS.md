# `doc/分析` — 机制对照与改进备忘

## 目录用途

沉淀**非放行**的对照结论与改进思路：说明当前机制现状、与外部产品（如 Cursor）的差异，供后续议题选型参考。  
**不等于**功能目录放行；落地须另开议题并经用户明示写入 `doc/功能/`。

## 文档范围

| 允许 | 禁止 |
|:---|:---|
| 机制现状、效果/成本对照、可选项改进方向 | 可运行代码；把本目录条目当已放行功能 |
| 链到 `功能/` / `议题/` 真源 | 与功能说明整段重复拷贝；另起平行「伪功能总表」 |

## 目录结构

```text
doc/分析/
  AGENTS.md
  {短主题}.md          # 一文一对照；命名用稳定中文短名
```

## 协作约定

| 相邻 | 边界 |
|:---|:---|
| `议题/` | 要立项落地时，从本目录结论开议题，再谈放行 |
| `功能/` | 已支持能力仍以功能说明为准；本目录只对照与展望 |
| `版本/` | 评测分数不替代本目录的机制叙述 |

编辑前先读本文件与 `doc/AGENTS.md`。
