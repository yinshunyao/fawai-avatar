# 远端取证超大输出与验收空转

证据任务（只读）：父计划 `8966b29c91a446faa2e7aa450af0649c`；监管脑节点 `n1` 子任务 `b02e007e9e10474aa577d1d431fb4269`。目标是在远端用「今天结束的最新分类训练 best 权重」跑 insect 北京测试；卡在 n1「确认训练完成并定位权重」，n2/n3 未启动。

## 目标与终态

父计划 `running`：n1 长期 `running`，步数已过 60，标签反复落在「4090最新分类权重核查 / 获取训练完成状态与权重路径」。材料显示 best 路径、history 末 epoch、metrics、测试集目录都曾出现，但节点产物键未交付，验收条不断加码。

## 用户多轮

两条追问明确纠偏：「定位的最新权重不是最新的」「最新训练应该是今天结束的」。编排脑据此恢复/加严了权重定位节点。纠偏被听见（改图、重开 n1），但**没有**钉死「何谓最新」的可交付判据（目录 mtime / history 末条 / 日志结束时间 / 无活跃进程等），也未在证据冲突时按路径分项交付或报告阻塞，因而转成更长的同族核查空转。

## 工具双栏

### 工具本身

1. **`FAWAI_TOOL_OBS_SOFT_CHARS` 默认 `0`**：`shell` stdout 不压缩。本案单步 `result_chars` 可达约 2.1e7（约 21MB）；`data/observe/*_obs_reflect.txt` 同量级。训练日志本身约 25MB，无界 `grep`/`cat` 或转义失败时会整份灌进观察管道。
2. **检查点 history 头裁切**：`runtime/checkpoint.py` 的 `_HISTORY_CONTENT_MAX=8000` 只保留内容**前缀**。超大输出里靠后的 history.json 尾部 / epoch 终值被丢掉；规划续跑只看见日志头附近的 ep1 tqdm，误判「训练未完成」。
3. **观察反省预览与禁补读冲突**：反省默认预览约 2500 字，超预算走压缩摘录，且明示禁止为补全摘录去读落盘或重跑同一命令；同时规划侧又常已丢尾。两端都看不到尾证，却被要求「禁止补读」→ 反省反复写「关键缺失」，`progress` 长期 `advanced`、几乎不到 `enough_to_answer`。
4. **`shell` 无返回体量硬顶**：控制层未见对远端 stdout 字节上限；体量门禁完全依赖可关闭的 soft 压缩。
5. **反省 alternate 可把明文带密命令写进 constraints**：本案在 shovel/`expect` 失败后，alternate 约束改写成直接 `sshpass` 命令模板，口令进入轨迹与约束（出站另议；规划/落盘可读凭据仍属高风险扩散）。

### 调用

1. 认证失败后弃铲改裸 `sshpass`，同族微调命令（换 `tail`/`grep`/`metrics`/`ps`）数十轮，未把已齐材料收成 n1 产物键。
2. 对超大训练日志做无界 `grep`（匹配 Epoch/Training 等），放大输出体量。
3. 把**可选旁证**（finish/done 字样、本机 `python3` 解析、conda 列表）抬成必要验收，证据齐了仍加码「再确认今天/最新」。
4. 远端进度闸默认关（见对照文），连续只读远端核查不会被既有 idle 闸打断。

## 机制根因

1. **超大工具结果 → 头裁切 → 假「关键缺失」**（工具本身为主）：尾部证据进不了续跑上下文，反省/规划用日志头 ep1 与 best.pt 时间打架，驱动无尽核查。
2. **探索→交付相位不切换**：节点停条件偏「确认…」，无「证据冲突时分项交付或明确阻塞」的收束；观察反省持续 `advanced`。
3. **用户纠偏未变成可验收台账**：只加严「今天/最新」，没有把判据写成可勾选项；可选探索喧宾夺主。
4. **方法族未稳住**：带密铲失败后锁进明文 `sshpass` 同构循环（调用 + 反省约束）。

## 通用优化清单

下列换掉主机名、run 目录、权重 basename 后仍成立；优先补既有层，禁止本案升闸。

| 优先级 | 层 | 补什么 | 验收 |
|:---|:---|:---|:---|
| P0 | 工具观察 / `shell` | 超大 stdout **默认**压缩或硬顶：落盘 + 头尾（及错误/目标关键词窗）；禁止默认可把数十 MB 全文塞进观察 | 同类远端日志核查不再出现千万级 `result_chars` 且 `compressed=false` |
| P0 | 检查点 / history 裁切 | 超长工具观察裁切须 **头+尾**（或结构化 digest + `dump_path`），禁止只留前缀 | 尾部指标/路径在续跑后仍可见或可按指针取回 |
| P0 | 观察反省契约 | 当规划 history 已丢中段/尾段时，禁止「禁补读」与「关键缺失」同时成立：要么保证规划侧保真，要么允许按 `dump_path` 定向回读一次 | 不再因预览头是 ep1 就循环判定未完成 |
| 其后 | 调用/闭环 | 远端「定位产物」类：必要路径台账要求路径类证据齐则交付或分项阻塞；可选关键词旁证不得无限抬杠 | 同类 n1 在路径+mtime/history 末条已齐后能收束 |
| 其后 | 反省清洗 | alternate 不得把明文口令命令模板写入 constraints；换道指向已有带密铲/环境注入族 | 轨迹约束不再扩散口令字面量 |
| 其后 | 远端进度 | 仅当显式打开 `FAWAI_REMOTE_IDLE_GATE` 时，对连续同族远端只读注入换道/收束；默认关时不要另发明「4090 权重」门 | 与既有远端闸文档一致 |
