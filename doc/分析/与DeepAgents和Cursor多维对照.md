# 与 DeepAgents、Cursor 的多维对照

对照对象：fawai-avatar **当前已支持机制**，相对 LangChain **Deep Agents**（开源 Agent harness）与 **Cursor** Agent / Plan / 子代理的公开形态。  
目的：按同一组维度看清三者各强在哪一层，避免把「库里的默认件」当成「产品该换成的主叙事」。**不等于**功能放行。

## 1. 先分清三层东西

三者不在同一货架上，直接比「功能清单谁更全」会比歪。

| | 它是什么 | 主场 | 别人怎么用 |
|:---|:---|:---|:---|
| **Deep Agents** | 观点鲜明的 **Agent harness**（库 + 可选托管） | 长程、多步、工具调用；文件与代码是默认环境 | 开发者 `create_deep_agent()` 组装，再接到自己的产品 |
| **Cursor** | **编辑器产品**里的编码代理 | 代码仓、diff、终端、索引 | 人在 IDE 里开 Agent / Plan，盯改动 |
| **fawai** | **操作分身产品**（会话 + 任务线 + 本机控制） | 桌面/浏览器/文件/shell；前台键鼠互斥是一等约束 | 用户下目标，总管建任务，Worker 在本机做完 |

Deep Agents 解决的是「一条 Agent 循环要默认带上哪些长程零件」。Cursor 解决的是「改这份仓时人怎么审、怎么接地」。fawai 解决的是「这台电脑上的事能不能被托管着做完，且坏写盘被拦住」。

```text
Deep Agents     可嵌入的运行骨架（规划可选、子代理、虚拟盘、权限、技能、记忆）
Cursor          骨架藏在 IDE 里，接地是编辑器
fawai           骨架藏在产品里，接地是本机控制 + 任务租约
```

## 2. 多维对照

| 维度 | Deep Agents | Cursor | fawai |
|:---|:---|:---|:---|
| **规划** | 可选待办（`write_todos`：pending / in_progress / completed），写在**同一条** Agent 状态里；v0.7 起默认不装 | Plan：先出可改计划再执行，人审常态；同会话 Todo | 简单目标：执行脑逐步。复杂目标：编排脑自动出**任务图**，监管脑按节点跑，成功边用规则衔接 |
| **委派** | `task` 拉起短命子代理；默认同上下文隔离，只回一份报告；可 fork 父历史；异步子代理可并行，中途 check / update / cancel | Task / 云子代理，只读探索可并行；云端可独立 worktree | 同任务内快模型委派一段再摘要回灌；计划模式是**多个工作任务**，不是一次工具调用 |
| **上下文** | 大工具结果外置到虚拟盘再按需读回；历史自动摘要；静态系统提示可缓存（Anthropic / Bedrock） | 索引 + 打开文件 + 规则进上下文；长对话靠产品压缩，策略不对外成文 | 规划提示档按目的裁剪；历史近窗 + 远窗摘要；压缩未读有闸。正文被压掉后仍可能被「勿再盲读」收成禁读而失败（见 [禁读与工作记忆](./禁读与工作记忆.md)）。大结果外置与提示缓存未产品化 |
| **执行环境** | 虚拟文件系统（内存 / 本地盘 / Store / 组合后端）+ 可选沙箱 shell + 进程内 JS 解释器；工具与 MCP 由调用方接入 | 真实工作区读写、终端、MCP；无整机前台锁 | 真实工作区 + shell + 浏览器 + 桌面 GUI；`foreground_lease` 与写路径租约 |
| **权限** | 路径 glob 的 allow/deny，先匹配先生效；**不覆盖**沙箱 `execute` | 终端/改文件常有人批；规则多数是提示 | 路径禁写、租约、`shell_guard`、计划后校验是硬闸；软规则靠命中注入，不保证 |
| **人在回路** | `interrupt_on` 按工具名暂停，可改参数再放行 | Plan 可编辑；危险操作人批；对话里随时改口 | 默认自动开跑；澄清走 `need_input`；失败节点可重试/删节点/整图重规划。缺「改图后再放行」为默认 |
| **技能** | Agent Skills：`SKILL.md` 头信息常驻，正文按需读 | Skills / Rules：`.mdc` 按 alwaysApply 或 glob 进提示 | Skill 为 JSON（何时用 / 步骤）；规划注入摘要；铲子台账另管可执行脚本 |
| **记忆** | `AGENTS.md` **整篇常驻**；Agent 可回写；跨线程靠虚拟盘 | Project Rules + Memories；仓是主记忆 | lore 可写（人审缓冲）+ Skill；检索偏子串。常驻块与主动分页仍弱（见记忆对照） |
| **耐久** | LangGraph checkpoint、interrupt 后续跑、流式事件含子代理 | 会话与云代理运行；中断恢复依产品，不是对外 checkpoint API | 任务检查点：进程重启续跑、从步骤恢复、挖掉单步；计划节点绑子任务 |
| **进化** | 文档承诺可按使用更新 memory / skills / prompts；无产品级禁改核 | 规则与记忆靠人写或产品记忆 | Skill 可写；**默认不**在任务结束时自动蒸馏；版本/闸门/保活路径智能体禁改 |
| **模型** | 任何能做工具调用的模型；harness profile 可按供应商裁工具 | 产品内切模型；强绑定 IDE 上下文 | 主模型 + 可选快模型；快模型默认关深度思考 |
| **可观测** | LangSmith 轨迹、typed stream、子代理独立流 | IDE 里看 diff / 终端 / 思考 | 任务事件、步骤簇、计划图浮层、任务统计；闸门命中还不够可观测（见守规对照） |
| **扩展方式** | 中间件插在模型调用与工具执行前后，不改运行时 | 规则文件、MCP、Skills | 改能力清单、规则注册表、闭环闸；没有对外 middleware API |
| **主战场缺口** | 不负责任意桌面 App 接地，也不做前台互斥 | 仓外 GUI 不是主叙事 | 仓内符号索引、可编辑计划、MCP 生态弱于 Cursor；编码议题已明确不做 embedding / LSP / MCP 当 P0 |

## 3. 四条机制差在哪

### 3.1 规划：待办列表、人审计划、任务图

Deep Agents 的规划是**同一上下文里的待办**。它帮助长任务不丢步骤，父代理仍看见子步骤噪声，也没有「无依赖就可并行、前台必须串行」的调度语义。

Cursor Plan 强在**人能改计划再执行**，且计划和 diff 在同一会话里。适合要盯着改仓的人。

fawai 的计划模式把编排从逐步执行里拆出去：编排脑出图，监管脑各跑一段，成功路径用规则接下游。这比待办更适合「多段工作、部分可并行、键鼠不能并行」。代价是出图质量不稳，且默认无人审就开跑（详见计划对照）。

### 3.2 委派：短命子代理 vs 快模型段 vs 工作任务

Deep Agents 子代理默认**隔离上下文、只交回一份报告**，重活不污染父窗口。异步子代理还能在飞的时候改目标或取消。这是长上下文成本上最值得学的形状。

fawai 的快模型委派更轻：同一 Worker 里跑一段机械步，失败立刻交回主脑，快模型不能再委派、不能向用户提问。它省的是主模型步数，不是一份独立权限的子代理。

计划模式的监管脑才接近「隔离执行体」：独立轨迹、父计划不吃步噪声。它比 Deep Agents 的 `task` 重（完整工作任务、租约、检查点），也因此能续跑、重试单节点。Cursor 云子代理在**改代码的隔离**（worktree）上更完整；fawai 多节点改同一仓仍靠写租约。

### 3.3 上下文：外置、裁剪、常驻

Deep Agents 把三件事做成默认件：大工具结果丢进虚拟文件再读、历史摘要、静态提示缓存。Skill 用渐进披露（头信息常在，正文才读）。

fawai 已经在做**裁剪**（提示档、规则命中上限、不全书灌规则）和**历史压缩**，并用闸防止「压缩了却当已读」。还没有把「大段工具输出自动落成可再读文件」和「静态提示缓存」做成与模型无关的产品件。

Deep Agents 的记忆是把 `AGENTS.md` **整篇钉进每轮**。这和 fawai 已经否决的「全书灌规则」是同一类成本。lore 的可写、可审更接近个人事实；不该为了对齐 Deep Agents 改成单文件常驻。

### 3.4 权限：声明式路径 vs 执行闸

Deep Agents 的权限是数据：glob、allow/deny、先匹配先生效，子代理可以比父代理更窄。官方写明：**这套规则管不到沙箱 `execute`**。壳仍然能绕过路径表。

fawai 的硬边界写在闭环里（禁写路径、租约、shell 绕过文件工具）。作者要加一条软规则，通常得改注册表或闸，不如丢一个 `AGENTS.md` / `.mdc` 便宜。可靠度排序已经在守规对照里写过：不可逆写上 fawai 更硬，软规范铺开上 Cursor / Deep Agents 的文件更轻。

人在回路的形状也不同。Deep Agents 是「这个工具调用先停」。Cursor 是「计划与危险命令先给人看」。fawai 是「边界直接拒绝或重规划，歧义才 `need_input`」。三套可以并存，不能互相替代。

## 4. 场景上谁更合适

| 场景 | 更合适 | 原因 |
|:---|:---|:---|
| 自己做一条长程编码/工具 Agent，要 checkpoint、子代理、虚拟盘 | **Deep Agents** | 骨架现成，模型可换，托管可选 |
| 在 IDE 里改仓、要审计划、要 diff 和索引 | **Cursor** | 接地和人审是产品本身 |
| 本机多 App、前台互斥、后台写不同路径、要托管跑完 | **fawai** | 租约、GUI/浏览器、任务续跑是主场 |
| 大工具输出把上下文打满 | **Deep Agents 的默认件** | 外置再读是 harness 职责；fawai 尚未产品化 |
| 必须拦住 shell 绕过写盘 | **fawai** | Deep Agents 路径权限明示不管 `execute` |
| 廉价加很多软规范 | **Cursor 规则 / Deep Agents 的 AGENTS.md** | 文件即上下文；fawai 登记才稳 |
| 只读探仓并行 | **Cursor Task**，其次 Deep Agents 异步子代理 | 无整机前台锁；fawai 编码隔离没有默认 worktree |
| 节点失败后保留已完成、只重开失败段 | **fawai 计划模式** | 依赖边 + 重试节点；待办列表没有这层调度 |

## 5. 可后续开议题的方向（非放行）

下列是对照后的备忘。落地须另开议题，经明示写入功能目录。

### 5.1 值得学的形状（若立项，按序做；后项仍在范围内）

| 序 | 方向 | 向谁学 | 落到 fawai 时应保持什么 |
|:---|:---|:---|:---|
| P0 | **大结果外置** | Deep Agents 的上下文外置 | 工具输出超预算时落任务侧文件并留指针，规划可再读；不把虚拟盘换成第二套工作区 |
| P1 | **Skill 渐进披露** | Deep Agents Skills | 头信息（何时用）可进提示，正文与附件按命中再读；不必先改成上游 `SKILL.md` 标准 |
| P2 | **闸与人停可观测** | Deep Agents 的 `interrupt_on` 可按工具配置；Cursor 侧人能看见停在哪 | 先做命中规则、闸种类、额外规划轮次的统计，再考虑少量工具级「先停再放行」；默认仍自动跑 |
| P3 | **静态提示缓存** | Deep Agents 对支持的供应商自动缓存 | 只包能力清单里稳定段；换供应商无缓存时行为不变 |

### 5.2 可选（可砍）

| 方向 | 说明 | 砍掉后仍成立的部分 |
|:---|:---|:---|
| 声明式路径权限表（YAML/glob） | 软作者体验接近 Deep Agents `permissions` | 现有代码硬闸仍拦住禁写与 shell |
| 编码节点 worktree | 学 Cursor 隔离 | 写租约仍能避免两节点同时改同一路径 |
| 接入 MCP 当工具来源 | Deep Agents / Cursor 都把 MCP 当扩展面 | 能力清单 + 铲子仍是当前工具面；编码议题已把 MCP 放在 P0 之外 |
| 可选「只出图不调度」 | 学 Cursor 人审计划 | 默认自动开跑不变 |

### 5.3 不建议照搬

- 用单上下文 `write_todos` 替换计划模式的任务图、监管脑和前台租约。简单目标可以另留一份小待办。已有任务图时，节点状态就是完成清单；多节点共用的事实由编排脑在出图时钉在图上，只获取一次。见 [窗口满后的摘要与待办](./窗口满后的摘要与待办.md)。
- 把 `AGENTS.md` 式整篇常驻当成记忆方案，冲掉「规则命中有上限、不全书灌」。
- 因为 Deep Agents 的路径权限不管 shell，就放松 `shell_guard`。
- 把产品做成对外 harness SDK。Deep Agents 的位置是库；fawai 的位置是这台电脑上的分身。
- 为对齐 Cursor 而默认要求人审每一张计划图。

## 6. 一句话结论

Deep Agents 强在**长程 Agent 的默认零件**（隔离子代理、大结果外置、声明式路径权限、技能渐进加载、可续跑的图运行时）。Cursor 强在**改代码时的接地和人审**。fawai 强在**本机操作的租约、硬边界和可恢复任务**。

下一刀若只学一件事：学 Deep Agents 把撑爆上下文的工具结果外置出去，而不是把它的待办、常驻记忆或「权限不管 shell」一起搬过来。
