# 深度思考开与供应商接线

对照：任务 `dca2648deea84233aa996d531ad3707d`（主脑 `gpt-6-sol` / 小黄）；另对照步骤卡「思考关」却有深度思考正文（模型 `deepseek-v4-pro`）。功能真源见 [LLM 接入](../../功能/01-接入与呈现/01-LLM接入/说明.md)；不等于放行。

## 三层含义不要混

| 层 | 谁决定 | 界面看到什么 |
|:---|:---|:---|
| **意图 / 角色默认** | `resolve_thinking`：主脑默认开、快模型与观察反省默认关；可被模型档案 / Fast 显式覆盖 | facts「思考开 / 思考关」（`thinking_meta.enabled`） |
| **真正发给供应商的思考开关** | `thinking_extra_body`，且仅当 `provider_supports_thinking_extra` 为真 | 无单独徽章 |
| **响应里的可见推理** | 供应商是否回 `reasoning_content` / `reasoning` / `thinking` | 「深度思考」直播区（`meta.thinking_text`） |

前端两路独立：`formatThinkingFact(meta.thinking)` 与 `updateStepLive` 的 `thinking_text` **互不校正**。因此会出现两种对打：

| 现象 | 常见机制 |
|:---|:---|
| **思考开 · 无正文** | 意图开；请求可能已写 / 未写开关；对方不回可见推理字段（小黄常见） |
| **思考关 · 有正文** | 意图关（Fast / 快模型角色 / 档案强制关）；请求**没把关发出去**或对方默认仍思考；响应仍带 `reasoning_content`，直播区照常展开 |

「执行档 · 仅执行」只分流成功后的观察反省，**不会**单独把本枪规划标成「思考关」。

## 当前接线边界

`thinking_extra_body` 按方言写入：

| 识别 | `extra_body` |
|:---|:---|
| DashScope / 千问系 / 小黄（`kklt`） | `enable_thinking`；可选 `thinking_budget` |
| 百炼上的 DeepSeek（`provider_id=dashscope` 等） | 同上 `enable_thinking` |
| 官方 DeepSeek / 模型名含 `deepseek` 的非百炼口 | `thinking: {type: "enabled"|"disabled"}`（不映射 `thinking_budget`→`reasoning_effort`） |

未知 OpenAI 兼容口仍省略，避免未知参数报错。

档案「空=跟随角色」在已接线口与百炼一致：主脑开、快模型关。

## DeepSeek（`deepseek-v4-pro` 等）

官方 Chat Completions：思考模式**默认开**；关必须显式 `thinking.type=disabled`。接线后：Fast / 快模型角色 / 档案强制关会写入 `disabled`，避免「思考关」标签空转、对方仍吐 `reasoning_content`。

仍可能对打的情况：对方忽略开关、或网关方言不是官方 `thinking.type` 也不是百炼 `enable_thinking`——此时 UI 双信号问题仍在（见上表「思考关 · 有正文」）。

**未做（可另开）**：带 `tools` 时官方要求后续回合回传 `reasoning_content`；与现网消息拼装是否齐套未在本接线验收。

## 小黄实测（Chat Completions）

对本机 `api.kklt.lol` + `gpt-6-sol`：

| 观察 | 含义 |
|:---|:---|
| `extra_body.enable_thinking` true/false **均不报错** | 配置可以、也应当写入 |
| 多数流式/阻塞回合 **无** `reasoning_content` | 步骤卡可能仍无「深度思考」展开正文 |
| `usage.completion_tokens_details.reasoning_tokens` 常有值 | 服务端可能在做隐式推理计费，但不等于可展示正文 |
| 偶发流式带回短 `reasoning_content` | 不稳定，不能当验收 |

因此：**接线解决的是「配置跟上角色/档案」**；**不等于**保证界面一定有思考反馈。可见正文仍取决于对方是否在 Chat Completions 里吐推理字段。
