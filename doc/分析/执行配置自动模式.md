# 执行配置自动模式

对照：compose「执行配置」四开关（[Fast](../功能/Fast/说明.md) / [Effort](../功能/Effort/说明.md) / [步级执行档](../功能/步级执行档/说明.md) / [复杂任务计划模式](../功能/复杂任务计划模式/说明.md)）；任务级开关问题见 [极速全力任务级开关](../问题/极速全力任务级开关.md)；逐条确认见 [执行配置自动模式](../问题/执行配置自动模式.md)。

---

## 现状

- 面板四项各自独立，默认多关；本机 `localStorage` 记住；随消息入站写入 `meta.fast` / `effort` / `step_tier` / `plan_auto`。
- **计划是否真进模**：另有编排脑 `decide_complexity`（LLM 优先，失败启发式）；`plan_auto` 只是「允许判定」，不是「必定出图」。
- **极速开**会强制跳过复杂度判定、单任务执行，并跳过观察反省；与「非简单开分档 / 计划」天然互斥。
- 用户常要手动拨四档；简单任务开全力/计划浪费，中档/复杂忘开分档则步级反省不当。

---

## 已定目标

四项各自三态（**无全局自动总闸**）：

| 项 | 约定 |
|:---|:---|
| UI | 每项：自动 / 开 / 关；默认自动；图标入口；说明悬停 |
| 自动 | 每个新任务初始化再判；面板不记「自动·开/关」 |
| 开/关 | 手工固定偏好，分析跳过 |
| 极速 | **仅** 简单任务（自动推导时） |
| 全力 | 围绕目标尽量做完；有计划则**每节点**同样尽量完成（继承） |
| 分档 | **非简单都开**（含中档） |
| 计划 | 同轮分析判定是否允许进模；是否出图仍走编排判定 |

不等于换模型；不等于取消写租约等硬闸。

---

## 策略矩阵（已确认）

| 画像 | 极速 | 全力 | 分档 | 计划模式（`plan_auto`） |
|:---|:---|:---|:---|:---|
| **简单** | **开** | 关（分析未要全力且用户未锁） | **关** | **关** |
| **中等**（非简单、通常不必拆图） | **关** | 分析要则开 | **开** | 通常关（分析 `allow_plan=false`） |
| **复杂 / 多阶段** | **关** | 分析要则开；进图后节点继承 | **开** | **开**（允许判定；出图仍由编排脑） |

推导（未锁定项）：

```text
simple=true  → fast=1, step_tier=0, plan_auto=0
simple=false → fast=0, step_tier=1, plan_auto=allow_plan
effort       → want_effort（分析）且与 fast 互斥时关极速 / 不开极速
```

显式口令：可覆盖**尚未被用户锁定**的项（「快点」→ 极速；「拆计划」→ `plan_auto` 等）。

---

## 单项锁定（已确认）

```text
总自动开
  ├─ 未锁项 ← 每次/首轮分析可回写
  └─ 已锁项 ← 用户拨过；跟用户值，分析跳过
总自动关 → 四项全手工（可清锁或保留末次值，落地时定一条）
```

UI：被锁项可辨（如副文案「已手动」）；不必因锁一项而关总自动。

---

## 判定相位（已确认）

**合并进建卡后首轮任务分析**（扩展现有复杂度/编排判定），禁止另开专轮只评四开关。

建议同响应字段（名可微调）：

| 字段 | 用途 |
|:---|:---|
| `simple` | 简单 → 极速；非简单 → 分档 |
| `want_effort` | 是否开全力（围绕目标收尾） |
| `allow_plan` / `enter` | 是否允许 / 是否进计划模式 |
| `reason` | 短说明，可上 progress |

失败 → 启发式兜底（短查询=simple；多阶段连接词=非 simple + allow_plan）。

```text
建卡 → 首轮任务分析（含 simple / want_effort / allow_plan）
     → 合并未锁项写入 meta.fast|effort|step_tier|plan_auto
     → fast=1：跳过进模（现网）
     → plan_auto 且非 fast：既有出图路径
     → effort：规划/反省收紧；计划子任务继承
```

---

## 全力语义（已确认）

- 任务级：必要路径与目标对齐，能修则修，不早早交差。
- 计划级：父 `effort` 传给监管子任务；**每个节点**按全力口径尽量完成节点目标，不因「父图还在跑」就降档糊弄。

---

## UI / 作用域（已确认方向）

| 点 | 约定 |
|:---|:---|
| 面板 | 最上「自动」（默认开）+ 四开关显示生效值；锁项可辨 |
| 作用域 | 任务级 `meta`；新建继承全局末次「自动开/关」 |
| 何时 | 建卡后首轮分析写回；progress 可一句说明选档原因 |

---

## 不做

- 不把「自动」做成第五种执行语义（它是选档总闸 + 按项锁定）。
- 不另开第二轮 LLM 只评四开关。
- 不因自动默认永久开全力（由分析 `want_effort` 定；简单默认关）。
