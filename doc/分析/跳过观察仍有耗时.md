# 跳过观察仍有耗时

| 项 | 内容 |
|:---|:---|
| 对照对象 | 进度卡「观察完成（跳过）」仍显示「耗时 Xxx ms」 |
| 目的 | 澄清「跳过」跳的是什么；落地真跳过 |
| 关联 | [功能/观察](../功能/观察/说明.md)；`observe/methods.py`、`observe/frontmost.py`、`runtime/loop.py` |

## 原现状（已改）

旧实现里「方式 跳过」=`none` 只表示不截屏、不采工作区，闭环仍会：

1. 发「观察中…」进度
2. `collect_observation` 拼说明摘要
3. **始终** `attach_frontmost`（macOS `osascript`，常见百毫秒级）
4. 发「观察完成（跳过）」并写入 `elapsed_ms`

故时间线仍见前台 App 与耗时。

## 已落地：真跳过

用户确认后已改验收与实现：

| 项 | 行为 |
|:---|:---|
| 前台探测 | `none` 不跑 |
| 观察进度 | 不推 `phase=observe`（无「观察完成（跳过）」卡） |
| 规划入模 | `skipped_env_observation` 空壳（短说明 + `observe_candidates` + 标题上下文） |
| 真实取证 | `obs_fs` / `obs_screen` / `obs_ax` 仍附前台窗摘要并推进度 |

入口：`is_env_observe_skipped` / `skipped_env_observation`；主环与快模型委派环均短路。

## 观察反省跳过（同口径已落地）

| 路径 | 时间线 | 规划 history |
|:---|:---|:---|
| `skipped_fast`（极速） | 不推 `obs_reflect` 卡 | 不写「极速跳过」占位 |
| `skipped_act` / 机械成功 | 不推跳过卡 | 仍写规则摘要（供后续规划） |
| 实际跑 brief/reflect LLM | 正常推进行中/完成卡 | 写 `【观察反省】` |

内部 `supervisor.report` 仍记 skipped_*，便于复盘，不出站时间线。

## 取舍

步 0 GUI / 纯执行后的 `none` 不再自带廉价前台态；依赖界面时须显式点选 `obs_screen` / `obs_ax`。
