# 交稿 mermaid 与出站脱敏误伤

对照对象：终稿里的 mermaid 流程图渲染，以及 Web 出站 `redact_for_client`。  
证据任务：`6d71d77272ae4268974ae8e0fe6952ef`（查看 4090 训练状态；追问预估结束时间后 `failed`）。

| 脱敏 | `fawai_avatar/channel/redact.py`；[会话通道](../功能/会话通道/说明.md) |

## 表面现象

会话里终稿下方出现两次 Mermaid「Syntax error in text」（mermaid 11.4.1 炸弹图），正文方案与表格仍在。

## 工具双栏

| 栏 | 结论 |
|:---|:---|
| **工具本身** | **P0**：出站脱敏把节点文案 `F[输入密码登录]` 抠成 `F[输入密码***`（吞掉 `]`），图源在进前端前已非法。旧正则 `(密码\s*[:=：]?\s*)(\S+)` 把「密码」后的任意非空白当口令，误伤中文词组。次要：未加引号的节点里若含 `/`、`@`、命令原文，mermaid 本身也易解析失败；失败时库会往 DOM 塞错误 SVG，前端 catch 未清理，代码块也不提示失败。 |
| **调用** | 模型按交稿规则画了 flowchart，节点里写了「输入密码登录」和带 `/` 的命令摘要——在脱敏修好前，即使用法正常也会被抠破。追问 ETA 时把 SSH `Permission denied` 写成「沙箱网络隔离」属假归因；必要路径「给出结束时间估计」未交付（缺 `max_epochs` 时应分项说明并给可算区间或交付取数命令）。 |

## 机制根因

1. **出站脱敏过宽 × 交稿 mermaid**（工具本身）：脱敏与流程图标签共享同一段用户可见正文，无「仅抠像口令的值」边界。  
2. **mermaid 失败无回退**（工具本身）：解析失败只 `console.warn`，炸弹图留在页上。  
3. **假归因 / 答复未覆盖追问**（调用+结果判定）：认证失败被收成沙箱断网；用户多次追问「什么时候训练结束」未给出基于已有 Epoch/速度的估计或明确缺参。

## 通用优化（已落 / 待选）

| 优先级 | 层 | 项 | 状态 |
|:---|:---|:---|:---|
| P0 | 工具 · 脱敏 | 「密码」须带 `:`/`：`、引号值或 ASCII 口令形态再抠；禁止抠「输入密码登录」 | 已改 `redact.py` + `demo_compliance` |
| P0 | 工具 · 渲染 | mermaid `render` 失败时删掉库插入的错误节点，保留代码块并标 `mermaid-failed` | 已改 `markdown-render.js` |
| P1 | 提示 | 交稿规则要求特殊字符标签用双引号 | 已改 `prompt_profile.report_delivery_rule` |
| P1 | 调用/闭环 | 远端认证失败勿升成「沙箱断网」；问询 ETA 须答复覆盖或分项缺参 | 未改（靠既有假归因/答复覆盖闸，不新开本案专用门） |

## 明确不做

- 不为「4090 / insect-cls-vlm / 某端口」单开预估结束时间闸。  
- 不为避开脱敏而禁止终稿出现「密码」二字；应修正则，不修文案菜谱。

## 验收

- `redact_for_client("F[输入密码登录]")` 保持原文；`输入密码 \`…\`` / `密码: x` / `sshpass -p` 仍抠掉。  
- 非法 mermaid 不再显示炸弹图，退回可见代码块。  
- 合法且标签已加引号的 flowchart 仍能画图。
