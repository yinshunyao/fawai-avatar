# 术语与称呼索引

本表是文档文字、代码锚点、LLM/Agent 工具称呼的**唯一真源**。  
规范名不可重复；会话多种说法只进「别名」，不另起规范名。

维护规则见 `AGENTS.md` 与 `.cursor/rules/rules-doc-code.mdc`。

## 怎么用

| 角色 | 用法 |
|:---|:---|
| 写文档 | 正文只用「规范名」；首次可括注常用别名 |
| 写代码 | 入口注释钉规范名或 `doc/…` 路径 |
| 与人会话 | 出现稳定新说法 → 写入别名列 |
| LLM / Agent | 调工具用「工具 id」或规范名；禁止自造同义工具名 |

## 命名约束（摘要）

1. 新概念先查本表；已有则复用规范名，只追加别名。
2. 规范名宜短、稳定、可进代码注释；避免一句口语当规范名。
3. 废弃项不删行：备注标「废弃」，别名仍可指向，避免 LLM 找回死名。
