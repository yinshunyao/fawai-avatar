# 议题：安装器与跨系统分发

范围：给普通用户（非开发者）在 **macOS / Linux / Windows** 上安装并启动本机会话网关 + keeper；交付「私有 Python 运行时前缀 + 预装依赖 + 一键启动器」三端产物。不含重做会话 UI 为原生 App；不含把 Windows GUI 操控抬到与 macOS 同等宣传（能力仍按运行平台矩阵）。

## 已定结论

1. **立项范围：三端同轮覆盖**。安装器 / 分发包从第一期就产出 **macOS、Linux、Windows** 三套工件（同构前缀布局，按 OS/架构换二进制），不做成「只先 Mac、另两端遥遥无期」。落地实现可按平台排联调先后，但**打包脚本与产物清单必须三端齐备**才算本议题主验收。
2. **主形态：私有 Python 运行时前缀（便携前缀）**，不是系统 Python，也不是默认 PyInstaller 单文件。
   - 包内自带 Python `>=3.11` 与预烘焙依赖；安装路径 **0 次手动 venv / pip**（升级走整包替换或与运行时选版分工，见下）。
   - 保留**可写**应用树（`fawai_avatar` / `fawai_lore`），以兼容自我进化、`py_pip`、运行时版本快照。
3. **装完后的主动作：起本机 Web 服务器（会话网关）**，不是装一个独立桌面聊天壳。
   - **本机**：启动器设环境 → 起 keeper/网关 → 健康检查通过后，**默认用系统浏览器打开 `http://127.0.0.1:<port>/`**（端口与现网关默认一致，如 `7980`，可配置）。
   - **远端 / 手机**：安装器**不**自动推送、不代开；用户自行在手机或其它机器浏览器里填局域网 IP / 穿透地址 / 中继 URL（及口令）。启动日志与本机 PWA 运维页可展示「可给手机用的地址」作抄写辅助，但打开动作由人完成。
   - 监听仍可按现约定绑 `0.0.0.0`（或配置项），以便同网设备能连；**自动打开的 URL 只用 127**，避免本机浏览器误走局域网网卡地址。
4. **前缀布局（三系统同构）**：

   ```text
   FawaiAvatar/
     runtime/     # 私有解释器
     app/         # 产品与 lore（可写）
     site|venv/   # 预装依赖
     bin/         # 本系统 frpc；可选 Playwright 浏览器目录
     data/        # 或重定向到用户数据目录
     Start.*      # 本系统启动器
   ```

5. **各端交付物**：

   | 系统 | 交付 | 首期能力承诺（安装器验收） |
   |:---|:---|:---|
   | macOS | 签名+公证的 `.dmg` / `.app`（arm64 与 x64 分产或通用策略另定） | 起网关 + 本机开 `127.0.0.1`；文件/shell + 桌面 GUI（既有）；TCC 引导 |
   | Linux | `tar.gz` 与/或 AppImage；可选 systemd user unit 说明 | 起网关；有桌面时可开本机 `127`；文件/shell + 可选无头浏览器；**不承诺** Linux GUI 键鼠 |
   | Windows | `Setup.exe`（Inno/NSIS 等）或解压 zip + `Start.bat` | 起网关 + 本机开 `127`；文件/shell + PWA；**GUI/AX 不按 macOS 同等宣传**，直至运行平台另议放行 |

6. **与现机制分工**：
   - **整包升级**：换 Python / 依赖大版本、启动器、旁路二进制。
   - **运行时选版**：包内代码树快照与回滚（既有能力）；不得用选版冒充「换解释器」。
   - **frpc / Playwright**：消费包内预置对应 OS 二进制，或安装器一步完成；改变「须用户手跑 playwright install」的开发态假设。
7. **明确不做（本议题）**：
   - 以 PyInstaller/Nuitka **单文件冻死**作默认消费通道（除非另开「只读运行、关自进化/`py_pip`」分轨）。
   - 让小白先装官网/系统 Python 再 pip 当主路径。
   - 为聊天再做原生会话 App（与跨端通道「不做原生 App」一致）；托盘壳仅可选后置，只保活与打开本机浏览器。
   - 安装器**代开手机/远端浏览器**，或强制二维码/自动发现配对作为首期必达（地址与口令由用户自行配置打开即可）。
   - Docker 作三端统一小白方案（仅可作 Linux 无界面旁路，非本议题主验收）。
   - 用安装器包装掩盖 Windows GUI 未产品化；对外文案须分端诚实。
8. **已放行实现**（用户明示「实现安装脚本」）：见 [功能/安装器](../../功能/安装器/说明.md)。Release 默认发到 GitHub Releases；安装包启动器与说明须 **中/英** 可选。
9. **安装包语言（已定）**：启动器文案与包内安装说明支持 `zh-CN` / `en`；`FAWAI_LANG` / `--lang` / 系统语言猜测；与 PWA「界面多语言」独立（PWA 仍用其自身 locale）。

## 依据摘要

- 分析真源：[分析/普通用户安装与跨系统分发](../../分析/普通用户安装与跨系统分发.md)：产品是本机 Python 服务 + PWA；自进化与 `py_pip` 需要真解释器与可写树。

## 可行性速览

口径：**全 AI 实现**；粗估、未核价；不等于放行或开工。

| 想法 | 难易（对 AI） | 成本与时间（粗） | 可借用资产 |
|:---|:---|:---|:---|
| **同构前缀布局 + 打包脚本骨架（三端）** | **中**。难点：路径约定与现 `FAWAI_DATA_DIR` / editable 安装对齐；CI 矩阵 | 约 **3～6 次** Agent 会话 / **约 0.5～1.5 日墙钟**；编码期 token | **可直接用**：`pyproject` extras、`fawai-keeper`/`fawai-gateway` 入口。**需适配**：从 editable 改为前缀内 site-packages 布局 |
| **嵌入私有 Python（三 OS）** | **中**。难点：各端取官方/standalone 构建、体积与许可证声明 | 约 **2～4 次**会话；下载与缓存墙钟另计 | **可直接用/需适配**：[python-build-standalone](https://github.com/astral-sh/python-build-standalone)；Windows embeddable 发行；python.org macOS 安装树裁剪 |
| **预烘焙依赖进 site/venv** | **低～中**。难点：Darwin-only pyobjc；Windows 轮子；可选 browser 体积 | 约 **1～3 次**会话 / 平台 | **可直接用**：现有 `pip install` 依赖表；`.[gui]` / `.[browser]` |
| **启动器（起网关 + 本机开 127）** | **低**。难点：健康检查后再 `open`/`xdg-open`/`start`；失败中文日志；headless 跳过开浏览器 | 约 **1～2 次**会话 | **可直接用**：`FAWAI_GATEWAY_PORT`（默认 7980）、`lan_gateway`/`keeper`；本机 URL 固定 `http://127.0.0.1:<port>/` |
| **展示局域网/穿透地址（仅抄写，不代开远端）** | **低**。难点：与现启动横幅/运维页文案对齐 | 约 **0.5～1 次**会话（可并进启动器） | **可直接用**：网关启动已打印局域网 URL 与口令 |
| **macOS 签名公证 + TCC 引导** | **中高**。难点：公证流程、权限跟签名身份走；**人机闸门**：Apple 账号、真机点「允许」 | 脚本约 **2～5 次**会话；公证联调依赖人机闸门与墙钟不确定 | **需适配**：`codesign` / `notarytool`；现有 `permissions_mac.py` 引导文案 |
| **Linux tar/AppImage** | **中**。难点：AppImage 与可写树张力；headless systemd 文档 | 约 **2～4 次**会话 | **可直接用/仅参考**：`study/配置信息/beyond-5080/fawai-avatar/部署说明.md`；AppImage 工具链 |
| **Windows Setup** | **中**。难点：杀软误报、路径空格、`Scripts\python.exe`；GUI 能力文案闸 | 约 **3～6 次**会话；**人机闸门**：真机安装点选 | **可直接用/需适配**：Inno Setup / NSIS；embeddable Python |
| **预置 frpc + Playwright** | **中**。难点：按 OS 拉二进制、体积、许可 | 约 **1～3 次**会话 | **可直接用**：现 `bin/frpc` 与 `FAWAI_FRPC_BIN`；`playwright install` 可进打包步骤 |
| **托盘壳（可选后置）** | **中**。难点：多一构建链，易滑向「原生 App」心智 | 另估；**可砍** | **仅参考**：pystray / 轻量托盘；不替代 PWA |

## 开放问题

| 优先级 | 项 |
|:---|:---|
| P0 | 可进化代码放「安装目录可写」还是「用户数据目录 overlay」（影响公证与 Program Files） |
| P0 | macOS 是否必须 Universal / 是否先只打 Apple Silicon |
| P1 | 自动更新通道（整包差分 vs 仅代码选版）是否进首期（**已落地手动 Install：默认平滑升级保留 data / 可选覆盖安装**；差分自动更新仍可选） |
| P1 | Playwright Chromium：预置进主包 vs 首次惰性下载 |
| P2 | 是否提供企业静默安装参数 |
| P2 | 商店上架（Mac App Store 等）——默认不做 |

3. 发版：打 `v*` 标签推送，或本机构建后 `bash packaging/publish_github_release.sh`。
