## 2026-11-08（装后打开方式）

- **焦点**：安装包装到目标机之后，用户怎么进界面。
- **要点**：
  - 装完后主动作仍是**启动本机 Web 服务器（会话网关）**。
  - **本机**默认用浏览器打开 `http://127.0.0.1:<port>/`。
  - **远端 / 手机**自行配置并打开对应地址（局域网 IP / 穿透 / 中继）；安装器不代开、不强制自动配对。
  - 监听可继续绑 `0.0.0.0` 以便同网接入；自动打开的 URL 只用 127。
- **对结论的改动**：新增「装完后的主动作」条；明确不做「代开手机/远端」；可行性与下一步改为「起网关 + 本机开 127」。
