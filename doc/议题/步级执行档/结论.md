# 议题：步级执行档

## 议题

规划同轮声明本步成功后观察反省深度（`reflect` / `brief` / `act`），避免另开一轮 LLM 评难度；对简单步少烧观察反省。

## 已定结论

1. 规划 JSON 增 `step_run`，与 `actions` **同轮一次写出**；禁止「先规划再 LLM 评难度」。
2. 三档语义：
   - `reflect`：完整观察反省
   - `brief`：**短观察反省**（仍调 LLM，短提示、强制关思考）
   - `act`：**规则检查**、不调观察反省 LLM（工具成功 + expect/规则过）
3. 失败一律走执行反省，与档位正交。
4. 任务级 Fast 仍可整单跳过观察反省；缺省字段跟现网（机械只读成功可规则跳过）。
5. `act` 规则不过 → 升 `brief`，不静默放过。
6. 任务级开关与极速/全力同款：compose **分档** → `meta.step_tier`（默认关）；开才写提示并按档分流，关则忽略 `step_run`。
