# 议题：Linux 无界面运行

范围：在 **无桌面会话** 的 Linux（及强制 headless）上跑会话网关 + 编码/文件/shell；大脑须**自动探测** OS 与是否有界面，禁止臆造另一套平台。

## 已定结论

1. **首期支持面**：Linux headless + 网关 + `fs_*` / 编码闭环 / `shell` / `wait` / `done`；会话走 PWA/浏览器，不新建 tty REPL。
2. **自动平台判定**：`platform_info.runtime_platform()` 读 OS、显示会话、`FAWAI_HEADLESS`；注入大脑 system prompt；能力清单在无 GUI 时去掉 click/type/hotkey。
3. **观察**：headless 或结构化目标候选不含 `obs_screen`；误请求截屏返回可读失败观察，不崩闭环。
4. **依赖**：核心安装不含 `mss`/`pyautogui`；桌面 GUI 用 `pip install -e ".[gui]"`。
5. **frpc**：校验二进制与 OS 匹配；Mach-O 不能在 Linux 跑；用 `FAWAI_FRPC_BIN` 或 PATH；不匹配则明确失败并可关穿透。
6. **明确不做（本切片）**：Linux/Wayland 真实 GUI 操控；系统级 tty 会话通道；自动下载 frpc。

## 依据摘要

- 编码/文件/shell/网关路径本就可移植；macOS 硬点集中在权限与截屏。
- `permissions_mac` 非 Darwin 已跳过；planner 原先已有 Linux 命令提示，需升级为统一平台块 + 能力闸门。

## 可行性速览

| 想法 | 实现难易 | 成本与时间（全 AI） | 可借用资产 |
|:---|:---|:---|:---|
| Headless 闸门 + 平台注入 | 低 | 约 1 次 Agent 会话；无额外 API | 现有 capabilities / planner / capture=False |
| 可选 `[gui]` 依赖 | 低 | 同会话；安装路径变更 | setuptools extras |
| frpc 平台校验 | 低 | 同会话 | 魔数检测 ELF/Mach-O |
| Linux 桌面 GUI | 高 | 另开议题；X11/Wayland | pyautogui/mss（需适配） |

## 开放问题

- 最小容器无 `lsof`/`pgrep` 时端口回收是否需兜底（保活可关）。
- 是否需要独立 stdin CLI 通道（非本切片）。
