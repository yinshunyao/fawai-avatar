# 会话

## 2026-11-02

- **诉求**：Web / 用户交互面按常规 i18n 架构支持多语言；先落地中文与英文；界面可随时切换。
- **范围**：PWA 会话壳（导航、门闩、任务管理、系统日志、服务与版本、系统配置、气泡壳与枚举展示名）；不改大脑/LLM 产出语言，不把协议口令（如复盘 `ok`/`全部`/`取消`）跟展示文案绑死。
- **做法**：目录资源（`zh-CN` / `en`）+ 运行时 `t(key)` + DOM `data-i18n*` + `localStorage` 偏好；顶栏与系统配置可切换。
- **放行**：用户明示「设计并先实现」→ 写入功能目录并落地。
