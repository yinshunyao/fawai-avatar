# 议题

同一任务执行中，规划近窗/compact 有损后，Agent 如何主动找回本任务已出现的话与工具结果。

# 已定结论

1. 产品面：`task_context_search` + `task_context_get`；默认仅当前 `task_id`。
2. 不替代规划历史窗；不拉长近窗；不混用 `lore_search` / 仓 FTS。
3. 首期词法检索；真源优先 live history → 检查点 history → steps 合成；observe dump 以指针回灌。
4. 规划提示：摘要里没有的本任务事实，先 `task_context_*`，文件再 `fs_read`。

依据：[分析/任务内上下文查询.md](../../分析/任务内上下文查询.md)。用户明示「立项落地」。

# 可行性速览

| 项 | 判断 |
|:---|:---|
| 难度 | 低～中（同任务体量小；接检查点与 BackgroundTools） |
| 成本 | 全 AI 可闭环；无新外部依赖 |
| 现成 | Web 已有 `GET /api/tasks/{id}/history`；闭环有 `run_checkpoint.history` |
