# 会话

## 2026-11-02

- **焦点**：fawai-avatar 作为 PC/手机操作分身的主能力分层
- **要点**：
  - 产品定位：跑在 PC/手机上的操作分身，替用户理解任务并动手完成
  - 主内容拆为三层，且形成闭环：观察 → 大脑 → 控制 → 再观察
  - **大脑**：理解与规划任务；产出指令（做什么、调什么工具/代码）、脚本/代码、PC/手机动作指令；评估任务进度并给结论
  - **控制**：调用工具、执行脚本与代码；操作鼠标与键盘；把执行结果回传
  - **观察**：看懂屏幕操作与状态，解析成 LLM 可消费的内容（含 OCR 等路径）
  - 本轮只定「三层职责边界」，未定各层技术选型与指令协议
- **对结论**：新建议题并写入三层职责与闭环；开放问题与下一步已列

## 2026-11-02（续）

- **焦点**：在三层之外补两条贯穿线
- **要点**：
  - 除大脑 / 控制 / 观察外，另需两条线，与执行闭环正交、可被各层读写
  - **任务与事件管理**：任务生命周期、进度、触发事件与调度（谁在跑、卡在哪、何时唤醒）
  - **知识经验存储**：可复用的做法、失败教训、场景经验，供大脑规划与评估时检索
  - 两条线不是第四「执行层」：不替代控制做副作用，也不替代观察读屏
- **对结论**：已定结论扩为「三层 + 两线」；开放问题补任务模型与知识写入边界
