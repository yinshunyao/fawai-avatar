# 结论

## 议题

任务对话如何用 `@` 提示工作区目录（非角色），并把所选目录作为语义焦点带进规划上下文。

## 已定结论

1. **`@` 针对工作区路径（目录与文件）**，不针对角色 / Agent；菜单无人物项。
2. **根 = `work_root`**；每级列出子目录与文件（目录在前）；隐藏 `.` 前缀与 `node_modules` / `.git` / `__pycache__` 等噪音。
3. **交互**：输入 `@` 弹出级联菜单；桌面目录**单击**展开下级（带动画；空则空列表）、目录/文件均**双击**选中；文件单击无动作；悬停不切换；三级时可藏一级；窄屏点入下钻 + 返回。
4. **载荷**：线缆文本为 `@相对路径`；`meta.at_dirs` 为 POSIX 相对路径列表（可含文件）；越界丢弃不挡发送。
5. **呈现**：输入框与会话气泡用 chip 原语（参考 Cursor），**只显示当前名**（目录/文件图标区分）；完整相对路径放 `title`/悬停。
6. **语义**：规划注入【语义路径】软偏置，优先落在这些路径（目录含子树）；不做硬闸「只能改这些路径」。
7. **明确不做（本切片）**：整盘 `FAWAI_READ_ROOTS` 浏览、角色提及、改中继协议。

## 依据摘要

- 用户明示：@ 不针对角色；弹出一级、悬停二级、三级可滚并藏一级；目录进上下文。
- 确认实施方案即放行落地。

## 可行性速览

| 想法 | 难易（对 AI） | 成本与时间（粗） | 可借用资产 |
|:---|:---|:---|:---|
| 目录列举 API | **低** | 约 1 次会话 | `work_root` + 路径闸模式 |
| PWA 级联菜单 | **中** | 约 1～2 次会话 | compose `#text`；窄屏点入 |
| meta + 规划注入 | **低** | 约 0.5 次会话 | `outboundEffortMeta` / `_plan_effort` 同模式 |
