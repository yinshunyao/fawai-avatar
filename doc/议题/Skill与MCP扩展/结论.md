# 议题

用户侧如何上传/修改 Skill，以及如何注册 MCP 外挂工具进入能力清单。

# 已定结论

1. **Skill 管理（2A）**：PWA 完整 CRUD——列表 / 查看 / 新建编辑 / 上传 JSON / 删除或停用；对齐 lore 条目管理。停用不删文件，规划注入与 `skill_search` 只见 enabled。
2. **工具扩展（1A）**：仅 **MCP stdio**；用户配置 server → refresh 发现 tools → 动态 `Capability`（`action_kind=mcp__{server}__{tool}`）进能力清单并由控制层调用。
3. **本切片不做**：上传 `.py` 当工具、铲子台账 UI、MCP SSE/HTTP、MCP resources/prompts。
4. 安全：MCP 为本机用户信任的子进程，与 shell 同级风险；不自动从网上装 server。

用户明示实现（计划确认 1A+2A）。

# 可行性速览

| 项 | 判断 |
|:---|:---|
| 难度 | Skill：低（扩 SkillStore + lore 式 API/PWA）。MCP：中（stdio 客户端 + 动态能力合并 + 执行分发） |
| 成本 | 全 AI 可闭环；运行期依赖官方 `mcp` SDK；无新云服务 |
| 现成 | `skills/store.py`、`lore_api`/`#lorePage` 模式、`list_capabilities` / `Controller.execute` 扩展点 |
