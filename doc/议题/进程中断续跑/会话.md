# 会话

## 2026-11-02

- **现象**：后台/网关重启后，任务状态仍为「执行中」，但 Worker 线程已没，不再推进；追问被 running 硬拒；「恢复」只改状态不拉线程。
- **选型**：采用策略 B——启动自动续跑；`paused` 保持暂停。
- **约束（用户）**：**不要整任务重开**（禁止 `requeue→pending` 当默认），须**从断点继续**。
- **做法**：步末/暂停时落 `meta.run_checkpoint`；启动扫描 `running|waiting|blocked|pending` 拉 Worker；`resume` 在无活线程时补拉；同进程暂停中的线程仍在则禁止双开。
