# 会话

## 2026-11-02

- **焦点**：任务执行失败后只简单重规划，原样重试仍失败；需要反省策略
- **要点**：
  - 现状：`WorkerLoop` 失败 → 写反馈 → `continue` 再 `plan`，无「为何失败 / 换方案还是止损」
  - 与「任务复盘」区分：本能力是**执行中**裁决；复盘是终态用户触发蒸馏
  - 方案：**专用 `Brain.reflect` + 动作指纹硬约束**；裁决 `retry` / `alternate` / `abort`
  - 同指纹失败 ≥2 强制 alternate；≥3 或 alternate 后仍同指纹 → abort
- **对结论**：新建议题六节写齐；用户确认执行计划即放行实现
