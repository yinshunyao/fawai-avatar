# 会话

## 2026-11-02

- **焦点**：分身跑在 macOS 上时，用户如何跨端对话；要支持多模态会话与展示
- **要点**：
  - 现状：已有大脑 / 控制 / 观察 / 总管，尚无「用户对话通道」
  - 主通道拍板：**自建 Web/PWA**（多模态优先）；不做个人微信作主 UI
  - 可达：先做 **同局域网**；架构同步支持 **云端中继**（Mac 出站长连接，手机只连中继；不要求家宽入站）
  - 架构：通道与操作解耦——手机 ↔ 会话网关 ↔ 总管 ↔ 工作任务；统一消息信封；LAN 与中继共用同一 PWA 协议
  - 明确不做：微信/OCR 主通道、首期原生 App、首期实时桌面视频流；中继厂商选型留到功能放行
- **对结论**：新建议题；已定结论含主通道、两档传输、信封、不做清单；可行性与开放问题已写；仍停在议题，未写入功能目录

## 2026-11-02（多轮归任务 / 新会话）

- **焦点**：多轮对话能否识别属于哪个工作任务；要不要做 ChatGPT 式「新会话」
- **要点**：
  - 现状：出站带 `task_id`；普通入站每条都 `create_task`；追问未落地；单文件历史时间线
  - **会话 ≠ 任务**：通道是气泡时间线；隔离真源是总管工作任务
  - **追问**：入站信封可选 `task_id`（PWA 当前线程）；无则 create；有则先硬规则（running/归档拒），再 **LLM/规则**判 continue|new_task；**不做**跨任务猜归属
  - ~~终态一律 sibling~~ → 已否决；同目标换法/补救可 reopen 续跑；另开时 `parent_task_id` 链原线程
  - 执行中（running）追问 → 明示拒绝，请先暂停/取消或等结束
  - **新会话**：仅清前端展示分段 + 重置焦点；**不**删任务库、不做多会话账本
- **对结论**：已定结论增「追问 / 建任务 / 新会话」语义与不做清单；可行性补追问与新会话行；开放问题关闭「多轮归任务」；下一步指向功能说明与实现

## 2026-11-02（线程内 LLM 路由）

- **焦点**：终态不要一刀切新建；按原目标/状态/本轮话判断续跑还是另开
- **要点**：
  - `brain/task_route.route_followup` → continue | new_task；mock 可离线
  - continue 终态走 `requeue_task(reopen=True)`；new_task 带 `parent_task_id`
  - 归属仍只认显式 `task_id`；路由只解决「线程内」是否拆任务
- **对结论**：已定结论第 7 条改写；功能会话通道 / 术语表同步；去掉 sibling 一刀切

## 2026-11-02（任务线程 UI）

- **焦点**：焦点条 /「设为焦点」太绕；要按任务维护对话入口
- **要点**：

  - 线程内发送自动带 `task_id`；「新任务」进空白compose（无 id → create）
  - 去掉焦点条与「设为焦点」；管理抽屉改为「打开对话」+ cancel/删/复盘
- **对结论**：已定结论第 7～8 条改为「任务线程」产品壳；新会话改为「新任务」入口；可行性补任务线程行

## 2026-11-02（执行中追加 + 用户图粘贴）

- **焦点**：running 时用户要能追加约束；会话里用户图不显示；粘贴图不要立刻发送
- **要点**：
  - 推翻「running 硬拒追问」：执行中 **追加** → LLM 结合状态 / 原 goal / 增量 → `apply`（并入 goal + `pending_appends`，Worker 步前消费）或 `new_task`；不打断当前工具
  - 用户入站图须 `publish` 带 `media_url`；PWA 乐观气泡带预览 URL
  - 粘贴/选图 → 会话附件暂存；点发送再 upload 派发
- **对结论**：已定结论第 7 条改写；关闭 P2「排队追问」；功能会话通道/网关同步放行落地

## 2026-11-02（图文气泡露出 `[image:]`）

- **焦点**：图文/回放把 goal 里的 `[image:/abs/…]` 当纯文本；进度刷历史后用户图丢失 → 合成气泡无 media_url
- **要点**：PWA 解析标记 → `/media/` 渲染；历史裁剪钉住用户消息；复盘指令展示剥标记；大脑把用户附图走 VLM
- **对结论**：功能会话网关/通道验收补强；属已支持面的缺陷修复
