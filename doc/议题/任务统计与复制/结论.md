# 结论

## 议题

对话侧栏（及任务管理卡）如何让用户**一键复制任务 id**，并看到**总 token / 总执行时间**，点击后查看含轮次、大模型调用、工具分布的统计详情——而不必展开整条执行时间线手算。

## 已定结论

1. **入口（已定）**：主落点为会话网关 PWA **左侧对话列表**（`.thread-row`）；任务管理页表格行同步支持。不另做独立统计页。
2. **id 复制（已定）**：
   - 列表展示仍可用短码（前 8 位 + `…`）。
   - **点击 id 区域**复制完整 `task_id`；复制成功给短暂反馈（如「已复制」），失败时提示。
   - 点击 id **不**切换当前线程（避免与整行打开对话抢手势：id 单独可点；其余区域仍打开线程）。
3. **列表摘要（已定）**：
   - 每行展示：**总 token**（优先 `total_tokens`）与 **总执行时间**（见下定义）。
   - 无数据时显示 `—`，不编造。
4. **总执行时间定义（已定）**：
   - **主指标**：该任务各次 Worker run 的墙钟合计（`started`→终态/`finalize`；续跑/reopen 累加）。
   - 不以逐步 `elapsed_ms` 简单加总当主展示（逐步含重叠与非 LLM 间隙，易误解）；详情里可另列「逐步耗时合计」若已有数据。
5. **统计详情弹层（已定）**：点击摘要区打开；至少含：

   | 项 | 含义 |
   |:---|:---|
   | 总 token | `prompt` / `completion` / `total`（有则分列） |
   | 总执行时间 | 上节墙钟合计 |
   | 轮次 | Worker 闭环步数（observe→plan→act 一轮计 1） |
   | 大模型对话次数 | 实际 LLM API 调用次数（含 plan / reflect / 路由等计入 usage 的调用） |
   | 工具类型与调用次数 | 按 `action.kind` 聚合；次数为实际执行次数 |

6. **数据真源（已定）**：
   - 运行中与结束后统一写入任务 `meta.stats`（结构稳定、可 JSON）；`GET /api/tasks`、`/api/session` 的 `_task_summary` **带出摘要字段**（不必每次拉满 steps）。
   - 闭环内**增量更新**（每步/每次 LLM 后 bump），以便 `running` 任务列表也能看得到。
   - 历史任务：若无 `meta.stats` 但有 `meta.steps`，可**懒回填**一次；仍无则显示 `—`。
7. **明确不做**：
   - 跨任务汇总仪表盘 / 计费出账
   - 用会话 `progress` 历史在前端现算当唯一真源（易丢、难列表化）
   - 未写入 `doc/功能/` 前不开工

## 依据摘要

- 侧栏已有短 id 与时间，缺复制与用量摘要；用户截图标出 id 与 meta 行右侧。
- 逐步 token/耗时已在时间线 `progress.meta` 与 `plan.raw`；缺任务级汇总与列表暴露。
- `_task_summary` 是列表唯一轻量面；适合挂 `stats` 摘要而非塞整段 steps。

## 可行性速览

口径：**全 AI 实现**；粗估、未核价；不等于放行或开工。

| 想法 | 难易（对 AI） | 成本与时间（粗） | 可借用资产 |
|:---|:---|:---|:---|
| **id 点击复制 + 反馈** | **低**。难点：与整行 `openThread` 手势分离 | 约 **0.5～1** 次会话 | **可直接用**：`index.html` `.thread-row` / `.tid`；Clipboard API |
| **`meta.stats` 增量 + 摘要 API** | **中**。难点：墙钟起止对齐续跑；LLM/工具计数口径一致；截断 steps 后仍保 stats | 约 **2～4** 次会话。**运行**：无额外 LLM | **可直接用**：`loop.py` `_llm_progress_meta` / `_finish`；`lan_gateway._task_summary`；`plan.raw.usage` |
| **侧栏摘要 + 详情弹层** | **低～中**。难点：窄栏排版；工具表可读 | 约 **1～2** 次会话 | **可直接用**：现有 Modal/抽屉样式；`formatTokenFact` / `formatElapsedMs` |
| **旧任务 steps 懒回填** | **低**。难点：clipped steps 可能少计 | 约 **0.5～1** 次会话 | `meta.steps[].plan.raw` / actions |
