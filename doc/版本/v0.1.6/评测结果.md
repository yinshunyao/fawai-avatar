## 分维依据

### D3 8.5

- **证据**：同线程跟进/执行中追加/计划追加一律续跑或并入，去掉 LLM 自动拆 sibling；减少「多轮被拆成新任务」空转。
- **扣分**：未跑 `demo_eval_priority` 量化步数。

### D5 8.5

- **证据**：hub 同事件循环 `publish_from_thread` 避免死锁；Cursor Agent 回合异常可 `fail` + error 气泡；可选 `FAWAI_SKIP_STARTUP_PERMISSIONS` 避开启动权限探测 SIGSEGV。
- **扣分**：启动跳过权限是逃生舱，不替代稳定权限路径。

### D7 9.5

- **证据**：任务级执行配置（列表/详情 `exec_config`、`POST …/exec-config`、开任务回填）；Cursor 身份吃 `exec_config`+`meta`，多轮同 `task_id` resume。
- **扣分**：真机同网手机未测；公证仍缺。

### 其余维度

- 沿用 [v0.1.5](../v0.1.5/评测结果.md)；本轮无新 GUI/C3 / 真 LLM 任务完成证据，D1/D2/D4/D6 不动。

## 相对上版

| 变化 | 说明 |
|:---|:---|
| +任务级执行配置 | 底栏跟任务；进行中可写 meta |
| +一对话一任务 | 禁止自动拆 sibling |
| +Cursor 多轮续跑 | 列表认 Cursor + 同线程 resume |
| +Node / 启动稳健 | vendor Node、nvm≥22；可跳过启动权限弹窗 |
| 总分 +1.7 | D3/D5/D7 各 +0.5 |

## 优先改进

1. 真 Cursor 登录 + 多轮 resume 端到端抽样（抬 D1 live）。  
2. 真机同网手机 PWA + Install 联调（D7）。  
3. 补跑 `demo_eval_priority`（D3/D5）。  
4. macOS 公证与 Windows 冒烟（安装器 P1）。  
5. 启动权限探测 SIGSEGV 根治（少依赖 skip 环境变量）。
