## 分维依据

### D1 8.0

- **证据**：冒烟三件仍绿；模式/台账/MCP 不直接计入任务 SR。  
- **扣分**：无新的真 LLM 端到端自我改进核心实测。

### D2 8.5

- **证据**：MCP 工具进能力清单；Skill 管理与成败极性进检索；假归因/完成任务相关代码合入。  
- **扣分**：`FAWAI_C2_LIVE` 未跑。

### D3 8.0

- **证据**：极速跳过观察反省；`act`/`brief` 分档；自动模式按难度写回偏好。  
- **扣分**：无本轮步数/token 台账写入报告。

### D4 7.5

- **证据**：沿用 0.1.3 文件回证与 capture；本轮无新 GUI 实测。  
- **扣分**：C3 live / Electron 仍缺。

### D5 8.0

- **证据**：沿用租约/步骤守卫；取消打断与计划时序有代码合入但未单开全套评测。  
- **扣分**：未重跑 D5 全套 `demo_eval_priority`。

### D6 8.5

- **证据**：路径/租约冒烟仍拒无租约 GUI；出站脱敏细化。  
- **扣分**：未新开专项安全任务集。

### D7 8.5

- **证据**：模式面板中英；Skill/MCP/铲子管理页；产物预览；Install 平滑升级保留 data。  
- **扣分**：公证未做；真机同网手机未测。

## 优先改进

1. 补跑 `demo_eval_priority`（含 capture）确认 D5 不回退。  
2. 真机同网手机 PWA + 安装包 Start/Install 联调（抬 D7 证据）。  
3. macOS 公证与 Windows 杀软冒烟（安装器 P1）。  
4. `FAWAI_C2_LIVE` / 真 LLM「记一笔」抽样（抬 D1/D2）。  
5. 安装包预置或惰性 Playwright（可选）。
