## 分维依据

### D2 9.0

- **证据**：Cursor Agent 独立面 + 主脑 `tier=cursor`；diff 浏览与产物投影进 PWA；能力清单可分轨（本机编码 vs Cursor SDK）。
- **扣分**：未跑 `FAWAI_C2_LIVE`；live Cursor 质量未盲测。

### D7 9.0

- **证据**：Cursor 式步骤流写 `meta.steps`；diff hunk/清单可监督；doc 编号化利于产品/测试对齐。
- **扣分**：真机同网手机未测；公证仍缺。

### 其余维度

- 沿用 [v0.1.4](../v0.1.4/评测结果.md) 依据；本轮无新 GUI/C3 证据。
