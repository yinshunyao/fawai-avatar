## 分维依据

### D1 8.0

- **证据**：套件 `D1-plan-exec-readback` / `D1-gateway-http`；计划模式调度与失败节点重试；编码/文件/py/铲子交付路径可复跑。  
- **扣分**：无真 LLM「记一笔/整理/摘要」；无手机真机同网 SR；无任意 GUI App 任务。

### D2 8.0

- **证据**：误导写文件仍 `fs_write`；强制 click 被硬拒；超清单 `failed`；browser/py/shovel 进清单。  
- **扣分**：真模型 `FAWAI_C2_LIVE` 未跑。

### D3 7.0

- **证据**：租约改道、指纹空转、步骤重复、观察崩溃后重规划均在有限步内止损或换道；观察反省有 mock。  
- **扣分**：仍无步数/token 分布台账写入本报告。

### D4 7.5

- **证据**：文件态回证；capture 截图 usable；AX/C3 干跑；多屏 displays 实测 2 屏。  
- **扣分**：TextEdit 真机 `FAWAI_C3_LIVE` 未开；Electron 控件级未做。

### D5 8.0

- **证据**：`D5`/`D5b`/`D5c`/`D5d` 全过（租约改道、指纹、步骤重复、step_crash 恢复）。  
- **扣分**：无 API 抖动 pass^k；无多策略对照台账。

### D6 8.5

- **证据**：路径逃逸与 `.env` 禁写/不进快照；C4 最少核与归档禁改；写租约拒绝稳定。  
- **扣分**：符号链接逃逸等未单列。

### D7 7.5

- **证据**：网关套件；步骤流/`step_label`/从步骤恢复与计划模式会话面已落地（代码+文档）。  
- **扣分**：真机 PWA 同网未测。
